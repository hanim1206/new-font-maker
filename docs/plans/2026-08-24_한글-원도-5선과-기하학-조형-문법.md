# 한글 원도 5선과 기하학 조형 문법

이번 작업은 **네모꼴 폰트**를 만든다는 전제에서 시작한다. Font Space는 1000이고, 글자 몸틀은 사방 75 여백을 둔 850×850 Canonical Design Body로 고정하는 안을 비교 보드에서 검토한다.

## 원도 5선

원도의 다섯 가로선은 다음 두 종류로 구분한다.

- 고정 몸틀선: `윗선`, `밑선`
- 가변 배치선: `첫닿윗선`, `원도 중심선`, `받침밑선`

다섯 선은 모든 획이 반드시 닿는 셀 경계가 아니다. 네모꼴 전체의 수직 리듬과 초성·중성·종성의 기본 영역을 정하는 레이아웃 기준이다. P0에서는 초성이 포함된 7개 조합 레이아웃만 이 선에 연결한다.

`원도 중심선`은 글자 배치 기준이고, 자소의 선을 만드는 `획 중심선`과 다른 개념이다.

## 형태를 만드는 그리드

레이아웃 그리드와 자소 형태 그리드는 분리한다.

- 레이아웃 그리드: 자소가 놓일 영역을 5선으로 계산한다.
- 자소 형태 그리드: 계산된 영역 안에서 선의 앵커, 면과 hole의 경계, 사선과 곡선을 만든다.
- 최종 잉크: 선과 면을 동등한 재료로 합쳐 화면과 폰트 출력에서 함께 사용한다.

서체의 일관성은 같은 셀을 반복하는 것만으로 만들지 않는다. 공통 면 두께, 선 굵기, 사선 각도군, 곡률과 모서리, 끝처리, 간격과 속공간이 함께 조형 문법이 된다. 셀 점유는 그 문법을 표현하는 도구 중 하나다.

## P0 범위

P0는 신규 5선 네모꼴 프로젝트만 다룬다.

- 5선과 7개 조합 레이아웃의 기본 영역
- 대표 ㄱ·ㅁ의 선·면·hole 투영
- 사용자 시각 승인 뒤 신규 프로젝트 저장과 Guide 편집
- 대표 SVG와 prototype OTF

기존 프로젝트의 5선 연결이나 1000 advance 변환, 전체 67개 자모, 사선·곡률의 production 연결, 완성형 11,172자 출력은 포함하지 않는다.
