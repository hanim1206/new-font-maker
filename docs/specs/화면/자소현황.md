# 자소 현황

형태 시스템에 저장된 자소 원형(마스터)이 몇 개인지 보는 목록. 고치는 기능은 없다.
탭에서는 올 수 없다. `자소` 탭은 자소 편집(`/workspace/jamo`)으로 가고, 이 화면은 주소를 직접 치거나 없는 `/workspace/…` 주소의 안내 화면에서만 들어온다.

## 1. 셸
- 1.1 문장 보정으로 · 화면 이동 — `자소편집 1.1` `자소편집 1.4`와 같음. 되돌리기 · 다시 하기는 꺼져 있고 상태는 `화면 검토 모드` 고정

## 2. 머리
- 2.1 형태 시스템 상태 — 연결 전 / 마스터 몇 개 연결됨 / 저장 데이터 확인 필요

## 3. 저장된 원형 목록
- 3.1 원형 줄 — 형태 시스템이 있을 때. 역할과 자모(`초성 ㄱ`), 글자 미리보기, `저장 요소 N개 · 직접 보정 M개`
- 3.2 원형 보기 — 초성 ㄱ 줄만 `/workspace/jamo/master`로 간다. 나머지 줄은 `화면 연결 전`으로 꺼져 있다

## 4. 대표 자소 목록
- 4.1 대표 여섯 자 — 형태 시스템이 없을 때 대신 나온다. ㄱ ㅇ ㅏ ㅂ ㅎ ㅙ의 미리보기와 상태(`연결 전` `저장된 마스터 없음` 등). 미리보기는 앱의 지금 획이지 원형 상태가 아니다
- 4.2 화면 보기 — ㄱ만 원형 화면으로 간다. 나머지는 꺼져 있다
