## 동선

1. `VITE_LOGIN_AT=entry | download`. `entry`는 지금 그대로. `download`면 비로그인은 이 기기 사본(`LOCAL_OWNER`)으로 바로 연다. 10/9에 Vercel 값만 바꾼다.
2. 다운로드를 누르면:
   - 동의 기록이 없거나 약관 버전 · 라이선스가 바뀌었으면 **동의 시트**(필수 넷: 약관 · 처리방침 / 만 14세 이상 / 공개 · 홍보 / 폰트 사용 조건). 넷 다 체크해야 단추가 켜진다.
   - 로그인 전이면 단추가 `동의하고 카카오로 계속`. 체크한 것과 "받던 중" 표시를 sessionStorage에 두고 카카오로 갔다 온다 → 프로필에 기록 → 이 기기 사본을 계정 폰트로 올림 → 이름 시트 → OTF.
   - 로그인돼 있으면 `동의하고 받기`. 이미 동의했으면 시트 없이 바로 이름 시트.
3. 베타 계정도 받을 때 같은 시트를 한 번 본다. `download` 모드에서 베타 코드 입구는 로그인 자리의 작은 링크로 남긴다.
4. 받은 폰트는 계정 화면(`AccountPage`)에서 본다. 탈퇴 단추도 여기.
