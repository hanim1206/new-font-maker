# 판정 v1.2 홀드아웃 게이트

[2026-09-15_변화량-모델-상호작용-v2-착수](./2026-09-15_변화량-모델-상호작용-v2-착수.md)의 후속. v2 selective 판정이 놓치던 큰 신호를 홀드아웃으로 다시 잡는다.

## 발견

궥(ㄱ+ㅞ+ㄱ) 검수 중 홀자 밑기둥이 실측과 +25.5u 벌어졌다. 첫닿왼선은 -3.9u로 잘 맞았고, 이 차이는 밑기둥 쪽. 원인을 파보니 baseStem mixed-final 층이 **broad로 배제된 상호작용**이었다. 강셀 17개, 흡수율 78%인데 10셀 cap을 넘어 selective서 빠졌다. 사용자가 처음 눈으로 짚은 ㄲ+ㅗ 밑선도 같은 부류(강셀 13개).

## 왜 cap이 틀렸나

- 순차 추정이라 셀 보정은 v1 잔차에서만 뽑는다. **주효과는 셀 수와 무관하게 안 바뀐다.** v1이 전셀 상호작용을 뺀 이유(주효과 흡수·편집 Δ 붕괴)는 이미 무효.
- 많은 셀의 진짜 위험은 "잔차 암기"뿐인데, 그건 셀 수가 아니라 **홀드아웃**이 직접 잡는다.

홀드아웃(셀 보정항이 못 본 글자)에서 broad 층들이 오히려 좋아졌다:
- baseStem mixed-final: p95 28.8 → 9.1
- ㄲ+ㅗ bottom-final: p95 23.3 → 14.0
- bottom mixed-final: p95 26.0 → 15.2

암기면 나빠져야 하는데 일반화됐다. 게다가 강셀 비율(coverage)은 다 0.14~0.19로 낮다 — 소수 셀만 튀는 구조지 잔차 저장이 아니다.

## v1.2 규칙

10셀 하드 cap을 버리고 두 게이트로 바꾼다.

- **홀드아웃 게이트**: 셀 보정을 넣은 홀드아웃 p95가 안 넣은 것보다 충분히(약 10%) 좋아질 때만 적용. 일반화 못 하면 예외로 실측 보존.
- **coverage 안전장치**: 강셀이 관측 충분한 셀의 큰 비율(약 0.6 초과)이면 사실상 잔차 저장이니 배제.

그대로 두는 것:
- shape-transition 가드(윗보 접촉 on/off는 셀 보정 아님)
- 셀당 최소 3관측·부호 80% 일관
- 실측 안 덮음, 편집 Δ 불변(셀 보정은 잔차처럼 딸려감)

결과적으로 selective/broad 이분법이 사라진다. **일반화되는 상호작용은 셀 수와 무관하게 흡수, 안 되는 건 예외 보존.**

## 영향

- v2 산출물 판정이 바뀐다(broad 여럿 → 적용). 검수판 예외수·오버레이 예측이 달라진다.
- API·검수판 코드는 `interaction.applied`만 보므로 그대로 반영된다(수정 불필요).
- 빌더 판정 로직 + 테스트 갱신 필요.

## 승인셋 검증 · 무받침 보 한계

승인 57자(무받침) 대비 정합을 골든셋 회귀로 고정했다(`validate_against_approved.py`).
- 닿자 위치면은 사람 마스터와 정합: 첫닿 밑·왼·오른선 중앙 ~1u.
- 약점은 보 길이·혼합홀자 보뿐: 아랫보 길이 p95 41.6u(쫘·좌·화 등).

원인은 모델 결함이 아니라 무받침 데이터 희소. 무받침 보 길이 층은 (첫닿,홀자) 셀마다 관측이 딱 1개(n=76, 76셀)라 강셀도 홀드아웃도 못 만들어 상호작용이 안 붙는다. 같은 타깃 right-final은 셀당 27개라 상호작용이 잘 붙는다(gain 0.80). 받침 글자는 잘 모델링되고, 승인 무받침은 마스터라 실측을 그대로 쓰므로 출력 품질엔 영향 없다. 무받침 자동생성 단계에서 필요하면 -final 셀 오프셋을 빌려오는 걸 검토한다(생성 단계 과제).

## 결과 (구현 후)

- 적용 6 → 18층, 예외 10010 → 3833 (62% 흡수).
- 꼭 첫닿밑선 ㄲ×ㅗ −47u 흡수, 잔차 1.8u. 궥 홀자 밑기둥 ㄱ×ㅞ +25.3u 흡수, 잔차 0.2u.
- broad·no-generalization 판정은 현 corpus에 없음 — gain 통과 층이 전부 coverage 낮고 홀드아웃 개선. cap만이 잘못 버리고 있었음이 확정.
- 빌더 v1.2 + 테스트 26개 통과. dev 커밋 완료. API·검수판은 무수정 반영.
