# 뼈대 탭 제거

- **이번에 비교하는 것**: 셸의 `뼈대` 탭을 없앨지, 그 자리에 `전체·층` Δ 화면을 새로 둘지.
- **이번 승인으로 바뀌는 것**: `뼈대` 탭과 `/workspace/skeleton` 화면이 사라진다. 셸 탭은 `홈 · 자소 · 검수 · 출력`. 옛 주소는 자소 탭으로 넘긴다.
- **바뀌지 않는 것**: 글자 배치(모델 상자 + Δ), `Noto 배치` 토글, 스키마 fallback, OTF 내보내기, 형태 저장소와 `layoutGridSystem` 서비스, production 값.

9/17 결정("손으로 만든 옛 프리셋·뼈대 페이지 폐기")의 남은 순서 가운데 첫 조각. [2026-09-20_레이아웃-수정을-자소-탭으로-옮기기](./2026-09-20_레이아웃-수정을-자소-탭으로-옮기기.md)에서 다음 플랜으로 미룬 것.

## 지금 상태

**사실** (코드 읽기)
- `/workspace/skeleton` = `ShapeWorkspacePage.tsx`의 `SharedLayoutScreen`(1181~1429행)과 그 앞 `resolveLayoutRailModels`. 옮긴 기준선은 형태 저장소(`layoutGridSystem`)에만 저장된다.
- 그 값을 읽어 글자를 그리는 화면이 없다. 자소·검수·문장의 글자는 전부 `useContextPlacement`의 모델 상자로 놓인다. 화면 명세 `docs/specs/화면/뼈대.md`에도 `폐기 예정 · 글자에 안 닿음`.
- 탭 링크는 `WorkspaceChrome.tsx` 한 곳. 이 화면을 직접 여는 e2e는 `shape-workspace-shell`의 L-01 하나.
- `layoutGridSystem*` 서비스는 형태 저장소·5선 랩·테스트 20여 곳이 쓴다. 화면만 지우고 서비스는 남긴다.
- `전체` 범위 배치 Δ는 이미 자소 탭 레이아웃 모드의 전파 카드 `전체` 칩으로 고친다. 뼈대 자리에 같은 일을 하는 화면이 또 필요한 근거가 지금은 없다.

**같이 못 하는 것과 이유** — 9/17엔 한 묶음이었지만 선행 조건이 안 됐다.
- 스키마 fallback·`Noto 배치` 토글 제거: 모델이 dev API(`/api/noto-preset/model`)로만 오고 `public/`에 정적 파일이 없다. 지금 지우면 배포 빌드에서 글자가 안 그려진다.
- **OTF 내보내기가 아직 스키마 배치다**(`fontExportUtils.ts:145` `placement: { kind: 'schema' }`). 화면은 모델 상자 + Δ인데 내보낸 폰트는 옛 배치다. 레이아웃 모드에서 고친 Δ가 OTF에 안 들어간다. 이 플랜 밖이지만 다음 순서의 첫째로 둔다.

## 하려는 것

1. `WorkspaceChrome`에서 `뼈대` 탭을 뺀다. `WorkspaceArea`의 `'skeleton'`도.
2. `SharedLayoutScreen`과 그 화면만 쓰는 코드(`resolveLayoutRailModels`, 전용 CSS, 전용 import)를 지운다. 다른 화면이 같이 쓰는 건 남긴다.
3. `/workspace/skeleton`은 `/workspace/jamo`로 넘긴다(검수 글자 화면 때와 같은 방식).
4. e2e L-01을 지우고 "옛 뼈대 주소는 자소 탭으로 넘어간다" 한 줄로 바꾼다. 셸 탭 수를 세는 단언이 있으면 맞춘다.
5. 화면 명세: `뼈대.md`를 `docs/archive/`로, `_트리.md`와 `screenRoutes.ts`에서 뼈대 줄을 뺀다.
6. `CLAUDE.md`·`AGENTS.md`의 "유지할 설계 결정: Split + Padding 레이아웃"은 **이번에 안 고친다.** fallback이 살아 있는 동안은 아직 참이다. 4단계(아래)에서 고친다.

## 미결정 → 2026-09-21 승인: 셋 다 추천안

1. **뼈대 자리** — 탭 제거(추천) vs `전체·층` Δ 화면을 그 자리에. 제거하면 원칙의 "탭 순서 = 수정 범위(전체 → 이 층 → 이 자모 → 이 글자)"가 셸과 어긋난다. 범위는 탭이 아니라 전파 카드의 칩으로 고르게 된 지 이미 오래라, `마무리` 때 원칙 문구를 고칠지 같이 본다.
2. **옛 주소** — 자소 탭으로 넘김(추천) vs 없는 화면으로 둠.
3. **순서** — 이 플랜 먼저(추천: 작고 위험 없음) vs OTF 불일치 먼저.
