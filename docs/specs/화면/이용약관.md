# 이용약관

서비스 이용약관. 로그인 게이트 앞에서 열려 로그인 없이 읽을 수 있다(카카오 심사 · 가입 전). 본문은 `src-next/legal/terms.md`, 빈칸은 `legalInfo.ts`가 채운다.

## 1. 본문
- 1.1 머리 `‹` — 같은 사이트에서 왔으면 뒤로, 주소로 바로 왔으면 처음 화면으로
- 1.2 머리 제목 `이용약관` — `‹` 옆, 작업 화면 머리와 같은 18 · 아주 굵게
- 1.3 조항 — 조 제목, 번호 목록, 굵게. 글은 고를 수 있다
- 1.4 끝에 `개인정보 처리방침 보기` 링크
