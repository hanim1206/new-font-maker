# 자소 크기 막대 — 획 편집 캔버스 왼쪽 세로 막대로 자소를 통째로 키운다

- **이번에 비교하는 것**: 자소 크기를 점을 하나씩 끌어서 바꾸는 지금 방식과, 왼쪽 세로 막대 하나로 자소 전체를 같은 비율로 키우고 줄이는 방식.
- **이번 승인으로 바뀌는 것**: 획 편집 캔버스 왼쪽 가장자리에 세로 막대가 생긴다. 올리면 자소가 가운데를 기준으로 커지고, 내리면 작아진다. 결과는 획 좌표에 저장된다.
- **바뀌지 않는 것**: 굵기(전역 값 그대로) · 레이아웃 상자와 틀 계산 · 피그마식 선택 규칙 · 레이아웃 탭 · 문장 줄.

배경: 획 편집은 탭하면 중심선만 보이고 상자가 없어서, 크기를 바꿀 손잡이가 없다(2026-09-28, 사용자 아이디어. 프로크리에이트의 왼쪽 브러시 크기 막대 같은 것).

## 결정 (2026-09-28, 사용자)

| 무엇 | 결정 | 왜 |
|---|---|---|
| 무엇이 커지나 | **자소 전체**(ㄹ이면 ㄹ 통째로) | 획 하나만 키우면 이음새가 벌어진다. 사용자가 원한 건 "ㄹ 자체가 커지는 것". |
| 굵기 | 그대로 | 굵기는 전역에서 정한다. `두께 고정` 원칙과 맞는다. |
| 상자 밖으로 넘치면 | 넘친 채로 둔다 | 레이아웃 상자는 가이드다. 틀이 상자를 붙잡고, 넘친 만큼이 눈에 보인다. |

## 어떻게 (AI 안)

1. **막대.** 획 편집 캔버스 왼쪽 가장자리에 세로 막대를 둔다. 끄는 만큼 커지고, 손을 떼면 가운데로 돌아온다(조그). 여러 번 이어서 올릴 수 있다. 끄는 동안 `112%`처럼 배율을 작게 보여 준다. 획 편집 중일 때만 보인다.
2. **계산.** 자소의 모든 채널(`strokes` · `horizontalStrokes` · `verticalStrokes` · `contextStrokes`)의 점과 곡선 핸들에 같은 배율을 곱한다. 기준점은 중심선 범위의 가운데다. 새 순수 함수 `scaleJamoStrokes(jamo, factor)`로 만들고 테스트한다.
3. **저장.** 기존 획 편집 저장 경로를 탄다. 이 경로의 `frameForEdit`(`CalibrationSentenceEditor.tsx:2211`)이 **처음 키울 때 틀을 먼저 굳힌다.** 틀이 없으면 맞춤 계산이 커진 자소를 상자에 다시 꽉 채워 넣어서 막대가 아무 효과가 없다.
4. **되돌리기.** 막대를 한 번 끌었다 놓는 게 되돌리기 한 번이다. 끄는 도중에는 미리보기만 보여 준다.

## 미결정

- 막대 한 번에 바뀌는 폭. 막대 끝까지 끌면 ±30%인지 ±50%인지.
- 보선 rail과 막대가 겹칠 때 어느 쪽이 이기나. AI 안은 획 편집 중에는 rail이 없으므로 막대가 이긴다는 것.
