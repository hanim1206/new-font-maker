# 로그인

받을 때 로그인 모드(`VITE_LOGIN_AT=download`)의 로그인 화면. 들어올 때 로그인 모드에선 같은 화면이 주소 없이 앱 자리에 뜬다(초대 코드만). 계정 화면 `카카오로 시작하기`와 다운로드 직전 동의 시트에서 온다. 이미 로그인돼 있으면 대시보드로.

## 1. 로그인
- 1.1 인사 — 맨 위 앱 글자 `환영합니다`(초대 링크 `?to=`가 있으면 이름까지)
- 1.2 카카오로 시작하기 — 카카오 노랑 단추. Supabase 콜백을 거쳐 대시보드로 돌아온다
- 1.3 초대 코드가 있어요 — 작은 링크. 누르면 베타 코드 입력칸과 `들어가기`가 펼쳐진다
