# 결정 원칙 (자율 모드용)

클라우드 세션은 옵시디언 `원칙.md`를 못 본다. 거기서 사용자가 고른 줄만 옮긴 것이다. "멈추고 묻는다"에 걸리는지 애매할 때 먼저 본다. 여기 어긋나는 변경은 구현이 맞아도 묻는다. 줄을 더하거나 고치는 것은 사용자만 한다.

## 생성 엔진

- 모든 자소는 획(centerline)으로 그리고 편집한다. 노토 윤곽은 측정 · 고스트 · 룩에만 쓰고 잉크에 섞지 않는다.
- 두께는 문맥에 따라 변하지 않는다. 문맥별로는 위치 · 크기 · 비율만 변한다. 획마다 굵기는 사용자가 획 편집에서 정한다(기본은 프리셋 값).
- 홀자 줄기의 자리와 길이는 보선이, 모양(휨 · 기울기)은 획이 정한다. 보선은 레이아웃 편집에서만 옮긴다.
- 분석값은 제품 기본값으로 자동 승격하지 않는다. 레거시는 고치지 않고 동결한다.
- 프리셋이 넣는 오버라이드와 사용자가 넣는 오버라이드는 저장을 따로 한다. 사용자 값이 프리셋으로 올라가지 않는다.

## 편집

- 전파 범위의 기본은 자동이고, 좁히는 것만 사용자가 고른다.

## 일하는 방식

- 테스트 통과는 역할 정확도가 아니다. 상태를 섞어 완료율을 만들지 않는다.
- 같은 로직은 화면이 달라도 코드 한 곳에서 고친다. 고칠 때는 읽는 곳 · 쓰는 곳 · 재는 곳을 전부 찾는다.
