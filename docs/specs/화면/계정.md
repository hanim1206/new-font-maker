# 계정

대시보드 머리 아바타로 들어오는 내 정보 페이지(09-27, 팝오버에서 페이지로). 머리는 `‹`만 있고 대시보드로 돌아간다. 하위 주소 `/account/feedback`이 내가 보낸 의견 목록이다.

## 1. 내 정보
- 1.1 닉네임 — 큰 제목. 아래 옅은 줄 `베타 참여자`
- 1.2 내 폰트 — 가진 폰트 수 / 한도(계정당 3개)
- 1.3 요금제 — `베타 · 무료`
- 1.4 가입 — 가입한 날
- 1.5 로그아웃 — 로그인 게이트가 켜졌을 때만. 손님(받을 때 로그인 모드의 로그인 전)이면 대신 `카카오로 시작하기` → `/login`, 옅은 줄은 `로그인 전`

## 2. 내가 보낸 의견
- 2.1 계정 페이지의 `내가 보낸 의견` 줄로 들어간다. 안 본 한임 답이 있으면 빨간 점
- 2.2 큰 두 줄 제목에 보낸 개수, 옅은 안내 한 줄(쓰기는 화면 머리의 제보 단추로)
- 2.3 줄마다 갈래 아이콘 · 글 전체 · 보낸 화면. 한임 답이 있는 줄에만 `한임 답 보기` 토글, 펼치면 본 것으로 표시돼 점이 사라진다
- 2.4 `/account/feedback/<대화 id>`로 오면 그 줄의 답을 펼쳐 둔다(옛 링크)
