# 계정 페이지와 한임에게 의견 — 팝오버를 페이지로, 의견은 대화로

- **이번에 비교하는 것**: 계정 정보를 지금처럼 오른쪽 위 팝오버로 둘지, 토스식으로 밀려 들어오는 페이지로 뺄지. 그리고 의견을 카톡 대신 앱 안 대화(친구 ↔ 한임)로 받을지.
- **이번 승인으로 바뀌는 것**: 아바타를 누르면 `/account` 페이지가 열린다(팝오버 제거). 거기서 `한임에게 의견 보내기`로 의견을 쓰고, 보낸 의견마다 한임 답장을 대화로 본다. `/admin`에 `의견` 탭이 생겨 답장한다. Supabase에 의견 테이블 하나.
- **바뀌지 않는 것**: 로그인 · 계정 발급 · 3개 한도, 폰트 저장, 대시보드 캐러셀, 어드민이 이 맥에서만 열리는 것(루프백 + 전용 헤더).

배경: 계정 팝오버가 모바일에서 어색하다(2026-09-27, 사용자 "팝업 자체가 밤티"). 시안 다섯 장은 이날 실제 앱 위에 덧입혀 찍어 보여 줬다 — 계정 페이지 · 의견 쓰기 · 대화 · 어드민 목록 · 어드민 답장.

## 결정 (2026-09-27, 사용자)

| 무엇 | 결정 | 왜 |
|---|---|---|
| 계정 화면 | 팝오버 → **페이지** `/account` | 토스는 계정 · 설정을 페이지로 민다. PC도 같은 페이지. |
| 의견 | 앱 안 **대화**, 한임이 `/admin`에서 답장 | 베타 친구 의견을 한곳에 모은다. |
| 화면 캡처 | **1차 제외** | SVG · 캔버스 섞인 화면은 캡처가 잘 깨지고 저장소 권한이 따로 든다. 대신 경로 · 폰트 · 기기 · 버전을 글로 붙인다. |

## 어떻게 (AI 안)

1. **계정 페이지.** `AccountMenu` 팝오버를 걷고 아바타는 `/account`로 push. 큰 이름 · 베타 참여자 → 행 셋(내 폰트 n/3 · 요금제 · 가입) → 회색 띠 → `한임에게 의견 보내기 ›` → 맨 아래 회색 `로그아웃`. 선 · 카드 없음.
2. **테이블 하나.** `feedback_messages(id, thread_id, user_id, author 'friend'|'hanim', body, context jsonb, created_at)`. 첫 메시지의 id가 곧 `thread_id`. `context`는 보낸 경로 · 폰트 이름 · 기기(UA) · 빌드 해시.
3. **RLS.** 친구는 자기 `user_id` 행만 읽는다. 쓰기는 `author = 'friend'`이고 `user_id = auth.uid()`일 때만. 한임 답장은 어드민 API가 `service_role`로 쓴다.
4. **친구 화면.** `/account/feedback`: 입력칸 · `보내기` · 보낸 의견 목록(`답장 왔어요` / `읽었어요`는 굵은 검정, 파랑 없음). 목록 행 → `/account/feedback/:id` 대화, 아래에서 더 보내기.
5. **답장 표시.** 한임 답이 마지막으로 본 때보다 새로우면 계정 행과 아바타에 빨간 점.
6. **어드민.** `/admin` 위에 밑줄 탭 `베타 초대 | 의견 n`. 답장 안 한 것 먼저, 누르면 그 자리에서 펼쳐 context · 답장 칸 · `읽음만` · `답장 보내기`. API는 `betaInviteApi.ts`와 같은 세 겹 잠금.
