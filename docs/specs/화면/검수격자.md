# 검수 · 글자 격자

11,172자를 표로 한눈에 훑고, 고칠 글자를 골라 자소 편집으로 넘긴다. 셸의 `검수` 탭. 이 화면에서는 아무것도 고치지 않는다.
주소: `?char=간`으로 처음 고를 글자를 정한다. 옛 주소 `/workspace/review/glyph?char=…`는 같은 글자의 자소 편집 레이아웃 모드로 넘어간다.

## 1. 셸
- 1.1 문장 보정으로 — 왼쪽 위 링크, `/`로 간다
- 1.2 탭 이동 — 뼈대 · 자소 · 검수. 되돌리기 · 다시 하기는 이 화면에서 꺼져 있다

## 2. 머리
- 2.1 추출 현황 — Noto에서 몇 자를 읽어 왔는지
- 2.2 `문장 · 격자` 전환 — `문장`은 자소 편집(`/workspace/jamo`)으로 간다

## 3. 격자
- 3.1 축 배치 — 행 · 열 · 시트에 홀자 · 받침 · 첫닿자를 어떻게 놓을지 셋 중 하나
- 3.2 시트 고르기 — 시트 축의 자모 하나를 골라 그 장만 본다. 시트마다 상태별 글자 수
- 3.3 칸 크기 — `보통` / `크게 · 자모 점`(칸 안에 부품별 추출 단계 점)
- 3.4 칸 고르기 — 누르면 선택, 선택된 칸을 다시 누르면 5.2처럼 글자를 연다
- 3.5 키보드 — 방향키로 행 · 열, `[` `]`로 시트를 옮긴다. 선택만 바뀐다
- 3.6 승인 글자 표시 — 파란 테두리 = 승인 측정 글자

## 4. 칸 색
- 4.1 색 기준 — `Noto 대비 xor`(기본) / `추출 상태`
- 4.2 xor 범례 — 15 · 30 · 60% 네 단계와 계산한 날짜. 앱 기본 획 기준이라 내 편집은 반영되지 않는다
- 4.3 상태 범례 — 지금 시트의 추출 상태별 글자 수

## 5. 선택 카드
- 5.1 고른 글자 — Noto 모양, 글자, xor %, 자모 구성, 승인 여부
- 5.2 글자 열기 — 카드를 누르면 `/workspace/jamo?char=…&mode=layout`으로 간다
