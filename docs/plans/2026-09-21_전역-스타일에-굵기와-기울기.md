# 전역 스타일에 굵기와 기울기

- **이번에 비교하는 것**: 자소 편집의 `글로벌 스타일` 패널에 `굵기` · `기울기`를 넣을지, 지금처럼 네모꼴 · 획 스타일 둘만 둘지.
- **이번 승인으로 바뀌는 것**: 패널에 세 번째 탭 `굵기 · 기울기`가 생긴다. 폰트 전체에 한 값씩. 문장과 캔버스에 미리 보이고 손을 떼면 적용, 되돌리기에 들어간다.
- **바뀌지 않는 것**: 네모꼴(8.1) · 획 생성 규칙 · 붓촉 · 절단 끝(8.2–8.4), 획 데이터, 레이아웃 상자, 저장 형식(`globalStyleStore`에 `weight` · `slant`가 이미 있다).

옛 버전 전역 스타일을 지금 버전에 되살리는 첫 단계. 조사해 보니 네모꼴과 브러쉬(종류 · 각도)는 이미 자소 편집 8번 패널에 살아 있고, 빠진 건 굵기와 기울기의 조절 UI뿐이다.

## 지금 상태 (사실)

- `굵기`: 저장소에 있고 자소 편집 잉크(`ShapeWorkspacePage`의 `weightToMultiplier`)와 추출이 이미 읽는다. 바꿀 UI가 없어 늘 400.
- `기울기`: 저장소에 있고 `SvgRenderer`가 글자 중심 기준 skewX로 그린다. 추출은 `finalGlyphInk`의 기울기 투영으로 받는다. 바꿀 UI가 없어 늘 0.
- 원칙 `두께는 고정`은 문맥마다 굵기가 달라지지 않는다는 뜻이다. 폰트 전체 굵기 한 값은 어긋나지 않는다.

## 이 뒤에 오는 것 (이번 플랜 아님)

1. **네모꼴이 글자 모양까지 줄이게** — 8.1은 지금 글자 폭만 바꾸고 모델 상자 글자는 따라오지 않는다. 옛 `레이아웃별 캔버스 비율`이 하던 일의 빈자리.
2. **세로줄기 일괄 부리 · 커브** — 중심선 → 잉크 단계에 얹는 새 규칙 층. 대상은 `direction: 'vertical'` 획이고, `기둥`만 고를지 세로줄기 전부일지는 그때 정한다. 부리는 열린 머리에만 단다. 커브는 중심선에 주고 `seed + 세기`만 저장해서, 마음에 드는 모양이 나오면 그 seed를 일괄 적용한다. 형태 규칙 패널 7.2의 부리 메모(지금은 글자에 반영 안 됨)가 입력 자리 후보.
3. **그룹 제안** — 이용제 닿자 분류는 `ReferenceGroupLabPage` 안 상수로만 있다. 공용 데이터로 꺼내 `전역 < 그룹 < 이 자모 < 이 획` 층의 둘째 칸으로 쓴다. 홀자 줄기 그룹은 따로 만들어야 한다.
4. **레이아웃별 전역 값** — 같은 층에 `이 레이아웃` 칸을 끼운다. 유료 후보. 굵기와 기울기는 여기서도 열지 않는다(굵기는 원칙 `두께는 고정`과 부딪히고, 기울기는 한 문장 안에서 각도가 흔들린다). 후보는 네모꼴과 부리 · 커브.

## 진행 기록

### 2026-09-21
- **사실**: 플랜 작성. 코드 변경 없음. 위 `지금 상태`는 grep으로 확인한 것이고 화면에서 돌려 본 것은 아니다.
- **사실**: 처음 답변에서 "전역 스타일 조절판이 자소 탭에 없다"고 했는데 틀렸다. `/workspace/jamo`가 `CalibrationSentenceEditor chrome="workspace"`를 그리고 거기에 패널이 달려 있다(명세 2.5 · 8번).
- **사실 (결정)**: 전역 값을 다 만들어 두고 일괄만 여는 대신, 읽는 길만 `getEffectiveStyle` 하나로 모으고 레이아웃별 값 · UI는 만들지 않기로 했다. 닫아 둔 기능도 전수 검증이 들고, 부리 · 커브 모양이 정해지기 전이라 레이아웃별 설계가 틀리기 쉽다. 출처: AI 제안, 사용자 승인.
- **사실**: 글자꼴 용어를 『타이포그래피 사전』 기준으로 고정하고 옵시디언 `어휘사전.md`에 적었다. 레포 문서 27개에서 `혼합중성 → 섞임홀자`, `세로 · 가로중성 → 세로 · 가로홀자`, `가로획 · 세로획 → 가로줄기 · 세로줄기`, ㅗ ㅜ의 `세로획 → 짧은기둥`으로 바꿨다(코드 블록과 백틱 안은 그대로). `CLAUDE.md` · `AGENTS.md` 용어 절에 규칙 두 줄 추가. 안 건드린 것: `docs/archive/`, 다른 세션이 열어 둔 플랜 셋, 옵시디언의 주간 · 아이디어 · 결정과 뒤집힘, 코드 주석과 식별자.
- **미결정**: `초성 · 중성 · 종성`(레포 문서 약 430건)은 코드 식별자 · 옛 화면 이름과 얽혀 있어 일괄로 못 바꿨다. 새로 쓰는 문서부터 `첫닿자 · 홀자 · 받침`으로 쓴다.
- **가설**: 기울기를 주면 편집 핸들 좌표와 잉크가 어긋날 수 있다. `SvgRenderer`는 children을 기울기 그룹 안에 그리지만 자소 편집의 직접 조작 오버레이가 모두 그 안에 있는지는 확인 전. G1에서 본다.
- **미결정**: 추출 경로가 둘로 보인다(`fontExportUtils`의 `effectiveStyle`과 src-next `fontExportStore`). 어느 쪽이 지금 `OTF 추출`에 물려 있는지 D0에서 확정.
- **미결정**: 8.1 네모꼴에는 이미 `현재 레이아웃` 범위가 있다. "전역 값은 일단 일괄만"과 어긋난다. 그대로 둘지, 뒤 단계 4와 함께 고급으로 옮길지.
