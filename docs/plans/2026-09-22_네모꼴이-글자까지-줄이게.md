# 네모꼴이 글자까지 줄이게

- **이번에 비교하는 것**: 네모꼴을 바꿀 때 글자 폭(글자 사이)만 바뀌게 둘지, 모델 상자로 그리는 글자도 틀을 따라 같이 줄게 할지.
- **이번 승인으로 바뀌는 것**: 기본 네모꼴(850 × 850)의 틀을 사용자 틀로 옮기는 선형 변환을 모델 상자에 얹는다. 화면(문장 · 획 편집 캔버스 · 글자 그림)과 OTF가 같이 바뀐다. 획 두께는 그대로다.
- **바뀌지 않는 것**: 기본 네모꼴에서의 모든 글자(변환은 항등), 모델 값과 레이아웃 Δ의 좌표(기본 틀 기준 그대로 저장), 스키마 배치(독립 자모 · 폴백), 글자 폭 계산.

## 게이트

| 게이트 | 닫는 조건 |
|---|---|
| D0 계약 | 변환은 `contextPlacementOf` 한곳(화면 · OTF 공용)의 맨 끝에서 한 번. `x' = 왼여백 + (x − 0.075) × (틀 폭 / 0.85)`, 세로도 같다. 중심선 상자만 옮기므로 두께 고정. 기본 네모꼴이면 같은 객체를 돌려준다. 레이아웃별 네모꼴은 그 글자의 유효 여백(`schema.padding`)으로 따로 먹는다. Noto 고스트는 같은 변환으로 옮겨 그리고, xor는 변환 전 자리끼리 견준다. |
| G0 대표 | `한`에서 가로 600 → 문장 글자가 좁아진다. 세로 650 → 키도 준다. 스크린샷. |
| G1 홀드아웃 | OTF: 네모꼴 600에서 한 · 를 · 뷁의 상자가 화면과 같고 가장자리 어긋남 1유닛 아래, 잉크가 글자 폭(600) 안에 든다. 획 편집 캔버스에서 글자 · 부품 상자 · 고스트가 같이 옮겨지고 xor가 기본과 같다. |
| G2 전수 | `tsc -b` · eslint · vitest 전부 · 셸 e2e. 11,172자 추출에서 잉크가 글자 폭을 넘는 글자 0. |
| G3 사용자 검증 | 사용자가 네모꼴을 돌려 보고 판정. |

## 진행 기록

### 2026-09-22
- **사실 — 원인**: `resolveContextBoxes`는 네모꼴 여백을 받지 않는다. 모델 상자는 늘 기본 틀 기준 em 좌표였고 네모꼴은 글자 폭만 바꿨다. OTF도 같아서 폭을 줄이면 잉크(약 0.06–0.94em)가 글자 폭을 넘어 **옆 글자와 겹쳤다**. 화면만의 문제가 아니었다.
- **사실 — 구현**: `src/services/designBodyPlacement.ts`(순수 함수: 상자 · 네 변 · SVG transform) + `contextPlacementOf`에서 한 번 적용, `referencePlacement`(변환 전 자리)를 같이 돌려준다. `FocusedGlyph`가 고스트를 같은 transform으로 그리고 xor는 변환 전끼리 견준다.
- **G0 · G1**: 스크린샷 확인(가로 600 · 세로 650, 획 편집 캔버스 xor 20% 유지). `otf-screen-parity`에 `네모꼴 가로 600` 추가 — 가장자리 0.21–0.28유닛, 글자 폭 600, 잉크가 폭 안. 단위 테스트 3개.
- **사실**: 옛 단독 화면 e2e `design-body.spec › 폰트 전체와 현재 레이아웃…`이 HEAD에서 깨져 있던 지점("네모꼴을 바꿔도 문장 글자가 안 바뀐다")은 이 수정으로 통과한다. 그 뒤 `초성·혼합중성만 별도 적용` 문구 기대값에서 멈추는데, 기본 선택 글자가 바뀐 뒤 안 고친 낡은 기대값이다(이번 작업과 무관).
- **사실 — 남의 실패**: vitest 3개 — `preset-candidate-source` · `vertical-vowel-gap-reference`(HEAD에서 이미), `screen-spec`(다른 세션이 추가한 `/global-style-preview` 주소가 명세 목록에 없음).
- **미결정 ①**: 레이아웃 모드 캔버스(`GlyphLayoutEditor`)는 `resolveContextBoxes`를 바로 읽어 **기본 틀 자리 그대로** 보인다. 보선과 Δ가 기본 틀 좌표라서다. 네모꼴을 바꾼 폰트에서는 위 문장과 캔버스의 글자 비율이 다르게 보인다. 캔버스 전체를 같은 변환으로 옮겨 그릴지(보선 포함)는 따로 정한다.
- **미결정 ②**: 다른 세션의 획 스냅 기준선(`baselineRails`, 미커밋)은 기본 틀 좌표다. 네모꼴을 바꾼 상태에서는 획 편집 캔버스의 점선과 글자가 어긋난다. 그 세션이 커밋한 뒤 같은 transform을 얹어야 한다.
- **안 한 것**: G2의 11,172자 전수 확인, 셸 e2e 전부.
