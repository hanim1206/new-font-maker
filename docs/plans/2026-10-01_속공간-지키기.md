# 속공간 지키기

- **이번에 비교하는 것**: 모든 획을 같은 배율로 굵게 하는 지금 대 최소 속공간 하한선을 지키며 굵게 하는 것
- **이번 승인으로 바뀌는 것**: 굵기를 올릴 때 자소 안 속공간이 하한선(= max(고정 u, 두께 × 비율)) 아래로 안 간다 — 넘는 자소만 자동으로 덜 굵다(자동 보정 층, 기본 켬). 이어서 가로줄기 비율 · 자소 사이 · 바깥/안 분배를 하나씩 얹고, 조합표로 확인한다
- **바뀌지 않는 것**: 굵기 400 · 기본 네모꼴의 모든 글자, 저장된 굵기 값과 획 데이터, 성긴 자소(ㅣ · ㄱ)의 굵기, 자동 보정을 끈 글자

## 왜

굵기 900이면 모든 획을 1.95배로 굵게 한다. ㅣ 한 획도, ㅃ · ㄹ처럼 획이 빽빽한 자소도 같은 배율이라 빽빽한 자소부터 막힌다(기본 가로 · 굵기 900에서 `빼` · `를` · `뷁`이 검은 덩어리가 된다, 10-01 사용자 스크린샷). 실제 굵은 폰트는 빽빽한 자소의 획을 덜 굵게 그린다. 좁힌 네모꼴에서 막히는 것도 같은 문제라, 이게 풀려야 네모꼴 범위(지금 86 ~ 106%)를 넓힐 수 있다.

지금 상태(자동 보정 켬, 3,724자 표본, 어림값 — 아래 `재는 법` 참고):

## 단계 (10-01 다시 짬 — 아래 진행 기록 `뒤집힘`)

단계마다 판단할 것은 하나다. 한 단계를 사용자가 확인한 뒤 다음으로 간다. 모든 단계의 공통 확인 그림은 문장 줄 `뷁 를 빼 쫓 이` — 전체 농도(회색도)가 고른가. 확인 화면은 네모꼴 실험실의 진행 지도.

1. **재는 법** — 닫힘(10-01). 진짜 잉크로 막힘 · 자소 안 닿음 · 자소 사이 닿음을 센다. 틈 기준 = 두께 × 1/4.
2. **최소 속공간** — 판단: 하한선 값(고정 u와 두께 비율).
   - `counterKeep`을 "원래 속공간의 몇 %"에서 "하한선 몇 u는 꼭 남긴다"로 바꾼다. 덜 굵게는 따로 고르는 게 아니라 하한선에서 나온다.
   - 얹는 층이다. `자동 보정` 스위치 하나가 같이 켜고 끈다. 저장되는 굵기는 그대로. 문장 · 레이아웃 캔버스 · 획 편집 · OTF가 같은 함수를 지난다 — 붙이기 전에 실효 스타일 입구를 한 곳으로 모으는 일(다른 세션)이 먼저다.
3. **가로줄기 비율** — 판단: 굵을수록 가로줄기를 세로줄기보다 얼마나 덜 굵게(노토 900: 1.88 / 1.95). 닫을 때 2단계 문장 줄을 한 번 다시 본다(확인만).
4. **자소 사이** — 판단: 굵어질 때 이웃 자소 쪽으로 어떻게 자라게 할지. 후보: 이웃을 마주 본 획만 덜 굵게 / 칸 변을 지키고 안쪽으로 / 칸끼리 자리 나누기.
5. **바깥/안 분배** — 필요할 때만. 기본값 = 노토 실측 0.47.
6. **조합표 확인** — 가로 3 × 굵기 4를 다시 재고 네모꼴 범위와, 좁을수록 최대 굵기를 낮출지 정한다.

**미결정**
- 오늘 넣은 네모꼴 보정(세로줄기만 얇게, 폰트 전체 하나)과 합칠지. 같은 문제를 폰트 전체 값과 자소별 값으로 따로 푸는 꼴이다. 2단계 뒤에 본다.
- 자소마다 굵기가 달라지면 한 글자 안에서 획 굵기가 들쑥날쑥해 보일 수 있다. 자소 하나 안에서는 같은 배율로 묶는 것부터 해 본다.
- 얇아진 획은 칸 변에서 조금 떨어진다(다시 맞추면 간격이 또 바뀐다). 처음엔 안 맞추고 얼마나 떨어지는지 잰다.
