# 변화량 모델 v1 설계

[2026-09-15_Noto-기준선-기반-프리셋-폰트-개발-플랜](./2026-09-15_Noto-기준선-기반-프리셋-폰트-개발-플랜.md) 3절의 `대표값 + 첫닿자 효과 + 홀자 효과 + 받침 효과 + 상호작용·예외` 가설을 실제 모델로 정한 기록. 전수 11,172자 후보와 두께 v1이 확보된 뒤의 다음 단계다.

## 결정

- **효과 단위는 자모.** a[ㄱ]·a[ㅋ]를 따로 든다. 그룹은 모델이 아니라 편집 UI 층에서 "ㄱ계 일괄" 슬라이더가 소속 자모 효과항에 같은 Δ를 뿌리는 브로드캐스트로 만든다. 모델에 그룹을 박으면 자모 개별 조정이 불가능해지는 비가역 결정이라 피한다. 쌍자음–평자음 같은 관계는 나중에 효과표 위에서 발견해 그룹 후보로 제안만 한다.
- **v1은 주효과만.** 상호작용은 넣지 않는다. 동시에 풀면 상호작용 셀이 주효과를 흡수해 `효과항 = 편집 단위`가 무너지고, 편집식의 Δ 정의가 꼬인다. 단순 합으로 설명 안 되는 차이는 예외층이 실측 보존으로 받아 화면 왜곡은 없다.
- **추정은 median polish.** 대표값 = 층 중앙값, 효과는 반복 중앙값 제거, 효과 중앙값 0으로 정규화. 평균 회귀는 중앙값 원칙을 깨서 쓰지 않는다.
- **6층 독립.** 세로/가로/혼합 × 무받침/받침. 기존 contextId 그대로.
- **타깃 = 역할면 하나.** 글자 통째 모델 없음. 순서는 첫닿밑선 → 홀자 face → 나머지 변·가시길이. 두께는 전역 스타일 매개변수라 모델 밖(v1 실측으로 충분).

## 예외층과 판정

`|잔차| > 임계` 글자는 모델로 덮지 않고 실측 보존 + 이유. 임계는 7u/10u/14u 세 안을 같이 출력하고 기본 10u. 층별 판정은 비율과 집중도를 같이 본다.

- 예외 > 5% 且 뭉침(특정 자모쌍 상위 10셀이 예외의 절반 이상) → 상호작용 v2 후보. 그 셀만 데이터 근거로 투입.
- 예외 > 5% 且 고르게 분산 → 임계 문제 또는 폰트 고유 변동.
- 예외 ≤ 5% → 실측 보존으로 종결.

뭉침 진단은 (첫닿,홀자)·(첫닿,받침)·(홀자,받침) 세 쌍의 셀별 잔차 중앙값·건수 top을 출력한다.

## 편집식

`편집 후 = 실측 + Σ(사용자가 바꾼 효과항 Δ)`. 예외 글자도 같은 식이며 잔차는 그대로 딸려간다. 편집량 0이면 실측 그대로.

## 검증과 한계

- 층별 10% 홀드아웃, 재현 오차 p95 보고. 홀드아웃이 어떤 자모 수준을 비우지 않게 한다.
- 층별 관측 수·자모당 관측 수 명시. 무받침 층은 첫닿자당 5~9관측이라 저신뢰 표기. 무받침 층은 셀당 관측 1개라 상호작용 자체를 추정할 수 없다.
- 역할면 간 잔차 상관은 v1에서 무시한다.
- 기존 ㄱ 앵커 차분 31,244건은 새 모델의 부분집합. 배치 보고서 생성은 유지하고 분석 소비자만 새 산출물로 바꾼다.

## 1차 실행 결과 · 2026-09-15

전수 11,172자, 타깃 24개(첫닿자·끝닿자 네 변, 홀자 역할 8종의 face·가시길이) × 6층 = 층 모델 96개. 22초. 검증은 Python 15개(정확 가산 복원, 이상치 격리, 정규화, 무받침 층 진단 불가, 뭉침·분산 판정, 임계 3안, 홀드아웃 결정성·수준 보존, 실제 corpus 4개) 통과.

구현 중 규칙 하나 보정: "상위 10셀"은 셀 수백 개 층 기준이라 셀이 적으면 자명하게 참이 된다. 상위 셀 수를 셀 수의 5%(최대 10, 최소 1)로 두고, 받침 수준이 하나거나 셀당 관측 1개인 쌍은 진단 불가로 표시했다. 큰 층에선 원래 규칙 그대로다(513셀→10, 171셀→9).

층 판정 분포: 예외 보존 28 · 임계 또는 폰트 변동 66 · 상호작용 후보 2.

홀드아웃 오차가 학습 잔차와 같아 과적합은 없다. 기둥선·첫닿윗선·받침밑선은 주효과만으로 종결 가능. 첫닿밑선·받침윗선·보선은 예외가 많다.

**판정 규칙이 놓치는 것.** 첫닿밑선 세로-받침 층은 상위 9셀이 예외의 19%라 규칙상 "분산"인데, 셀별 잔차 중앙값 상위 10개는 전부 10u를 넘는다(ㄷㅕ 17u·ㄴㅕ 19u·ㅎㄶ 24u·ㄱㅊ 22u). 구조가 있지만 셀이 171~513개라 소수 셀에 안 모이는 경우다. "상위 셀 예외 점유율" 대신 "|셀 중앙값| > 임계인 셀 수"를 뭉침 신호로 쓰는 안을 v1.1 결정 후보로 둔다. 산출물에는 두 지표가 다 있어 규칙만 바꾸면 된다.

**상호작용 후보 2건**은 모두 ㄱ계 × 특정 홀자 셀 전체(받침 27자 모두)가 튀는 사례다.
- 첫닿왼선 혼합-받침: ㄱㅢ·ㄲㅝ·ㅋㅘ·ㄱㅝ 등 셀 전체 +12~19u.
- 보선 가시길이 가로-받침: ㄱㅗ·ㄱㅛ·ㄲㅗ·ㄲㅛ 셀 전체 +80~170u. 크기로 보아 상호작용이 아니라 ㄱ 다리와 ㅗ 보의 접합에 따른 가시 구간 형태 전환이다. 실제 윤곽 확인 대상.

다음: 뭉침 신호 v1.1 결정, 상호작용 후보·ㄴㄷ×ㅕ 예외의 윤곽 확인, corpus 랩 진척 패널에 변화량 모델 판정 표시.

## 검수판 겹쳐보기 (단계 B, 최신)

글자 상세에서 실측 첫닿밑선(주황 실선) 위에 모델 예측(보라 점선)을 같은 좌표계로 겹치고, 실측·예측·잔차·예외 여부를 수치 패널로 보여준다. 예측은 대표값 + 첫닿·홀자·받침 효과, 임계 초과 잔차는 예외로 표시만 하고 실측을 덮지 않는다. 모델 JSON은 글자 상세에서만 지연 로드하고 추출 단계 키가 다르면 붙이지 않는다. 커밋 f82d3a4. "10u가 눈에 보이나"를 실제로 답한다: 걫 +47u는 명확히 벌어지고 대부분 글자는 점선·실선이 거의 겹친다.

## 껴 추출 버그 수정 (최신)

첫닿밑선 예외 최상위 껴(+145)는 모델 문제가 아니라 추출 버그였다. Noto 껴는 ㅕ 세로기둥이 동일 윤곽 둘(c0·c7)로 그려져 있어, 홀자가 c0만 evidence로 잡고 중복 c7이 첫닿밑선(958, baseline 아래)으로 샜다. 홀자 윤곽과 좌표·부호면적이 같은 중복 윤곽을 첫닿자 후보에서 제외하는 가드를 추가했다. 전수 스캔에서 이 누수는 껴 1자뿐이라 영향이 고립됐다.

- 껴 실측 958 → 812.5(끼와 동일), 잔차 145 → 0. baseline 아래 글자 0.

- audit의 미배정 검사와 회귀 테스트 회계도 같은 중복 관용을 반영. audit 이슈 0, 블록은 넖·덢 2자 그대로.
