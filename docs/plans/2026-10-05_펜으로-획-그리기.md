# 펜으로 획 그리기

- **이번에 비교하는 것**: 애플펜슬로 그은 선을 앵커 몇 개의 중심선 획(`StrokeDataV2`)으로 바꾸는 단순화의 허용오차 `ε`. 같은 손그림에서 앵커 수와 모양 이탈을 잰다.
- **이번 승인으로 바뀌는 것**: 실험실 화면 하나(`/admin/labs/pen-lab`)와 순수 함수 둘(점 줄이기 · 곡선 맞춤). 제품 편집기 · 생성 엔진 · 저장 데이터는 그대로다.
- **바뀌지 않는 것**: 획 모델(중심선 + 베지어 앵커 + 두께 고정), 자모 → 음절 배치, 프리셋, 내보내기.

## 왜

지금은 프리셋 획을 옮기고 구부려서 자모를 만든다. 아이패드에서 선을 바로 그으면 처음 만드는 사람에게 훨씬 쉽고, 제품 철학(글자를 만드는 행위와 재료의 느낌까지 설계)에도 맞는다. 저장 구조는 이미 손그림을 받기에 맞다 — 그은 선을 앵커 몇 개로 줄이면 그대로 `StrokeDataV2`가 된다.

엎을 것은 없지만 두 가지는 새로 만들어야 한다.
- 펜 입력 자체. 손바닥 거부, 그리는 동안 스크롤 막기, 펜만 받기.
- 중심선용 단순화. `contourSimplify.ts`는 내보낼 때 윤곽(닫힌 다각형)만 줄이는 것이라 못 쓴다. 열린 선을 직선 · 곡선으로 나누고 3차 베지어로 맞추는 함수가 따로 필요하다.

진짜 위험은 그리기 뒤다. 생성 엔진은 획마다 역할(가로 · 세로 · 기둥 · 보 …)과 보선 자리를 보고 음절마다 자모를 맞춘다. 손으로 그은 획에는 이 정보가 없어서 다른 음절로 퍼질 때 어긋날 수 있다. 이 플랜은 그 앞까지만 한다. 역할 붙이기는 다음 플랜.

## D0 계약 초안

- **한 값**: 곡선 맞춤 허용오차 `ε`(0–1 정규화, 자모 상자 기준). 후보 0.005 · 0.01 · 0.02. 그은 선이 맞춘 곡선에서 `ε`를 넘게 벗어나지 않는다.
- **입력**: `pointerType === 'pen'`만. 손가락은 화면 이동, 손바닥은 무시. 압력 · 기울기는 받되 쓰지 않는다(저장 안 함).
- **출력**: 한 번 긋기 = 획 하나. `closed: false`, 두께는 자모의 다른 획과 같은 값. 앵커는 `handleIn/Out`가 있는 3차 베지어, 곧은 구간은 핸들 없음.
- **단계**: ① 가까운 점 합치기(최소 간격) → ② 꺾임점 찾기(각도 문턱) → ③ 꺾임점 사이를 각각 직선 또는 3차 베지어로 맞춤(최소제곱, `ε` 넘으면 쪼갬).
- **자리**: 실험실 `/admin/labs/pen-lab`. 빈 자모 상자 하나, 왼쪽에 그은 원본 점, 오른쪽에 맞춘 획 겹쳐 그림, 앵커 수 · 최대 이탈 숫자. 제품 편집기에는 안 붙인다.
- **안 하는 것**: 획 역할 자동 판정, 보선 스냅, 꺾임점에서 획 자동 분리, 백지 시작 제품 진입점, 압력 → 두께. 전부 다음 플랜 후보.
- **미결정**: 꺾임 각도 문턱(G0에서 `ε`와 같이 본다. 변수는 `ε` 하나로 두고 문턱은 고정값 하나로 시작), 한 번 긋기를 꺾임점에서 여러 획으로 나눌지.

## 게이트

| 게이트 | 무엇을 | 통과 기준 |
|---|---|---|
| D0 | 위 계약 승인 | 사용자 승인 |
| G0 대표 | 데스크톱 마우스 + 아이패드 펜으로 획 10종(가로 · 세로 · ㄱ꺾임 · ㅅ삐침 · ㅇ 비슷한 호 · S자 · 짧은 점 · 긴 대각선 · 떨린 가로 · 빠른 가로). `ε` 셋을 앵커 수 · 최대 이탈로 표 | 앵커 수가 프리셋 획과 비슷한 급(직선 2, 꺾임 3, 호 4–5). 최대 이탈 ≤ `ε`. 겹쳐 그림에서 떨림이 사라지고 의도한 꺾임은 남는다 |
| G1 홀드아웃 | 사용자가 아이패드로 자모 5개(ㄱ ㄴ ㅅ ㅇ ㅏ)를 전부 그음. 녹화한 점을 고정 입력으로 저장해 테스트로 둔다 | 자모마다 획 수가 맞고, 앵커 수 · 이탈이 G0 기준 안 |
| G2 전수 | 녹화한 입력을 전부 `ε` 기본값으로 다시 돌림 | 예외 0 · 빈 획 0 · 각 입력 10ms 안 |
| G3 사용자 | 아이패드에서 손맛 확인. 선이 늦게 따라오거나 손바닥에 찍히지 않는지 | 사용자 확인 |

## 확인 질문

1. 어디부터: **실험실 먼저**(추천) / 제품 편집기 `선 추가` 옆에 바로.
2. 한 번 긋기: **획 하나**(추천, ㄱ도 한 획) / 꺾임점에서 자동 분리.
3. 백지 시작: **이번엔 실험실 안에서만**(추천) / 제품 진입점까지(사용자 경험 변경이라 따로 결정).
