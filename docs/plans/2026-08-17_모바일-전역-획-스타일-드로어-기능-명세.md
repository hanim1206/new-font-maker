# 모바일 전역 획 스타일 드로어 기능 명세

관련 문서: [2026-08-17_모바일-자소-캐러셀-편집](./2026-08-17_모바일-자소-캐러셀-편집.md), [2026-08-17_모바일-트랙패드-편집](./2026-08-17_모바일-트랙패드-편집.md), [2026-08-17_도구-물성-기반-획-스타일](./2026-08-17_도구-물성-기반-획-스타일.md)

## 해결할 문제

모바일에서 폰트 전체의 획 인상을 바꾸면서도 현재 글자 문맥을 떠나지 않고 여러 자소 조합에 결과를 대봐야 한다. 별도 전체 화면 편집기는 이동 비용과 옵션 복잡도를 늘리므로, 기존 캐러셀 아래의 편집 드로어를 전환해 짧고 되돌릴 수 있는 흐름을 만든다.

## 목표

- 사용자가 현재 글자와 활성 파트를 유지한 채 전역 획 스타일을 조절한다.
- 원형과 납작형의 차이를 여러 글자 조합에서 즉시 확인한다.
- 한 번의 연속 조작을 한 번의 변경으로 저장하고 과거 상태와 비교·복원한다.
- MVP에서 선택지와 적용 범위를 제한해 결과를 예측하기 쉽게 한다.

## 전체 흐름

`자소 캐러셀·트랙패드 → 획 스타일 드로어 → 캐러셀로 여러 글자 확인 → 필요할 때 비교·히스토리 → 드로어 닫기 → 이전 트랙패드 상태 복원`

## 화면 상태

### 1. 기본 트랙패드

- 중앙 글자에서 파트·획·조절점을 선택한다.
- 하단 드로어에는 선택 대상을 이동하는 트랙패드가 보인다.
- 상단의 `획 스타일` 버튼으로 같은 화면 안에서 드로어 내용을 전환한다.

### 2. 획 스타일 드로어

- 헤더에 `획 스타일 · 폰트 전체에 적용`을 고정 표시한다.
- `원형`과 `납작형` 중 하나를 선택한다.
- 원형에서는 추가 조절 항목을 숨긴다.
- 납작형에서는 `납작함`과 `각도`만 노출한다.
- 납작함 값은 조작 중에만 표시한다.
- 각도는 가로축 기준 `-90°~+90°`, 기본 `0°`다.
- 원형으로 바꿔도 마지막 납작함과 각도를 기억하고, 납작형으로 돌아오면 복원한다.
- 상단 캐러셀은 기존 규칙을 유지한다. 활성 파트만 바뀌고 나머지 파트는 고정된다.
- 캐러셀에 나타나는 모든 글자는 현재 전역 획 스타일의 실시간 미리보기다.
- 대표 글자 `가 · 공 · 한 · 흘`을 통해 직선·곡선·사선·교차부·받침 밀도를 확인한다.

### 3. 비교·히스토리 전체 화면

- `변경 전과 비교`는 획 스타일 편집기 진입 시점과 현재 상태를 나란히 보여준다.
- 히스토리는 시간, 변경 항목, 이전 값과 현재 값, 적용 범위 `폰트 전체`를 표시한다.
- 과거 상태 복원은 현재 기록을 지우지 않고 새로운 변경 항목으로 남긴다.
- 뒤로 가면 획 스타일 드로어와 직전 미리보기 상태로 돌아온다.

## 저장 규칙

- 슬라이더를 움직이는 동안에는 미리보기만 갱신한다.
- 손을 떼면 실제 값이 달라진 경우에만 변경 한 건을 저장한다.
- 값이 바뀌지 않은 조작은 히스토리에 남기지 않는다.
- 원형·납작형 전환도 실제 상태가 바뀌면 변경 한 건으로 저장한다.
- 조작이 취소되거나 처리에 실패하면 마지막 확정 상태로 돌아가며 실패한 변경은 기록하지 않는다.
- 드로어를 닫으면 열기 전의 파트·획·조절점 선택과 트랙패드 상태를 복원한다. 전역 획 스타일 변경은 유지한다.

## MVP 필수 요구사항

- [ ] 현재 자소 캐러셀 화면을 유지한 채 하단 드로어만 전환된다.
- [ ] 적용 범위가 선택 불가능한 문구로 명확히 표시된다.
- [ ] 원형과 납작형을 선택할 수 있다.
- [ ] 납작형에서 납작함과 고정 각도를 조절할 수 있다.
- [ ] 조절 결과가 캐러셀과 대표 글자에 즉시 보인다.
- [ ] 캐러셀의 활성 파트 교체 규칙이 획 스타일 편집 중에도 유지된다.
- [ ] 연속 조작은 손을 뗄 때 한 번만 저장된다.
- [ ] 비교와 히스토리가 전체 화면으로 열린다.
- [ ] 드로어를 닫으면 이전 트랙패드 편집 상태가 복원된다.
- [ ] 실제 미리보기와 폰트 출력의 곡선·교차부·끝점은 끊김이나 돌기 없이 연속된 윤곽을 만든다.

## 인수 조건

- 초성 `ㄱ`이 활성화된 `곰`에서 획 스타일 드로어를 열고 캐러셀을 넘기면 `놈·돔·롬`처럼 초성만 바뀌고 같은 획 스타일이 모두 적용된다.
- 중성 `ㅗ`가 활성화된 `곰`에서는 `곰·굠·굼`처럼 중성만 바뀐다.
- 납작형에서 슬라이더를 연속으로 움직이면 미리보기는 계속 바뀌지만 손을 떼기 전에는 히스토리가 추가되지 않는다.
- 납작형 설정 뒤 원형으로 전환했다가 다시 납작형으로 돌아오면 마지막 납작함과 각도가 복원된다.
- 획 스타일 드로어를 닫으면 열기 전에 선택했던 획과 조절점으로 돌아가며, 확정된 전역 스타일은 유지된다.
- 과거 상태를 복원한 뒤에도 복원 전 기록을 확인할 수 있다.

## 제외 범위

- `획 따라가기`: 급커브와 교차부의 출력 품질을 먼저 검증해야 한다.
- 압력·속도·끝맺음·세리프: 방향과 시간에 따른 입력 모델을 별도로 정의해야 한다.
- 개별 획 오버라이드: 폰트 전체 적용만으로 부족하다는 사용 근거가 생긴 뒤 검토한다.
- 브러시 크기: 기존 전체 획 굵기와 역할이 겹치므로 추가하지 않는다.
- 별도 획 스타일 전체 화면: 드로어가 감당하지 못할 만큼 옵션이 늘어날 때만 재검토한다.
- 어니언 스킨과 아웃라인 직접 편집: 현재 모바일 MVP에서 제외한다.

## 검증 기준

- 사용자가 설명 없이도 적용 범위가 `현재 글자`가 아니라 `폰트 전체`임을 구분하는가.
- 드로어 전환 뒤에도 캐러셀에서 어떤 파트가 바뀌는지 혼동하지 않는가.
- 원형·납작형과 두 조절값만으로 원하는 인상 차이를 만들 수 있는가.
- 비교와 히스토리를 통해 변경을 안심하고 되돌릴 수 있는가.
- 대표 글자 미리보기와 실제 출력 사이에 눈에 띄는 윤곽 차이가 없는가.

## 상태 구분

- **결정**: 하단 드로어 전환, 폰트 전체 적용, 원형·납작형, 납작함·고정 각도, 자동 저장, 전체 화면 비교·히스토리.
- **가설**: 대표 글자 네 개와 현재 캐러셀만으로 전역 결과를 판단하기에 충분하다.
- **미결정**: 고정각 납작 붓촉의 윤곽 생성 방식, 미리보기와 OTF·TTF 출력이 같은 모델을 공유하는 방법.

## 다음 단계

이 명세를 기준으로 개발 항목을 상태 모델, 드로어 UI, 미리보기 연결, 저장·히스토리, 윤곽 생성 기술 실험 순서로 나눈다. 윤곽 생성 방식은 화면 기능 구현과 분리해 먼저 작은 기술 검증을 거친다.
