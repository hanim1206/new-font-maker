# 덱 셋 내비 개편 — 홈 › 폰트 › 획

- **이번에 비교하는 것**: 지금의 `☰ 메뉴 + 톱니 + 레이아웃 하단 바`를 두는지, 덱 셋(내 폰트 → 폰트 → 획)이 눈에 보이는 셸로 바꾸는지.
- **이번 승인으로 바뀌는 것**: 햄버거 · 톱니 · 레이아웃 하단 바 · 떠날 때 묻기가 사라진다. 머리 왼쪽은 `‹ 상위 이름`, 가운데는 지금 층 이름. 폰트 덱에 하단 탭 셋(폰트 · 자소 · 검수). `폰트` 탭이 글로벌 스타일 + 폰트 정보 대시보드. 획 덱은 폰트 덱 위에 얹히는 시트. 보선을 옮기면 켜진 옵션에 바로 저장. 화면 이동이 새로고침 없이 되어 되돌리기 기록이 남는다. dev에도 홈이 뜬다.
- **바뀌지 않는 것**: 편집 화면 속 내용(캔버스 · 전파 카드 · 오버라이드 띠 · 검수 격자), 저장소와 저장 형식, 글로벌 스타일 탭 넷, OTF 추출 로직, 주소 `/fonts` · `/workspace/jamo` · `/workspace/review`. 조합별 보정 차트는 이 플랜 밖(대시보드 아래 자리만 남긴다).

배경: 홈(`/fonts`)은 어제 생겼는데 입구가 `☰` 맨 아래 `내 폰트`뿐이라 "홈이 있다"가 안 보인다. `☰`는 화면 이동 · 폰트 동작 · 계정이 한 통에 섞여 있고, 글로벌 스타일은 라우트가 아니라 레이아웃 화면 위에 덮는 상태라 획 덱에서도 튀어나온다. 자소↔검수가 `<a href>` 새로고침이라 되돌리기 기록이 사라진다(피드백 31). 레이아웃만 명시 저장이고 획은 이미 바로 저장이다(피드백 04의 "통일은 배포 후"가 이 플랜).

## 덱 셋

| 덱 | 화면 | 머리 왼쪽 | 머리 가운데 | 들어가는 법 | 나가는 법 |
|---|---|---|---|---|---|
| 1 홈 | `/fonts` 내 폰트 목록 · 새로 만들기 · 이름 · 삭제 · 로그아웃 | 없음 | `내 폰트` | 로그인 · 앱 열기 | — |
| 2 폰트 | 하단 탭 `폰트` · `자소` · `검수` | `‹ 내 폰트` | 폰트 이름 | 목록에서 폰트 선택 (옆으로 밀려 들어감) | `‹` |
| 3 획 | 획 편집 (폰트 덱 위에 시트로 얹힘, 뒤에 폰트 화면 머리가 살짝 남음) | `‹ 폰트 이름` | `ㄱ 획` 처럼 자모 | 캔버스의 켜진 상자 재탭 · 모서리 칩 | `‹` = 지금의 `완료` |

`☰` 항목의 새 자리: 자소 · 검수 → 하단 탭. OTF 추출 → `폰트` 탭 주 버튼. 형태 규칙 → 획 덱 도구. 내 폰트 → `‹`. 로그아웃 → 홈. 남는 항목 없음 → 햄버거 삭제. 오른쪽은 되돌리기 · 다시 실행만.

`폰트` 탭(대시보드): 위에 문장 표본(지금 글로벌 스타일 공간의 140px 줄), 아래 글로벌 스타일 탭 넷(네모꼴 · 획 스타일 · 굵기 · 부리), 그 아래 이름 바꾸기 · 마지막 수정 · 마지막 추출 버전(1.00n) · `OTF 추출`. 차트 자리는 비워 둔다. 톱니로 열던 덮개 상태는 없앤다.

레이아웃 상시 저장: 보선을 놓는 순간 켜진 옵션(기본 = 같은 레이아웃 계열, 원칙)에 Δ 저장. 하단 바(복원 · 선택 옵션 · 신규 옵션) · 떠날 때 묻기 · 복원 제거. `신규 옵션`은 저장 뒤 오버라이드 띠의 칩에서 `다른 옵션으로 옮기기`로 남긴다. 되돌리기는 머리 undo 하나.

## 순서 (한 단계에 변수 하나)

1. 얇은 라우터 — `pushState` + `popstate`, 셸은 한 번만 뜨고 화면만 바뀐다. 되돌리기 기록 · Noto 모델 유지. (피드백 31 같이 닫힘)
2. 셸 머리 — `☰` → `‹ 상위 이름`, 가운데 층 이름, 하단 탭 셋. 햄버거 해체.
3. `폰트` 탭 — 글로벌 스타일 공간 승격 + 폰트 정보 + OTF 추출. 톱니 삭제.
4. 획 덱 얹기 — 시트 전환, `완료` → `‹`.
5. 레이아웃 상시 저장 — 하단 바 · 묻기 제거, 띠에 `옮기기`.
6. dev 홈 — 게이트 꺼진 서버도 `/fonts`가 뜬다(로컬 목록, 한도 3).

## 미결정
- 획 덱 시트가 남기는 폰트 화면 머리 높이(캔버스가 그만큼 준다). 후보 24~32px.
- 하단 탭 아이콘 · 이름 셋. `폰트`가 `홈`으로 읽히지 않게.
- 오버라이드 띠의 `옮기기` 모양 — 칩 길게 누르기? 칩 메뉴?
