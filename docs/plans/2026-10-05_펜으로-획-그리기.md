# 펜으로 획 그리기

- **이번에 비교하는 것**: 애플펜슬로 그은 선을 앵커 몇 개의 중심선 획(`StrokeDataV2`)으로 바꾸는 단순화의 허용오차 `ε`. 같은 손그림에서 앵커 수와 모양 이탈을 잰다.
- **이번 승인으로 바뀌는 것**: 실험실 화면 하나(`/admin/labs/pen-lab`)와 순수 함수 둘(점 줄이기 · 곡선 맞춤). 제품 편집기 · 생성 엔진 · 저장 데이터는 그대로다.
- **바뀌지 않는 것**: 획 모델(중심선 + 베지어 앵커 + 두께 고정), 자모 → 음절 배치, 프리셋, 내보내기.

## 왜

지금은 프리셋 획을 옮기고 구부려서 자모를 만든다. 아이패드에서 선을 바로 그으면 처음 만드는 사람에게 훨씬 쉽고, 제품 철학(글자를 만드는 행위와 재료의 느낌까지 설계)에도 맞는다. 저장 구조는 이미 손그림을 받기에 맞다 — 그은 선을 앵커 몇 개로 줄이면 그대로 `StrokeDataV2`가 된다.

엎을 것은 없지만 두 가지는 새로 만들어야 한다.
- 펜 입력 자체. 손바닥 거부, 그리는 동안 스크롤 막기, 펜만 받기.
- 중심선용 단순화. `contourSimplify.ts`는 내보낼 때 윤곽(닫힌 다각형)만 줄이는 것이라 못 쓴다. 열린 선을 직선 · 곡선으로 나누고 3차 베지어로 맞추는 함수가 따로 필요하다.

진짜 위험은 그리기 뒤다. 생성 엔진은 획마다 역할(가로 · 세로 · 기둥 · 보 …)과 보선 자리를 보고 음절마다 자모를 맞춘다. 손으로 그은 획에는 이 정보가 없어서 다른 음절로 퍼질 때 어긋날 수 있다. 이 플랜은 그 앞까지만 한다. 역할 붙이기는 다음 플랜.

## D0 계약 초안

- **한 값**: 곡선 맞춤 허용오차 `ε`(0–1 정규화, 자모 상자 기준). 후보 0.005 · 0.01 · 0.02. 그은 선이 맞춘 곡선에서 `ε`를 넘게 벗어나지 않는다.
- **입력**: 펜 · 손가락 · 마우스 전부(10-05 뒤집음, 아래 기록). 상자 안에서는 스크롤하지 않는다. 압력 · 기울기는 받되 쓰지 않는다(저장 안 함).
- **출력**: 한 번 긋기 = 획 하나. `closed: false`, 두께는 자모의 다른 획과 같은 값. 앵커는 `handleIn/Out`가 있는 3차 베지어, 곧은 구간은 핸들 없음.
- **단계**: ① 가까운 점 합치기(최소 간격) → ② 꺾임점 찾기(각도 문턱) → ③ 꺾임점 사이를 각각 직선 또는 3차 베지어로 맞춤(최소제곱, `ε` 넘으면 쪼갬).
- **자리**: 실험실 `/admin/labs/pen-lab`. 빈 자모 상자 하나, 왼쪽에 그은 원본 점, 오른쪽에 맞춘 획 겹쳐 그림, 앵커 수 · 최대 이탈 숫자. 제품 편집기에는 안 붙인다.
- **안 하는 것**: 획 역할 자동 판정, 보선 스냅, 꺾임점에서 획 자동 분리, 백지 시작 제품 진입점, 압력 → 두께. 전부 다음 플랜 후보.
- **미결정**: 꺾임 각도 문턱(G0에서 `ε`와 같이 본다. 변수는 `ε` 하나로 두고 문턱은 고정값 하나로 시작), 한 번 긋기를 꺾임점에서 여러 획으로 나눌지.

## 게이트

| 게이트 | 무엇을 | 통과 기준 |
|---|---|---|
| D0 | 위 계약 승인 | 사용자 승인 |
| G0 대표 | 데스크톱 마우스 + 아이패드 펜으로 획 10종(가로 · 세로 · ㄱ꺾임 · ㅅ삐침 · ㅇ 비슷한 호 · S자 · 짧은 점 · 긴 대각선 · 떨린 가로 · 빠른 가로). `ε` 셋을 앵커 수 · 최대 이탈로 표 | 앵커 수가 프리셋 획과 비슷한 급(직선 2, 꺾임 3, 호 4–5). 최대 이탈 ≤ `ε`. 겹쳐 그림에서 떨림이 사라지고 의도한 꺾임은 남는다 |

| G2 전수 | 녹화한 입력을 전부 `ε` 기본값으로 다시 돌림 | 예외 0 · 빈 획 0 · 각 입력 10ms 안 |
| G3 사용자 | 아이패드에서 손맛 확인. 선이 늦게 따라오거나 손바닥에 찍히지 않는지 | 사용자 확인 |

## 확인 질문

1. 어디부터: **실험실 먼저**(추천) / 제품 편집기 `선 추가` 옆에 바로.
2. 한 번 긋기: **획 하나**(추천, ㄱ도 한 획) / 꺾임점에서 자동 분리.
3. 백지 시작: **이번엔 실험실 안에서만**(추천) / 제품 진입점까지(사용자 경험 변경이라 따로 결정).

## 앞단에 붙일 때 걸리는 것 (10-05 점검, 코드 조사 기준)

엔진은 획의 `label`을 안 읽는다. 대신 **획 id**(`ㅏ-1` 같은 프리셋 id)와 **첫 점 · 끝 점**, **획 범위**로 판단한다. 펜 획은 id가 `stroke-<시각>`이라 전부 "이름 없는 자유 획"이 된다.

| # | 걸리는 곳 | 무슨 일이 나나 | 개선 |
|---|---|---|---|
| 1 | 홀자 줄기 ↔ 보선 (`stemAttach.ts` · `medialStemRails.ts` · `stemBend.ts`) | 이름 없는 획은 기둥 · 보에 안 붙고 저장 좌표 그대로. 얇은 칸(ㅣ 폭 0.013em, ㅡ · ㅢ 가로부 높이 0)을 넓혀 주는 것도 꺼져 **가로 휨이 납작하게 짓눌린다** | 그은 획에 **역할 이름을 붙이는 단계**(프리셋 획 수와 같으면 위치 · 방향으로 자동 대응, `survivingStrokeId`로 id 승계). 못 맞추면 사용자가 "이게 기둥" 고르기 |
| 2 | 섞임홀자 가로부 · 세로부 | 기하로 안 나누고 id 집합으로 나눈다. 새 획은 **무조건 세로부**(편집기) 또는 가로부(모바일). ㅘ의 '오'가 폭 0.2em 칸에 들어가 찌그러짐 | 섞임홀자는 **부분별로 따로 그리게**(ㅗ 먼저, ㅏ 다음) 하거나 그은 획의 범위로 채널 자동 분류 |
| 3 | 자모 칸이 획에서 나온다 (`notoComponentFit.ts` `componentBoxFromFaces`) | `frame`이 없으면 그은 획의 범위가 곧 칸 → 축별로 따로 늘어나 **문맥마다 비정방으로 찌그러짐**. 열린 획은 비율 핸들 보정도 없다 | 펜 입력 직후 **frame을 굳힌다**(첫 수정 때처럼). 그리는 상자 자체를 그 자모의 기본 칸 비율로 보여 주면 사용자가 칸에 맞춰 그린다 |
| 4 | 문맥 오버라이드 · 계열 획 (`overrideResolver.ts` · `jamoContextStrokes.ts`) | variant는 획 배열 통째 스냅샷. 펜으로 다시 그려도 **옛 오버라이드 글자는 옛 획 그대로**. `contextualInkSafety`는 id · 점 수가 바뀌면 보정을 조용히 지움 | 펜으로 자모를 새로 그리면 그 자모의 오버라이드 · 문맥 보정을 **비우고 알린다**("문맥 조정 N개가 초기화돼요") |
| 5 | 두께 · 틈 보호 (`counterKeep.ts` · `inkGapGuard.ts`) | 칸 여백은 최대 두께 하나로 계산. 닫히지 않은 ㅇ(시작 · 끝이 조금 벌어짐)은 이음매를 "틈"으로 잡아 자소가 얇아질 수 있음. 겹쳐 그은 획은 O(n²) 비용 | 두께는 자모 공통 하나로 강제(이미 모델). 시작 · 끝이 가까우면 **닫힌 획으로 자동 합치기**(ㅇ · ㅁ · ㅂ 판정) |
| 6 | 꺾임 · 머리 (`strokeGrammar.cornersOf` · `stemBeak.ts`) | 핸들 있는 앵커는 꺾임으로 안 봄. 곡선과 이어진 꺾임에 부리가 안 붙거나 엉뚱한 데 붙음. 삐침 끝 꼬리가 끝 모양 방향을 돌림 | `fitPenStroke`의 `corners`를 앵커에 표시(핸들 없는 꺾임으로 저장). 끝 꼬리는 끝 `span` 안에서 잘라내기 |
| 7 | 획 방향 | 이름 있는 홀자 획은 `points[0]`이 위 · 왼쪽이어야 보선 끝이 안 뒤바뀜 | 역할 붙일 때 방향을 기본 획과 맞춰 **뒤집어 저장** |
| 8 | 빈 자모 | 렌더는 안 터지지만 문맥 모델이 `'앱 획이 없습니다'`로 실패 → 그 자모가 든 **모든 음절이 스키마 배치로 조용히 되돌아감**. 내보내기에서 글리프가 빠짐 | 백지 시작은 "그리는 중" 상태로 두고, 획이 0개인 자모는 미리보기 · 내보내기에서 **프리셋 획으로 대체 + 표시** |
| 9 | id 충돌 | `stroke-${Date.now()}`를 두 곳이 써서 같은 ms에 겹칠 수 있음 | 자모 안 순번 id(`pen-<자모>-<n>`) |

가장 큰 둘은 1(역할 이름)과 3(칸). 둘 다 "그린 뒤 엔진이 알아서"보다 **그리기 전에 칸과 획 순서를 안내**하는 쪽이 싸다 — 프리셋 획을 연한 고스트로 깔고 그 위에 한 획씩 따라 긋게 하면 역할 · 순서 · 방향 · 칸이 한 번에 맞는다. 그 뒤 "고스트 없이 자유롭게"를 고급 선택지로.
