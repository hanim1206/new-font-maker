# 숫자 · 기호 획 편집 — 대시보드 › 기호 홈 › 도마 › 편집기

- **이번에 비교하는 것**: 숫자 · 기호를 노토 윤곽 그대로 두는지(지금, 한글날 판), 자소처럼 획으로 만들어 글로벌 스타일을 따르게 하는지.
- **이번 승인으로 바뀌는 것**: 대시보드 맨 아래 `숫자 · 기호` 섹션, 기호 홈(`/dashboard/symbol`), 도마의 새 종류 `symbol`, 편집기가 기호 하나를 캔버스에 올림, 폰트 데이터에 `symbols` 칸(FontData 1.6). 획으로 만든 기호만 OTF · 미리보기에서 노토 대신 획으로 그린다.
- **바뀌지 않는 것**: 한글 자소 저장 형식과 편집 동작, 레이아웃 · 검수, 아직 획으로 안 만든 기호는 노토 윤곽(한글날 판 그대로), 띄어쓰기 폭 220.

배경: 한글날 판은 노토 산스 KR의 ASCII 94자를 굵기 · 기울기 · 자간에만 맞춰 넣는다. 붓 · 둥글기 · 부리를 바꾸면 한글만 바뀌고 숫자는 그대로라 문장에서 따로 논다.

## 흐름

| 화면 | 보이는 것 | 들어가는 법 |
|---|---|---|
| 대시보드 | 맨 아래 `숫자 · 기호` 요약 줄(앞 4장 · 손댄 n) | 스크롤 · 왼쪽 레일 |
| 기호 홈 | 묶기 칩(숫자 · 문장부호 · 괄호 · 수학 · 영문) + 4열 판. 카드 탭 = 담기, 칩 = 그 묶음 도마에 | 요약 줄 |
| 편집기 | 도마 칩 줄 · 캔버스에 기호 하나 · 아래 전파 문장(`2026년 10월 9일, 3:00!`처럼 한글 사이에 둔 문장) | 홈의 `n개 고치기` · 대시보드 기호 카드(하나만 도마에) |

자소와 같은 길이다. 도마는 폰트당 하나라, 기호를 올리면 자소 도마는 비워진다(지금 규칙 그대로).

## 데이터

- `symbols: Record<코드포인트, SymbolGlyph>` — `{ char, strokes: StrokeDataV2[], advance }`. 좌표는 0–1, 상자는 EM 높이 전체(밑선 0.88) × 그 기호 폭. 자소의 `JamoData`와 같은 획 모델이라 획 편집 도구를 그대로 쓴다.
- 없는 기호 = 노토. 기호 하나를 처음 열면 씨앗 획(직접 그린 기본 세트)을 노토 중심선에 맞춰(`centerlineExtract`) 채워 준다. 저장은 손을 댄 기호만.
- 폭: 숫자는 고정폭 하나(표 숫자), 기호는 기호마다. 자간은 한글처럼 오른쪽에 더한다.

## 글로벌 스타일

굵기(`weightToMultiplier`) · 기울기 · 붓 · 둥글기 · 꺾임은 한글과 같은 함수로. 부리는 1차에서 기호에 걸지 않는다(`1`의 머리 같은 건 따로 판단).

| 게이트 | 무엇 | 통과 기준 |
|---|---|---|

| G1 홀드아웃 | 나머지 숫자 `2`–`9` | 씨앗 손질 없이 중심선 맞춤만으로 노토와 어긋남이 G0 수준 |
| G2 전수 | 1차 범위 전부(숫자 10 + 문장부호 · 괄호 약 20) | 추출 오류 0, 스모크 통과, 사파리 엔진 확인 |
| G3 사용자 | 대시보드 → 기호 홈 → 도마 → 편집 → 받기 | 사용자가 직접 한 바퀴 |

## 정할 것 (D0에서)

1. 첫 획을 어디서: **씨앗 직접 그리기 + 노토 중심선 맞춤(추천)** / 처음부터 빈 캔버스.
2. 1차 범위: **숫자 + 기본 문장부호(추천)** / 영문까지.
3. 숫자 폭: **고정폭 하나(추천)** / 숫자마다.
