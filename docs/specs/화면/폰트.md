# 폰트

폰트 덱의 첫 화면. 이 폰트 하나에 대한 것이 모이는 자리 — 이름, 마지막 고친 날, 출력, 그리고 폰트 전체에 먹는 글로벌 스타일. 셸의 `폰트` 탭.
글로벌 스타일은 자소편집과 같은 편집기의 `style` 자리다 — 캔버스 없이 문장 줄이 140px로 자라 미리보기를 맡고, 되돌리기는 셸 머리(자소편집 1.2와 같은 기록). 플랜: `docs/plans/2026-09-25_덱-셋-내비-개편.md`.

## 1. 폰트 정보
- 1.1 이름 — 지금 연 폰트 이름. 바꾸기는 내폰트 2.2
- 1.2 마지막 고침 — 서버가 마지막으로 받은 때(오늘 · 어제 · N일 전). 게이트가 꺼진 개발 서버에서는 없다

## 2. 출력
- 2.1 OTF 추출 — 폰트 이름을 묻는 창을 거쳐 지금 작업을 폰트 파일로 내려받는다. 진행 · 완료 · 실패가 버튼에 뜬다. 자소편집 `…` 메뉴에 있던 것이 여기로 왔다

## 3. 문장 표본
- 3.1 큰 문장 줄 — 보정 문장이 한 줄 · 가로 스크롤 · 140px. 글로벌 스타일을 끄는 동안 여기서 미리 보인다. 글자를 누르면 밑줄만 옮겨지고 편집은 열리지 않는다
- 3.2 문장 바꾸기 — 돋보기로 펼쳐 주사위 · 직접 입력(자소편집 3과 같다)

## 4. 글로벌 스타일
- 4.1 늘 열려 있다 — 닫기 없음. 탭 넷: 글자 네모꼴 · 획 스타일 · 굵기 · 부리. 각 탭의 내용은 자소편집 8절 그대로(8.1 네모꼴 막대 하나, 8.2 · 8.3 획 스타일과 둥글기 · 대비, 8.4 굵기, 8.5 부리)
- 4.2 되돌리기 — 손을 떼면 저장 + 기록 한 줄. 자소 탭으로 가도 기록이 남는다
