# 내 폰트

로그인하면 가장 먼저 보는 메인 화면. 내 폰트 목록과 `새 폰트 만들기`가 한 화면에 있다. 계정당 3개까지.
로그인 게이트가 꺼진 개발 서버에는 없다(`/fonts`는 자소편집으로 넘긴다). 플랜: `docs/plans/2026-09-25_계정-저장.md`.

## 1. 목록
- 1.1 폰트 줄 — 이름, 마지막 고친 날(오늘 · 어제 · N일 전 · M월 D일), 지금 연 폰트면 `지금 연 폰트`. 최근에 고친 것부터
- 1.2 열기 — 줄을 누르면 자소편집으로 간다. 다른 폰트로 갈 때는 지금 폰트의 못 올린 변경을 먼저 올리고, 못 올리면 가지 않고 알린다
- 1.3 개수 — 머리 오른쪽 `2 / 3`

## 2. 줄 메뉴
- 2.1 더 보기 — 줄 오른쪽 `⋯`
- 2.2 이름 바꾸기 — 그 자리에서 입력칸. 빈 이름은 안 받는다. 추출 창의 폰트 이름 기본값이 이 이름을 따른다
- 2.3 삭제 — 확인창 뒤 소프트 삭제(목록과 한도에서 빠지고, 되살리기는 관리자만). 지금 연 폰트를 지우면 사본도 버린다

## 3. 새 폰트
- 3.1 새 폰트 만들기 — 이름은 친구 아이디, 겹치면 `test1 2`. 기본 고딕에서 시작한다. 로그인 전에 이 기기에서 만든 작업이 있고 계정이 비었으면 그 작업이 첫 폰트가 된다
- 3.2 한도 — 3개면 버튼이 꺼지고 "하나를 지우면 새로 만들 수 있어요"

## 4. 계정
- 4.1 로그아웃 — 카드 아래. 못 올린 변경을 올리고 브라우저 사본을 지운다
