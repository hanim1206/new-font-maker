# 시작

앱을 열면 처음 오는 화면(`/`가 여기로 넘긴다). 첫 화면이 곧 학습 입구다 — 들어오자마자 줄기를 긋는다(입구 B안, 하니무스 2026-11-21). 제작 입구는 머리 오른쪽 단추로 대시보드에 간다.
기본 프리셋 위에 그리고, 아직 저장하지 않는다. 빚기 · 저장은 다음 단계에서 붙는다. 기획: 고양이 `학습-단계-뼈대-2026-11-20.md`. 긋는 판 · 퍼뜨리기는 획 긋기 시험판(`/pillar-lab`)과 같다.

## 1. 머리
- 1.1 이름 — `한글칸글`
- 1.2 보선 잡고 바로 만들기 — 제작 입구. 대시보드로(새로고침 없이)

## 2. 진행
- 2.1 막대 여섯 — 줄기 여섯(세로선 · 세로 짧은 선 · 가로선 · 가로 긴 선 · 대각선 · 동그라미). 지난 것 검정, 지금 것 주색
- 2.2 한도 줄 — `다 만들면 폰트 1개로 세요 · n개 남음`. 학습으로 만든 폰트도 한도에 센다. 다 찼으면 `폰트가 다 찼어요`, 목록을 못 읽으면 수 없이

## 3. 긋기
- 3.1 예시 글줄 — 기본 프리셋으로 쓴 한 줄. 방금 그은 줄기가 쓰인 획만 주색(다 그은 뒤엔 검정)
- 3.2 부탁 한 줄 — 무엇을 긋는지만(`세로로 길게 그어 보세요`). 이름은 긋고 나서
- 3.3 긋는 판 — 점선 길잡이. 손을 떼면 떨림을 지우고 글줄에 바로 퍼뜨린다. 다시 그으면 바꾼다
- 3.4 알림 — 맞으면 `방금 그은 게 기둥이에요` + `길이와 자리는 우리가 맞췄어요`. 방향 · 길이가 틀리면 고칠 말 한 줄
- 3.5 다음 — 그어야 눌린다. 마지막 뒤엔 `여섯 줄기를 다 그었어요`와 `처음부터 다시 긋기`
