# 조합별 결과 · ㄱ 초성

초성 ㄱ이 일곱 조합(ㄱ 가 고 과 각 곡 곽)에서 어떻게 나오는지 보고, 한 조합에서만 안쪽 기준선을 따로 보정하는 화면. ㄱ 고정.
**여기서 보정한 값은 앱의 글자와 폰트 추출에 닿지 않는다.** 형태 저장소에만 남는다.
주소: `?char=고`로 처음 볼 조합을 정한다. 일곱 자가 아니면 `가`. 카드로 바꿔도 주소는 안 바뀐다.

## 1. 셸
- 1.1 문장 보정으로 · 화면 이동 · 상태 표시 · 되돌리기 — `자소원형 1.1`과 같음. 상태에 `조합 비교` / `현재 조합 보정 중`이 더 있다

## 2. 머리
- 2.1 수정 범위 — 현재 대상 · 현재 행동 · 영향 표시. 범위 버튼은 늘 꺼져 있다
- 2.2 형태 시스템 상태 · 저장 결과 — `자소원형 2.2`와 같음

## 3. 결과 캔버스
- 3.1 결과 윤곽 — 고른 조합의 ㄱ 초성을 최종 윤곽으로 그린다. 형태 시스템이 없거나 못 풀면 앱의 지금 획으로 대신 그린다
- 3.2 기준선 핸들 — 보정 중일 때만 네 선이 뜬다. 끌거나 방향키(0.005씩)로 옮기고 손을 떼면 저장 · 형태 저장소. 잡는 순간 값이 손가락 자리로 뛴다

## 4. 조합 비교
- 4.1 조합 카드 일곱 장 — 누르면 관찰 대상이 바뀌고 보정 모드가 풀린다. **카드 그림은 앱의 지금 획이라 여기서 한 보정이 안 보인다**

## 5. 검토 액션
- 5.1 원형 보기 — `/workspace/jamo/master`
- 5.2 추천 기본 구조로 시작 — 형태 시스템이 없을 때만 · 형태 저장소
- 5.3 이 조합만 보정 — 보정 모드로 들어가고 서랍이 열린다. 막혀 있으면 사유가 아래에 뜬다. 보정 모드를 끄는 버튼은 없고 다른 카드를 눌러야 풀린다

## 6. 정밀 조절 서랍
- 6.1 기준선 고르기 · 값 슬라이더 — `자소원형 4.2` `자소원형 4.3`과 같되 이 조합에만 저장
- 6.2 출처 — 지금 값이 `자소 원형` / `역할 기본값` / `조합 기본값` / `이 자소에서 수정됨` 중 어디서 왔는지
- 6.3 기본값으로 — 이 조합의 보정을 지운다. 보정이 없으면 꺼짐 · 형태 저장소
- 6.4 잠금 안내 — 보정 중이 아니면 자물쇠와 사유만
