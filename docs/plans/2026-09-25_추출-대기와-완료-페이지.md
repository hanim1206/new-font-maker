# 추출 대기와 완료 페이지

- **이번에 비교하는 것**: 추출 버튼을 누르면 버튼에 스피너만 도는 지금과, 대기 화면(딤 · 퍼센트 · 엔진 렌더 예시) → 완료 페이지(진짜 폰트로 다시 그린 예시 · 다운로드 · 실패 글자)로 이어지는 것. 정할 변수 하나: **대기 중 예시를 엔진 렌더로 보여 줄지, 끝날 때까지 안 보여 줄지.** 추천은 엔진 렌더 → 완료 후 진짜 폰트로 전환.
- **이번 승인으로 바뀌는 것**: 추출 중 폰트 탭 위에 딤 층(퍼센트 + 템플릿 하나를 내 획으로 렌더). 끝나면 `/workspace/font/export` 완료 페이지 — 같은 템플릿을 방금 만든 OTF(`FontFace`)로 그리고, 다시 받기 · 버전 · 빠진 글자 목록. 추출기가 폰트 바이트와 빠진 글자 목록을 돌려주고, 저장소가 `done/total`을 버리지 않는다.
- **바뀌지 않는 것**: 윤곽을 만드는 방식, 자동 다운로드(끝나면 지금처럼 바로 내려받는다), 추출 이름 창, 버전 번호(1.00n), 실패 토스트, 굵기 트랙 파일(다른 세션).

## 지금 상태 (사실, 코드 확인 09-26)

- 진입점은 폰트 탭 `OTF 추출`(`FontWorkspacePage.tsx`, 덱 셋 개편 2·3번). `…` 메뉴는 없다. 이름 창(`FontExportDialog`)은 확인 즉시 닫히고, 추출 중엔 버튼 스피너 + 단계 글(`준비 중… / 글리프 데이터 수집 중… / 윤곽 변환 중… / 파일 생성 중…`)뿐이다.
- 진행률은 이미 나온다. `generateAndDownloadFont`의 `onProgress(done, total, phase)`가 100자 묶음마다 불리고(`processInChunks`, 묶음 사이 `setTimeout(0)`으로 화면에 양보) — 저장소가 `done/total`을 버리고 `phase`만 든다(`fontExportStore.ts:102`). 1단계(상자 풀기)가 십여 초, 3단계(파일 조립)는 동기라 그 사이엔 화면이 멈춘다.
- 폰트 바이트는 함수 안에서 `Blob` → `<a download>`로 내려가고 밖으로 안 나온다. `FontFace`로 그리는 곳은 없다.
- 빠진 글자(`skippedChars`)는 결과로 돌아오지만 저장소엔 토스트 글(`notice`)만 남는다. 목록은 안 남는다.
- 문장을 내 획으로 그리는 부품: `AppGlyph`(글자 하나, 저장소를 직접 읽음, 한글만). 검수 격자 · 범위 고르기에서 이미 쓴다.
- 하단 58px은 없다 — 탭 바가 차지한다(09-25). 대기 · 완료는 폰트 덱 안에서 푼다.

## 계약 (D0)

- **대기 층**: `status === 'exporting'` 동안 폰트 탭 위에 딤 층. 위에 퍼센트(단계별 가중치 없이 `done/total`을 그대로, 3단계는 `99% · 파일로 묶는 중`으로 서 있다 → 끝나면 100), 아래에 템플릿 하나 — 유튜브 자막 틀(검은 띠 위 흰 글 두 줄, 문구 고정)을 `AppGlyph`로 그린다. 문구는 받침 있는 글자 · 가로홀자 · 섞임홀자가 다 들어가게 고른다(빠진 글자가 있으면 템플릿에 구멍이 보이는 것도 정보). 한글 아닌 글자는 그냥 span. 닫기 없음(추출은 취소 못 한다, 지금도 그렇다).
- **저장소**: `progress: { done, total, phase }`, `lastExport: { revision, at, fileName, skippedChars, bytes } | null`(메모리만, 새로고침이면 사라진다). `generateAndDownloadFont`는 `ArrayBuffer`를 결과에 담아 돌려준다. 다운로드는 지금처럼 함수 안에서 바로.
- **완료 페이지** `/workspace/font/export`: 추출이 끝났을 때 **폰트 탭에 있으면** 라우터로 이동, 다른 탭이면 화면을 바꾸지 않고 토스트에 `완료 페이지 보기` 링크만(획을 만지는 중에 화면이 바뀌면 작업이 끊긴다). 같은 템플릿을 `new FontFace(\`${familyName}-${revision}\`, bytes)`로 등록해 진짜 폰트로 그린다("진짜가 됐다") — 이름에 버전을 넣어 같은 family로 두 번 등록해 옛 바이트를 붙드는 일을 막고, 페이지를 떠날 때 `document.fonts.delete`. 아래에 `다시 받기`(같은 바이트, 같은 이름) · 버전 `1.00n` · 파일 크기 · 빠진 글자 목록(있을 때만, 글자 칩을 누르면 자소 탭 `?char=`로) · 설치 안내 한 줄(`iPhone에서는 파일 앱에 저장한 뒤 컴퓨터에서 설치해요` — iOS는 폰트 설치가 안 된다). 머리는 `‹ 폰트`. `lastExport`가 없으면(새로고침) 폰트 탭으로 넘긴다. `screenRoutes` · 화면 명세 `폰트추출완료.md` 추가.
- **실패**: 지금처럼 에러 토스트, 완료 페이지로 안 간다. 빠진 글자가 있어도 폰트가 나왔으면 완료 페이지로 가고 목록에 보인다(토스트는 그대로).
- **쇼케이스 확장**은 이 페이지에 붙이되 이번엔 템플릿 하나만. 사용자 이미지 업로드 · 앱 전체 유저 폰트 렌더는 밖.

덱 셋 개편(`2026-09-25_덱-셋-내비-개편.md`) 남은 셋을 여기 끼운다. 각 단계는 제 플랜과 게이트 그대로.

5. 덱 4 — 획 덱을 폰트 덱 위에 얹기(`‹ 폰트이름`, 탭 숨김)

9. 아이콘 · 패턴 정리, 애니메이션

## 미결정
- 템플릿 문구(조합 골고루 — 받침 · 가로홀자 · 섞임홀자)와 폰트 크기. 자막 두 줄 · 28px 정도로 시작.
- 3단계(파일 조립) 동안 화면이 멈추는 것 — 워커로 빼는 건 이 플랜 밖(99%는 글로 알린다, 계약에 넣음).
