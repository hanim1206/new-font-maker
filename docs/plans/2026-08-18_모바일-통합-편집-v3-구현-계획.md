# 모바일 통합 편집 v3 구현 계획

관련 문서: [2026-08-18_모바일-통합-편집-v3-디자인-핸드오프](./2026-08-18_모바일-통합-편집-v3-디자인-핸드오프.md), [2026-08-17_모바일-트랙패드-편집](./2026-08-17_모바일-트랙패드-편집.md), [모바일 레이아웃 편집](./2026-08-17_모바일-글자-배치-편집.md)

4화면 와이어프레임과 이후 피드백을 다음 순서로 구현한다.

1. 현재 모바일 v2 변경 안정화와 컴포넌트 분리
2. 자소 편집과 레이아웃 편집의 데이터 귀속 분리
3. 같은 높이의 좌우 캐러셀, 자소 전체 → 획 → 점 선택, 문맥 카드
4. 선택 획을 화면 폭으로 확대한 상세 편집 화면
5. 트랙패드 `이동 | 비율`과 두 손가락 가로·세로 비율 조절
6. 기준선·패딩 전용 색상 트랙패드, 그리드 간격, 영향 글자
7. 전체 글자 그리드·검색·문장 검토 화면
8. 자동 저장·실행 취소·전체 히스토리·실기기 회귀 검증

자소 편집에서 자소 전체를 움직이면 `JamoData`의 기본형에 귀속한다. 레이아웃 편집에서 기준선이나 패딩을 움직일 때만 같은 레이아웃 유형 전체에 반영한다. 두 범위는 선택 상태와 고정 범위 문구로 분명히 구분한다.

트랙패드가 나오기 전의 초기 글자 선택 상태를 공통 진입점으로 쓴다. 자소를 선택하면 자소 편집 트랙패드가 열리고, `레이아웃` 진입 표시를 선택하면 같은 글자에서 분할선과 패딩 선택 상태로 전환한다. 레이아웃 전용 조절 UI는 실제 분할선이나 패딩을 선택한 뒤에만 연다.

획 상세 화면은 선택 획과 모든 점을 크게 보여준다. 획 선택 상태에서는 `이동 | 비율`을 명시적으로 전환하며, 비율 모드의 두 손가락 가로·세로 간격으로 획의 x·y 비율을 독립 조절한다. 굵기와 회전은 바꾸지 않는다.

레이아웃 화면의 하단 패드는 빈 트랙패드가 아니라 초성·중성·종성 영역, 기준선, 패딩이 보이는 직접 조절 뷰다. 선택한 기준선이나 패딩은 허용된 한 축으로만 움직이고 `0.5% · 1% · 2.5% · 5%` 그리드에 스냅한다. 아래에는 같은 레이아웃 유형의 영향 글자를 가로로 보여준다.

전체 글자 검토는 현재 데이터로 실제 렌더 가능한 글자만 계산한다. 글자 그리드에서 하나를 탭하면 메인 캐러셀로 돌아가고, 문장 탭에서는 조판 결과를 확인한다.

획 삭제와 스무스는 와이어프레임에 보이지만 파급과 복원 규칙이 확정되지 않아 첫 구현에서는 비활성으로 둔다. 전역 획 스타일 드로어와 계보 인스펙터도 별도 개발 단위로 유지한다.
