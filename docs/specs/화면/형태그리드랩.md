# 형태 그리드 (Grid System 2 랩)

레일로 나눈 칸을 채워 자모를 면으로 만드는 실험. ㄱ ㄴ ㄷ ㅁ ㅇ 다섯 자모만. 앱의 획 데이터와는 따로 저장되고 글자에 반영되지 않는다.
들어오는 길: 글로벌 스타일 → 획 생성 규칙 `레거시 스냅 획` → `형태 그리드 편집 열기`(`자소편집 8.2`).

## 1. 머리
- 1.1 보정 화면으로 — 문장 보정(`/`)으로 간다
- 1.2 되돌리기 · 다시 하기 — 이 랩에서 한 편집만
- 1.3 기본안 복원 — 레일과 다섯 자모를 처음 상태로. 아래 `전체 초기화`와 같다
- 1.4 저장 데이터가 깨졌을 때 — 편집기를 열지 않고 원본을 그대로 둔 채 안내만 띄운다

## 2. 캔버스
- 2.1 자모 고르기 — 위 탭에서 다섯 자모 중 하나
- 2.2 지금 값 — 고른 레일의 위치, 사선 개수가 캔버스 구석에 뜬다

## 3. 도구
- 3.1 도구 고르기 — 레일 · 채우기 · 곡률 · 사선. 고른 도구에 맞는 안내 글이 바뀐다
- 3.2 레일 옮기기 — 캔버스에서 레일을 끌거나 방향키로. 스냅 단위마다 붙는다 · 다섯 자모가 같은 레일을 쓴다
- 3.3 레일 추가 · 삭제 — 세로선 · 가로선 추가(고른 선 다음 칸을 나눔), 선 삭제(양쪽 칸을 합침)
- 3.4 레일 위치 · 스냅 단위 — 숫자로 직접 넣는다
- 3.5 칸 채우기 — 누르거나 끌어서 칸을 채우거나 비운다. 채운 칸은 하나의 면으로 합쳐진다
- 3.6 곡률 — 외곽 모서리를 고르고 주황 핸들로 범위를 정한다. 이 모서리 해제 · 전체 해제 · 선택 취소
- 3.7 사선 — 볼록한 외곽 모서리를 고르고 쐐기 면 안에서 바꿀 구간을 정한다
- 3.8 요약 — 칸 수, 스냅, 곡률 · 사선 개수
- 3.9 전체 초기화

## 4. 같은 레일에서 비교
- 4.1 다섯 자모 미리보기 — 레일을 옮기면 그 레일을 경계로 쓰는 자모가 함께 바뀐다. 누르면 그 자모로 간다
