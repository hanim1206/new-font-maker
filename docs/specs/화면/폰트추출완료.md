# 폰트 추출 완료

추출이 끝나면 오는 허브. 방금 만든 OTF를 브라우저에 등록해 템플릿을 진짜 폰트로 그린다 — "진짜가 됐다". 폰트 덱 안의 하위 화면이라 머리는 `‹ 폰트`, 하단 탭은 그대로.
방금 만든 파일은 메모리에만 있다. 새로고침하면 폰트 탭으로 넘긴다. 플랜: `docs/plans/2026-09-25_추출-대기와-완료-페이지.md`.

## 1. 들어오는 길
- 1.1 폰트 탭에서 추출이 끝나면 바로 온다. 파일은 그 전에 이미 내려받아졌다
- 1.2 다른 탭(자소 · 검수)에서 끝났으면 화면은 안 바뀌고 토스트 `OTF가 나왔어요 · 완료 페이지 보기`로 온다

## 2. 결과
- 2.1 머리글 — 폰트 이름 · 버전(1.00n) · 파일 크기
- 2.2 템플릿 — 자막 틀 두 줄을 진짜 폰트로. 등록 이름은 `이름-1.00n`(버전마다 다르게, 떠날 때 지운다). 폰트를 못 읽으면 내 획 그림으로 남는다
- 2.3 다시 받기 — 같은 파일을 같은 이름으로
- 2.4 빠진 글자 — 모양을 만들지 못해 빈 칸으로 들어간 글자 목록. 칩을 누르면 자소 탭 그 글자로. 없으면 절이 없다
- 2.5 설치 안내 — iPhone은 파일 앱에 저장한 뒤 컴퓨터에서 설치(iOS는 폰트 설치가 안 된다)
