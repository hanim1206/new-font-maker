# 프리셋에서 커스텀까지 제작 동선

현행 앱 UX 분석 뒤 확정한 개편 방향. 사용자가 프리셋 폰트에서 시작해 자기 폰트로 끝내는 동선을 축으로 화면을 다시 짠다.

## 현행 진단

- 실제 앱은 `src-next`. `src/`의 옛 3컬럼 편집기는 라우팅에서 빠진 죽은 코드다.
- 편집 세계가 둘이다. `/` 문장 보정은 모바일 폭 컬럼을 데스크톱 중앙에 그대로 두고, `/workspace`의 5탭 셸은 형태 시스템 연결 전 상태다.
- 상단 아이콘 6개가 성격이 다른 것끼리 붙어 있다. 화면 이동, 출력, 형태 규칙, 글로벌 스타일, Undo/Redo. 문장 줄 오른쪽에 2개 더 있어 두 줄 8개.
- 트랙패드는 데스크톱에서 마우스로 문지르는 유일한 입력이고, 선택 대상에 따라 이동·비율·핸들로 암묵 전환돼 지금 무엇이 되는지 보이지 않는다. 구조 명령(추가·삭제·연결)이 패드 옆에 붙어 미세 조절과 섞인다.
- 시작 화면 없이 바로 `과` 획 편집으로 들어간다. 프리셋 선택, 다음 할 일 안내, 프로젝트 개념이 없다.
- `Rail`, `layout binding`, `UPM`, `L-01` 같은 내부 용어가 화면에 그대로 나온다.

## 결정

### 셸 하나

- 문장 보정 페이지를 없애고 문장을 셸 상단에 고정한다. 문장 속 글자는 어느 탭에서든 편집 진입점이며 탭이 범위를 정한다. 뼈대 탭에서 `각`을 누르면 기준선 캔버스에 펜스 `이 층`, 자소 탭에서는 ㄱ·ㅏ·ㄱ 파트 선택, 검수 탭에서는 `이 글자만`.
- 주사위는 현재 펜스 범위 안에서 문장을 뽑는다. 뼈대 탭에서 세로+받침 층을 잡으면 그 층 글자로 채운 문장이 나온다.
- 검수 탭은 문장 + 매트릭스 + 문제 목록으로 "찾는 곳"이다. 탭은 홈 · 뼈대 · 자소 · 검수 · 출력 다섯 개 유지.
- 상단 아이콘은 흩뿌린다. Undo/Redo는 우상단 고정, 출력은 출력 탭, 글로벌 스타일은 뼈대 탭, 형태 규칙은 선택했을 때 드로어 안.
- 데스크톱은 직접 드래그 · 방향키 · 숫자 입력이 기본이고 패드는 보조. 모바일은 패드 우선 유지.
- `src/` 레거시는 삭제하고 랩 라우트는 별도 엔트리로 뺀다.

### 동선 = 범위가 좁아지는 순서

```
[시작] 프리셋 고르기 ─ 예시 문장 바로 보임
   ▼
[1. 인상]  폰트 전체 ── 굵기·붓촉·네모꼴 비율·기울기 (다이얼)
   │           └─ 만족하면 바로 [5. 출력]   ← 최단 경로
   ▼
[2. 뼈대]  이 층 ────── 대표 7자(ㄱ가고과각곡곽)에서 기준선 자로 밀기
   ▼
[3. 자모]  이 자모 ──── 대표 6자(ㄱㅇㅏㅂㅎㅙ) 먼저 → 나머지
   ▼
[4. 검수]  이 글자만 ── 문장·매트릭스에서 문제 글자 손보기
   │           └─ 같은 문제 여러 글자 → 자모 단위로 승격 → [3]
   ▼
[5. 출력]  테스트 OTF → 설치 확인 → 완성 OTF
```

- 큰 것부터 작은 것으로. 초보자가 획부터 만지면 전체가 망가진다.
- 탭 순서 = 작업 순서 = 수정 범위. 세 개가 하나로 겹치므로 사용자가 범위 개념을 따로 배우지 않는다. 지금 있는 탭이 곧 펜스다.
- 모든 탭 상단에 현재 문장 고정. 문장은 피드백이자 진입점이다.
- 출력은 1단계가 끝나면 열린다.
- 뼈대 탭은 인상 → 기준선 두 화면으로 구성한다. 인상을 별도 탭으로 빼지 않는다.

### 수정 범위는 펜스 · 범위 계약

노토 기준선 프리셋이 들어오면 저장 단위가 `글자값 = 층 대표값 + 첫닿자 효과 + 홀자 효과 + 받침 효과 (+ 잔차)`로 바뀐다. 조합마다 기준선이 다른 것은 효과항에 이미 들어 있으므로, 사용자가 대표값을 옮겨도 조합 간 관계는 그대로 따라온다. 책장을 한 칸 내려도 책 순서는 그대로다.

- 밴드(펜스) 순서는 `전체 · 이 층 · 이 자모 · 이 글자`. 기본은 `전체`. 처음 조작은 크게 일괄 반영하고, 부분은 예외로 뒤에 처리한다.
- `홀자 효과` · `받침 효과`는 고급으로 숨긴다.
- 전파 단위는 **역할 구간 비율**이다. 첫닿밑선을 움직이면 초성 높이(첫닿윗선~첫닿밑선) 대비 비율을 다른 층에 뿌린다. 좌우 면은 초성 너비 대비. 같은 거리(u)가 아니라 같은 비율이어야 초성이 큰 무받침 글자와 작은 받침 글자가 각자 크기에 맞게 움직인다.
- 노토 대표값 예: 각(세로+받침) 초성 높이 426에서 첫닿밑선 +16u = 3.8%. 같은 비율이면 가(613) +23, 고(448) +17, 곡(326) +12, 곽(309) +12.
- 클램프: 첫닿밑선은 받침윗선 또는 밑선과의 최소 간격을 넘지 못한다. 클램프에 걸린 글자는 자동 예외로 표시한다. 여기서 "부분 예외"가 자연히 생긴다.
- 저장은 `Δ전체(비율) + Δ층 + Δ자모 + Δ글자`. 하위 범위를 다시 조정해도 상위 Δ는 건드리지 않는다.
- 화면 숫자는 지금 보는 글자의 u 그대로(`512 u`). 아래 작은 줄에 `+3.8% · 전체 적용 · 클램프 1층`.
- 4면을 같은 비율로 밀면 초성 크기 조절이 된다. `크기`(4면 동시, 중심 고정)를 상위 밴드로 두고 면 하나씩은 `◀ ▶`로 순회하는 안을 후속 검토한다. 인상 탭에 `초성 크기 · 받침 크기`를 넣을지도 같이 본다.
- 레이아웃 10종과 모델 6층의 매핑은 따로 정한다. 단독 자모 4종은 노토 모델 밖이라 현행 유지.

### 매트릭스는 제품 화면

`NotoCorpusMatrix`는 칸 상태 함수와 강조 조건만 바깥에서 받는 범용 표다. 검수 탭에 상주시켜 세 역할을 맡긴다.

1. 진행 현황판. 11,172자 중 얼마나 봤고 문제가 어디 몰렸나.
2. 범위 미리보기. 펜스를 고르면 영향 글자가 강조된다.
3. 글자 찾아가기. 칸을 누르면 그 글자 편집으로.

칸 상태는 제작 상태로 바꾼다. 기본값 그대로 · 내가 바꿈 · 이 글자만 보정 · 자동 예외 · 충돌 있음 · 확인 끝. 랩의 추출·승인 상태 함수와 분리한다. 모바일은 시트 하나씩 보여준다.

### 톤앤매너 · 라디오와 sunset

이미지 래퍼런스 캔버스 분석 뒤 두 규칙으로 정리했다. 기계 판넬 hi-fi 안은 한 화면에 기능이 너무 많아 폐기했다.

**라디오 규칙** — 값 하나를 바꾸는 화면. 조절(기준선·점·인상).
- 한 화면 = 대상 하나 · 값 하나 · 컨트롤러 하나.
- 글자 하나와 활성 기준선만 주황. 나머지 선은 점선으로 흐리게.
- 큰 숫자, 아래 `Δ · 프리셋값` 한 줄. 밴드 토글이 펜스.
- 컨트롤러는 하단 원호 다이얼로 전 화면 고정. 2D는 `x / y` 축 토글.
- `◀ 확인 ▶` 트랜스포트. 좌우는 이전·다음 기준선(또는 점), 가운데는 적용. 인상 화면에서는 가운데가 출력.
- 문장·대표 글자·매트릭스는 이 화면에 없다. 앞 단계(고르기)와 뒤 단계(확인)로 나눈다.

**sunset 규칙** — 값 여럿을 읽는 화면. 홈·확인·검수 요약·출력·자소 현황.
- 위 히어로 하나(문장 또는 글자), 아래 정보 블록.
- 라벨은 소문자 모노 자간, 값은 큰 산세리프. 라벨 위 값 아래, 2열.
- 값 옆 미니 세로 바 = 범위 안 위치, 색 = 의미.
- 맨 아래 풀폭 바 + 종합 수치. 히어로 옆 점 3개 = 상태 요약.
- 다이얼 없음, 버튼 하나.

공통: 웜 페이퍼 `#f0eee7`, 잉크 검정, 활성 주황 하나. 상태색(파랑·초록·노랑·빨강·보라)은 점·바·매트릭스에만. 흐름은 읽는 화면에서 고르고 → 바꾸는 화면에서 돌리고 → 읽는 화면에서 확인.

열어 둔 것: 하단 5탭을 없애고 홈 아이콘 + 점 인디케이터로 갈지, 점 이동을 x/y 번갈아 하는 게 패드보다 나은지, 대표 7자 스트립 없이 층 전환이 불편하지 않은지.

### 목공방 도구

범위 계약이 고정된 뒤 그 위에 얹는다. 라디오 규칙에 따라 컨트롤러는 하단 원호 다이얼 하나로 고정하고, 목공방 은유는 다이얼의 눈금·스냅·물성과 밴드(펜스)에 담는다. 기준선을 돌릴 때는 자, 굵기·각도를 돌릴 때는 다이얼, 점을 옮길 때는 축 토글이 있는 다이얼로 같은 컨트롤러가 대상에 맞춰 눈금만 바꾼다. 장식 노브 없이 모든 조작은 실제 값 · 미리보기 · Undo 1건에 연결한다. 획 추가·삭제·연결 같은 구조 명령은 다이얼에 두지 않고 글자를 길게 눌러 여는 메뉴에 둔다.

## 진행 순서

1. 범위 계약(위 절) 마무리. 남은 것은 10종↔6층 매핑과 클램프 최소 간격 수치.
2. 단일 셸, 문장을 셸 상단으로 승격, 상단 아이콘 분산, 시작 화면.
3. 매트릭스 범용화 → 검수 탭, 범위 미리보기 연결.
4. 목공방 도구 층.
5. 노토 프리셋 완성 시 데이터만 교체.
