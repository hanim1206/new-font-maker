# 화면 트리

화면마다 파일 하나. 기능은 `이름 영역.번호`로 부른다(예: `자소편집 6.14`). 지금 있는 것만 적고, 만들 것은 `docs/plans/`에 둔다.
개발 서버에서는 오른쪽 아래 책 모양 버튼이 지금 주소의 명세를 띄운다.

## 제품 화면

```
/fonts  내폰트 ──────── 로그인하면 처음. 목록 · 새로 만들기 (게이트 꺼지면 없음)
/  → /workspace/jamo 로 넘김 (앱을 열면 자소편집이 처음)
/calibration  문장보정 ───── 셸 없는 옛 첫 화면. 모르는 주소도 여기로
│
└─ 셸 (화면 이동은 머리 `…` 메뉴: 자소 · 검수 / 하단 내비 없음)
   ├─ /workspace/jamo          자소편집      획 · 레이아웃 두 모드. 실제로 글자를 고치는 곳
   │   ├─ /workspace/jamo/master   자소원형      실험 · ㄱ 고정 · 글자에 안 닿음
   │   └─ /workspace/jamo/result   조합별결과    실험 · ㄱ 고정 · 글자에 안 닿음
   ├─ /workspace/review        검수격자      11,172자 표. 고치지 않고 자소편집으로 넘김
   └─ /workspace/jamos         자소현황      실험 · 탭에서 갈 수 없음
```

| 화면 | 주소 | 상태 | 한 줄 |
|---|---|---|---|
| [[내폰트]] | `/fonts` | 사용 중 | 로그인 뒤 메인. 폰트 목록 · 새로 만들기 · 이름 · 삭제 |
| [[문장보정]] | `/calibration` | 사용 중 | 문장에서 글자를 골라 획을 고친다 |
| [[자소편집]] | `/workspace/jamo` | 사용 중 | 같은 편집기 + 셸 + 레이아웃 모드 |
| [[검수격자]] | `/workspace/review` | 사용 중 | 전체 글자를 표로 훑고 고칠 글자를 연다 |
| [[자소원형]] | `/workspace/jamo/master` | 실험 | 초성 ㄱ 원형의 기준선과 면 |
| [[조합별결과]] | `/workspace/jamo/result` | 실험 | ㄱ의 일곱 조합과 조합별 보정 |
| [[자소현황]] | `/workspace/jamos` | 실험 | 저장된 원형 목록 |

## 넘어가는 길

- 로그인 게이트: Supabase 설정이 있으면 모든 주소 앞에서 세션을 본다. 없으면 초대 코드 입력 화면, 들어오면 내폰트. 편집 주소를 바로 열거나 새로고침하면 마지막 폰트로 바로 열고, 고른 폰트가 없으면 내폰트로. 셸 `☰` 메뉴 끝 `내 폰트` → 내폰트, `로그아웃` → 코드 입력 화면
- 문장보정 → 자소원형(도구 줄). 셸로 들어가는 링크는 이것뿐이고 `자소편집`으로 바로 가는 길은 없다
- 셸의 모든 화면 → 자소편집 · 검수격자(머리 `…` 메뉴). 문장보정으로 가는 길은 없다(주소를 직접 치거나 모르는 주소일 때만)
- 자소편집 ⇄ 검수격자: 검수에서 글자를 열면 `자소편집` 레이아웃 모드(`?char=…&mode=layout`)
- 자소편집 → 자소원형 → 조합별결과 → 자소원형
- 자소현황 → 자소원형(ㄱ 줄만). 자소현황으로 오는 길은 없는 `/workspace/…` 주소의 안내 화면뿐
- 글로벌 스타일 `레거시 스냅 획` → 형태그리드랩
- 옛 주소: `/workspace/skeleton`(뼈대, 09-21 제거) → 자소편집, `/workspace/review/glyph` → 자소편집 레이아웃 모드
