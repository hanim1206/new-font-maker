# 검수 · 글자 격자

내가 만든 글자 11,172자를 표로 한눈에 훑고, 고칠 글자를 골라 자소 편집으로 넘긴다. 셸의 `검수` 탭. 이 화면에서는 아무것도 고치지 않는다.
칸은 지금 프로젝트의 획으로 그린다(자모 획 + 모델 상자 + 저장된 배치 Δ). Noto 추출 결과 · xor · 승인 측정은 여기 없다 — 그건 랩(`/noto-corpus-lab`)에 있다.
주소: `?char=간`으로 처음 고를 글자를 정한다. 옛 주소 `/workspace/review/glyph?char=…`는 같은 글자의 자소 편집 레이아웃 모드로 넘어간다.

## 1. 셸
- 1.1 화면 이동 — 하단 탭 셋(폰트 · 자소 · 검수). 머리는 `‹ 내 폰트` · 폰트 이름. 되돌리기 · 다시 하기는 이 화면에서 꺼져 있다

## 2. 격자
- 2.1 축 배치 — 행 · 열 · 시트에 홀자 · 받침 · 첫닿자를 어떻게 놓을지 셋 중 하나. 화면에는 없고 개발용 스티키 버튼(화면 명세 버튼 바로 위)을 눌러야 나온다. 기본은 행 홀자 × 열 받침 · 시트 첫닿자
- 2.2 시트 고르기 — 시트 축의 자모 하나를 골라 그 장만 본다
- 2.3 칸 고르기 — 누르면 선택, 선택된 칸을 다시 누르면 3.2처럼 글자를 연다
- 2.4 키보드 — 방향키로 행 · 열, `[` `]`로 시트를 옮긴다. 선택만 바뀐다
- 2.5 높이 — 격자가 시트 탭 아래 남은 높이를 다 쓴다. 세로 스크롤은 격자 안에서만
- 2.6 칸 그림 — 내 획으로 그린 글자. 크기는 하나(보통). 흰 바탕에 옅은 테두리, 색 표시는 없다. 화면에 들어온 칸만 그린다

## 3. 선택 카드
- 3.1 고른 글자 — 내 획으로 그린 모양, 글자, 자모 구성
- 3.2 글자 열기 — 카드를 누르면 `/workspace/jamo?char=…&mode=layout`으로 간다
