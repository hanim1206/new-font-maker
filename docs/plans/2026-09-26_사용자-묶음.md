# 사용자 묶음 — 이름 붙은 자소 목록 하나, 쓰는 곳 둘

- **이번에 비교하는 것**: 묶음을 섹션 홈의 보기용 묶기로만 둘지, 사용자가 만드는 이름 붙은 자소 목록으로 올려 스타일 전파와 레이아웃 규칙이 함께 부르게 할지.
- **이번 승인으로 바뀌는 것**: 묶음이 폰트에 저장되는 대상이 된다(`{ id, name, type, chars[] }`). 스타일 층의 빈 `그룹` 칸을 묶음이 채운다. 범위 규칙식이 자모 목록 대신 묶음 이름을 조건으로 받는다. 지금 묶기(줄기 · 홑 · 쌍 · 획 수 · 겹받침)는 고칠 수 없는 기본 묶음이 된다.
- **바뀌지 않는 것**: 점 편집의 전파(같은 자모 안), 획 우선 모델과 자소 저장 형식, 도마 규칙(폰트당 하나 · 담기는 홈), 층 순서 `전역 < 그룹 < 이 자모 < 이 획`과 좁은 쪽이 이긴다는 원칙.

배경: 섹션 홈에서 카드를 골라 도마에 올리는 게 이미 사용자 묶음의 초안이다. 사용자는 이걸 편집 전파에 쓰고, 나중에 레이아웃에서 "특정 자리에 이 묶음이 오면 ○○" 규칙에도 쓰려 한다. 두 용도를 따로 만들면 같은 목록이 두 벌이 된다 — 오픈타입 클래스(`@삐침닿자`)처럼 하나를 둘이 부른다.

## 결정 (2026-09-26, 사용자)

| 무엇 | 결정 | 왜 |
|---|---|---|
| 규칙이 묶음을 가리키는 법 | **이름으로**(베끼지 않음) | 묶음에 ㅋ을 넣으면 ㅋ도 기존 부리 · 레이아웃 규칙을 바로 따라야 레이아웃 규칙에 쓸 수 있다. 묶음을 고칠 땐 "규칙 n개 · 글자 n개가 바뀌어요"를 먼저 보인다. |
| 묶음으로 퍼지는 것 | **스타일 값만** — 부리 · 둥글기 · 굵기 비율 · 꺾임 | ㄱ과 ㅋ은 점이 짝지어지지 않는다. 스타일 값은 줄기 이름표(`strokeGrammar`)로 짝지을 수 있다. 도마를 들고 편집할 때 막대는 묶음 전체, 점 편집은 지금 글자만. |
| 두 묶음이 부딪힐 때 | **글자 수가 적은 묶음이 이긴다** | 규칙식 넓이 비교(`compareBreadth`)와 같은 잣대. 우선순위 화면은 두지 않고, 부딪힌 순간에만 "ㄱ은 「○○」 값을 따르고 있어요" 한 줄. |

## 게이트

| 게이트 | 닫는 조건 |
|---|---|
| D0 계약 | 위 결정 표 + 아래 미결정 중 입구 · 겹침 표시 승인. 저장 모양 `{ id, name, type, chars[] }`과 기본 묶음 id 목록 확정. 규칙식 계약(`docs/specs/적용범위-규칙식.md`)에 `묶음 참조` 조건 한 절 추가안. |
| G0 대표 | 폰 폭 스크린샷 넷: 초성 홈에서 ㄱ ㄲ ㅋ 담기 → `묶음으로 저장` 시트 → 칩 줄 `내 묶음`에 소제목 → 그 묶음으로 편집기, 부리 막대가 셋에 같이 먹음. |
| G1 홀드아웃 | 묶음에 ㅊ을 넣으면 ㅊ에도 부리가 붙는다(이름 참조). ㄱ이 「삐침 닿자」(8)와 「내 부리」(3)에 다 있으면 「내 부리」 값. 묶음을 지우면 그 층 값이 사라지고 전역으로 돌아간다. 점 편집은 ㅋ으로 안 퍼진다. |
| G2 전수 | `tsc -b` · eslint · `npm test` · e2e. 저장 → 새로고침 → 다시 열기에서 묶음 · 그룹 층 값이 남는다. 화면과 OTF가 같은 `getEffectiveStyle`을 읽는다. |
| G3 사용자 검증 | 폰에서 묶음 하나 만들고 → 부리 손질 → 묶음에 글자 하나 더하기 → 전파 문장에서 새 글자에도 먹은 것 확인 한 바퀴. |

레이아웃 규칙에서 묶음 부르기(`첫닿자가 「○○」면 홀자 상자 → …`)는 이 플랜 밖이다. 이 플랜은 규칙식이 묶음 이름을 읽을 수 있게까지만 연다.

## 미결정

- **입구.** A 도마에서 저장(2개 이상 담으면 `묶음으로 저장` → 바텀시트, 이름 미리 채움) / B 칩 줄 끝 `+` 단계 화면. AI 추천 A — 고르기를 두 번 하지 않고, 전파가 켜지는 순간도 도마를 들고 들어갈 때라 한 줄로 이어진다.
- **겹침 표시.** 섹션 홈 판은 카드 하나가 한 자리만 갖는다(key = 글자). 사용자 묶음은 겹친다. `내 묶음` 칩에서만 카드를 겹쳐 그릴지, 소제목 + 글자 칩 줄로 보일지.
- **같은 크기 두 묶음.** 가설: 나중에 값을 준 쪽. D0에서 확인.
- **묶음 고치기 · 지우기.** 소제목 길게 누르기 → 이름 바꾸기 · 지우기, 지우기는 확인 대신 `되돌리기` 토스트(가설).
- **기본 묶음과 사용자 묶음이 부딪힐 때.** 둘 다 `그룹` 층이라 크기 규칙이 그대로 먹는지, 사용자 묶음이 늘 이기는지.

## 진행 기록

### 2026-09-26
- **사실 (나)**: 묶음은 전파까지 한다. 나중에 레이아웃 규칙("특정 영역에 어떤 자소가 오면 ○○")에도 쓰고 싶다. 이름 참조 · 스타일만 · 작은 묶음이 이긴다.
- **가설 (AI)**: 묶음 = 전역 스타일 층의 `그룹` 칸. 기본 묶기는 고칠 수 없는 기본 묶음으로 합친다. 입구는 도마에서 저장.
- **미결정**: 위 목록. 코드는 아직 없음.
- **사실 (나)**: 입구는 `편집` 바로 왼쪽 동그란 `+`(도마 칩 끝 글자 단추 안 씀). 겹침은 AI 안대로 카드를 겹쳐 그림.
- **사실 (구현)**: `src/stores/jamoGroupStore.ts` — 묶음 `{ id, name, type, chars, stemBeak?, styledAt? }`, localStorage `font-maker-jamo-groups`. `groupStemBeakFor`가 작은 묶음 → 같으면 나중 값. 부리 함수(`stemBeakInkGroups`)가 획마다 `style`을 받고, 화면(`SvgRenderer`)과 OTF(`fontExportUtils` → `fontGenerator`)가 같은 resolver를 쓴다.
- **사실 (섹션 홈)**: 도마 2개 이상 · 아직 없는 묶음이면 `+` → 바텀시트(이름 미리 채움, 기본 묶음과 같으면 그 이름). 저장하면 `내 묶음` 칩(전체 다음)으로 옮겨 감. 소제목 `⋯` → 이름 · `지금 도마로 글자 바꾸기`(+/− 글자, 부리가 따라간다는 말) · 지우기(확인 없이 되돌리기 토스트). 겹친 글자는 카드가 하나 더 놓이고 담기는 같이 켜진다. 도마가 묶음과 같으면 칩 끝에 묶음 이름.
- **사실 (스타일 공간 `/workspace/font`)**: 도마가 묶음과 같으면 부리 탭 위에 `전체 / 「이름」 n자`. 기본은 전체(대시보드 `스타일 · 이 폰트 전체`로 들어오는 곳이라). 묶음 쪽은 미리보기 · 되돌리기 기록 따로.
- **사실 (확인)**: tsc · eslint 통과, vitest 새 테스트 10개 통과. 전체 vitest 실패 2개(`preset-candidate-source` digest, `vertical-vowel-gap-reference` SHA)는 이 변경이 없는 `beta-rls` 워크트리에서도 같게 실패 — 원래 있던 것. Playwright(4173, 게이트 끔): 저장 · 내 묶음 · 겹침 · `ㅂ ㅃ` 묶음 사각 부리 → `별`의 ㅂ에만 붙고 전역 부리는 꺼진 채.
- **미결정**: 획 편집기(도마 칩 줄 있는 곳)엔 부리 막대가 없어 묶음 부리는 스타일 공간에서만 준다. 묶음이 계정 저장(Supabase 폰트 데이터)에 안 실린다 — 이 기기에서만. 레이아웃 규칙식의 묶음 참조는 다음 플랜. ㄱ · ㅋ은 세로줄기 머리가 꺾임이라 부리가 원래 안 붙는다(`삐침` 묶음 예시로는 안 보임).
- **사실 (고침)**: 시트 올라올 때 튕김 · 배경 스크롤 — `autoFocus`가 화면 밖 입력칸을 보이려고 셸을 스크롤한 것. 포커스는 올라온 뒤 `preventScroll`, 열린 동안 판 잠금, 곡선 360ms 감속만.
- **사실 (나)**: `내 묶음` 칩 자리는 `전체` 다음 유지(AI 추천). 묶음 글자 고치기는 시트 안 판(A안).
- **사실 (구현)**: `⋯` 시트 = 이름 + 그 종류 자소 판(7열, 든 글자 진하게) + 바뀜 한 줄(`+ ㅊ  − ㄲ`, 부리 있으면 따라간다는 말). 비우면 저장 잠김. `지금 도마로 글자 바꾸기`는 뺌 — 도마와 묶음 고치기가 섞이지 않게. Playwright: 삐침 셋에서 ㅊ 넣고 ㄲ 빼 저장 → `ㄱ ㅊ ㅋ`.
- **뒤집힘 (나)**: `내 묶음` 칩은 맨 뒤로(같은 날 `전체` 다음 유지를 뒤집음). 시트 안내 `칸을 눌러 넣고 빼요` 뺌 — 바뀐 게 없으면 줄이 빈다.
- **뒤집힘 (나)**: 만들기 입구 `편집` 왼쪽 `+` → 칩 줄 끝 `+`(`내 묶음` 옆, 배경 한 단 진하게). 늘 켜짐 — 만들기 시트에도 자소 판을 깔고 도마 글자를 미리 켠다. 이름은 고른 글자를 따라가다가 사용자가 치면 멈춘다. 이름 칸 자동 포커스 뺌(폰 키보드가 판을 가림).
