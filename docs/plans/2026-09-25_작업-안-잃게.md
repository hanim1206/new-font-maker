# 작업 안 잃게 — 오류 화면 · 업데이트 알림 · 탭 충돌

- **이번에 비교하는 것**: 앱이 깨지거나, 새 버전이 나오거나, 같은 폰트를 두 곳에서 열었을 때 베타 친구가 **무슨 일인지 알고 작업을 잃지 않는지**.
- **이번 승인으로 바뀌는 것**: 흰 화면 대신 오류 화면(백업 받기 · 다시 불러오기). 새 버전은 알림 뒤 새로고침. 같은 폰트는 한 탭에서만 편집, 다른 기기가 먼저 바꿨으면 덮지 않고 알린다.
- **바뀌지 않는 것**: 저장 방식(계정 저장 + 브라우저 사본), 10초 자동 저장, 편집 화면, 추출, 로그인 게이트. 동시 편집 합치기는 하지 않는다.

단계는 셋, 한 단계에 하나만 본다: ① 오류 화면 → ② 업데이트 알림 → ③ 탭 · 기기 충돌. 셋 다 "저장부터 하고(`flushAccountFont`) 바꾼다"를 같이 쓴다.

## 지금 상태 (사실, 코드 조사)

- **오류**: `src-next`에 `ErrorBoundary` 없음. `main.tsx`가 화면마다 `root.render`를 따로 부름 → 어디서 던져도 흰 화면. 기존 실패 화면(이관 막힘, `AccountFontFailedPage`)은 렌더 전 실패만.
- **업데이트**: `vite.config.ts` `registerType: 'autoUpdate'`, 등록은 플러그인 자동 주입. 편집 중 늦게 불러오는 조각: 추출 `fontGenerator.ts:734`, 로그아웃 `betaAuth.ts:80·84`.
- **탭**: 폰트 키 6개(`LOCAL_FONT_KEYS`)를 모든 탭이 같이 쓴다. 제품 화면에 `storage` 이벤트 · `BroadcastChannel` · `navigator.locks` 없음. 디바운스 저장(`debouncedStorage.ts`)은 읽기도 탭 안 캐시라 다른 탭 값을 못 본다 → 나중에 쓴 탭이 이긴다.
- **기기**: `saveFont`(`accountFontApi.ts:52`)는 조건 없이 덮는다. 폰에서 고친 뒤 PC 옛 탭이 10초 뒤 저장하면 폰 작업이 사라진다. 버전 되돌림 트리거는 형식 버전만 막는다.
- **저장 실패**: 서버 실패는 토스트 + 재시도로 끝남(26, `b47cf4f`). 브라우저 사본 쓰기 실패(용량 초과)는 `debouncedStorage` 타이머가 삼키고 알리지 않음. 폰트 JSON 약 31KB라 되돌리기 기록 키가 아니면 한도 걱정은 적다(가설).
- **백업 재료**: `collectAccountFontData()`(`accountFontSync.ts:35`).

## 가설

- H1: 배포 뒤 옛 탭에서 추출 → 옛 해시 조각 404(Vercel) → 추출 실패.
- H2: 이벤트 · `await` 속 예외는 ErrorBoundary가 못 잡는다 → `error` · `unhandledrejection` 따로.
- H3: 같은 브라우저 두 탭이 실제 대부분(폰 · PC 동시 편집은 드물다). 그래서 탭은 막고, 기기는 묻기만 해도 충분하다.

## 계약 (D0 닫힘 · 최소 스펙)

넓힐 자리만 남기고 지금은 최소로 한다. 알림은 **한 자리**(화면 아래 한 줄 바 `AppNotice`, 종류만 늘린다). 충돌 판정은 `saveFont` 한 곳에서.

**① 오류 화면**
- `main.tsx`의 모든 렌더를 `AppErrorBoundary` 하나로 감싼다(헬퍼 `render(node)`).
- "문제가 생겼어요" + `작업 백업 받기` + `다시 불러오기`, 오류 문구는 접은 `자세히`에.
- 백업: `collectAccountFontData()` → `폰트이름_날짜.json`. 실패하면 `LOCAL_FONT_KEYS` 원문. 백업 버튼은 오류 화면에만. 불러오기는 이 플랜 밖(26).
- 이벤트 · 비동기 예외(`error` · `unhandledrejection`)는 **기록만**: 최근 10개를 메모리에 두고 오류 화면 `자세히`에 같이 보인다. 서버로 보내기는 나중(자리만).

**② 업데이트 알림**
- `registerType: 'prompt'` + `virtual:pwa-register` `onNeedRefresh`. 확인 주기는 플러그인 기본(따로 타이머 없음).
- `AppNotice` "새 버전이 있어요 · `새로고침`". 누르면 저장 → `updateSW(true)`. 저장 실패면 안 바꾸고 "저장 못 한 변경이 있어요". 닫으면 이 탭에선 다시 안 띄운다.
- 추출 조각 불러오기가 실패하면(H1) 같은 알림.

**③ 탭 · 기기 충돌**
- **탭**: `navigator.locks` `font-edit:<fontId>` 하나. 둘째 탭은 편집 화면 대신 "다른 탭에서 편집 중이에요 · `여기서 열기`". 누르면 `steal: true`로 가져가고 서버에서 다시 읽는다. 뺏긴 탭은 자동 저장을 멈추고 같은 안내로 바뀐다. 탭을 옮기면 `visibilitychange`로 이미 저장되므로 따로 넘겨받는 통신(`BroadcastChannel`)은 두지 않는다.
- **기기**: 열 때 받은 `updated_at`을 들고 `saveFont`에 `.eq('updated_at', 그 값)`, 저장 뒤 돌려받은 값으로 바꾼다. 0건이면 덮지 않고 `AppNotice` "다른 기기에서 바뀌었어요 · `그걸 불러오기`"(기본) · `내 것으로 덮기`. 불러오기 전에 내 것은 `font-maker-conflict-backup-v1` 한 칸에 남긴다(최신 하나만).
- **사본 쓰기 실패**: `debouncedStorage` 쓰기 실패를 `AppNotice` 한 번 "이 기기에 사본을 못 남겼어요(계정엔 저장됨)".
