## 2. 자소는 어떻게 저장되나 (dev, 제품 공통)

- 꼴: `src/types/index.ts` — `JamoData`(자모 하나) → `strokes: StrokeDataV2[]`. 섞임홀자는 `horizontalStrokes` · `verticalStrokes`.
- 획 `StrokeDataV2`: 중심선 앵커 `points`(칸 기준 0–1, 베지어 손잡이) + `closed` + `thickness`(절대값). **획 우선(centerline) + 두께**다. 윤곽은 저장 안 함.
- 문맥 변형: `JamoData.contextStrokes`(오른 · 아래 · 섞임 홀자 계열별 닿자 획), 고르기 `src/utils/jamoContextStrokes.ts` `strokesForFamily`. 기준 틀 `frame`, 조건부 변형 `overrides`.
- 저장소: `src/stores/jamoStore.ts`(choseong · jungseong · jongseong 맵). 홀자 줄기 마스터 `src/stores/stemMasterStore.ts` `propagatedJungseong`.
- 받침 · 쌍닿자 복사: `src/utils/jamoFromChoseong.ts` — `jongseongFromChoseong`(받침 = 첫닿자 한 번 복사, 뒤따라가지 않음), `clusterFromChoseong`(겹받침, `CLUSTER_SPLIT` 고정 구간), `doubleFromSingle`(ㄲ = ㄱ 둘, `DOUBLE_SPLIT`), `borrowFromChoseong` · `matchesChoseong`. 쓰는 곳 `DashboardLabPage.tsx` · `CalibrationSentenceEditor.tsx`.
- 글자 풀기: `src/utils/hangulUtils.ts` `decomposeSyllable` → `DecomposedSyllable`(자모 셋 + `layoutType` 짜임 10종).
- 전역 스타일(굵기 · 자간 · 붓 · 대비 · 흐림 손잡이): `src/stores/globalStyleStore.ts`. 굵기 → 배율 `src/utils/globalStyleUtils.ts` `weightToMultiplier`.

## 5. 빚기 시험판 안의 데이터 흐름 (`MoldLabPage.tsx` `MoldGlyph`)

글자 하나를 이 순서로 고친다. 칸은 매 단계 새 `boxes`, 획은 새 `syllable`.

1. 바탕: `useGlyphBase` — 저장소(또는 써 넣기 원본) 자모 + 그은 줄기 → `decomposeSyllable` → `useContextPlacement`. 처음 굵기 `moldBaseStyle`(400).
2. 인상 잡기 칸: `moldedBoxes`(MoldLabPage 안) = `moldLab.ts` `lookBoxes`(= `impressBoxes` 무게중심 · 밀림 + `jagBoxes` 윗선 들쭉날쭉) ← `applyPartEdits`(부위 다듬기 끈 값).
3. 획 다듬기: `waistSyllable`(허리선) → `branchSyllable`(곁줄기 길이) → `stemSyllable`(줄기 휨 · 길이 · 틈) → `serifSyllable`(부리). 모두 `moldLab.ts`.
4. 울타리: `fenceBand.ts` `correctGlyph` · `movedBoxes`(고딕 86벌 90% 폭으로 당김). 래퍼 `fencedBoxes`(같은 파일 안, MoldLabPage).
5. 풍선 닿자(닿자 크기 > 1): `moldLab.ts` `growSides` · `inflateSyllable` · `balloonOk`.
6. 좁은 칸 굵기 예산: `moldBudget.ts` `thinBudget`(먼저 넓힘 `WIDEN_MAX` 1.1, 모자라면 가늘게 `THIN_FLOOR` 0.69) → `thinSyllable`.
7. 굵기 갈림길(`heavyOn` = 굵기 배율 > 1):
   - **처음 굵기 이하** → 흐림 선 `moldHalo.ts` `haloCorrect`(= `haloFit` 첫닿자↔기둥 + `haloFinalFit` 받침 위 → `haloBoxes` · `finalBoxes`).
   - **굵을 때** → `moldStack900.ts` `solveStack900`(박스 없는 쌓임, 뼈대 점 옮김 + 굵기 배율). 끄면 옛 길 `moldStack.ts` `stackLay` + `moldBalloon.ts` `solveBalloon`. 그 뒤 `haloFit` · `haloFinalFit`을 굵은 두께로 다시.
8. 붓 · 대비 · 붓촉: `moldLab.ts` `moldInk`. 대비 안 만지면 굵기마다 패턴 `contrastPatternOf` · `patternWeightRatio`.
9. 그리기: `SvgRenderer`.

틈 바닥은 하나: `moldGap.ts` `engineGapOf` = max(0.025em, 0.2 × 획). 예산 · 쌓임 · 풍선이 모두 쓴다.

## 7. 연구 판 스위치 (코드 상수)

- `MoldLabPage.tsx` `BALLOON_WEIGHT = true` — 400 위는 자소마다 굵기. 끄면 글줄째 멈춤.
- `MoldLabPage.tsx` `STACK_900 = true` — 굵을 때 900 쌓임. 끄면 풍선 + 쌓인 획 법칙.
- `haloPlacement.ts` `HEAVY_FROM = 1.02` — 제품 · OTF 흐림 선은 처음 굵기 근처만. 900 쌓임은 **아직 빚기 화면에만** 있고 파일로는 안 나간다.
- 흐림 손잡이 시작값 `moldHalo.ts` `HALO_PRESETS`(고딕 · 명조).
