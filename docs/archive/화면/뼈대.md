# 뼈대 · 공통 배치 기준선

> 2026-09-21 화면 제거. 옛 주소 `/workspace/skeleton`은 자소 탭으로 넘어간다. 플랜: `docs/plans/2026-09-21_뼈대-탭-제거.md`

일곱 가지 레이아웃(단독 · 세로 · 가로 · 혼합 · 각각 받침)이 함께 쓰는 배치 기준선을 옮기는 화면. 셸의 `뼈대` 탭.
**여기서 옮긴 기준선은 이 화면의 미리보기에만 보인다.** 자소 · 검수 · 문장의 글자는 Noto 모델 상자(꺼져 있으면 옛 스키마)로 놓이고, 이 화면이 저장한 값을 읽는 곳은 없다. 9/17에 폐기로 정했다.

## 1. 셸
- 1.1 문장 보정으로 · 탭 이동 — `자소편집 1.1` `자소편집 1.4`와 같음
- 1.2 상태 표시 — 프로젝트 이름과 저장 상태(`저장 중…` `기기에 저장됨` `프로젝트 저장됨` `저장 확인 필요`)
- 1.3 되돌리기 · 다시 하기 — 형태 저장소의 기록을 한 단계씩. 원형 · 조합별 결과 화면에서 한 편집과 기록을 같이 쓴다 · 되돌린 뒤 바로 저장

## 2. 머리
- 2.1 수정 범위 — `공통 배치 Rail · 7개 layout binding · 조합 결과 7개` 고정 표시. `범위 변경`은 늘 꺼져 있다
- 2.2 형태 시스템 상태 — 연결 전 / 마스터 몇 개 연결됨 / 저장 데이터 확인 필요
- 2.3 저장 결과 — `이 기기에 저장했습니다` / `프로젝트와 기기에 저장했습니다` / 실패 글

## 3. 연결 전 준비
- 3.1 추천 기본 구조로 시작 — 형태 시스템이 없을 때만. 기본 형태 시스템을 만든다 · 형태 저장소
- 3.2 기존 7개 배치를 공통 기준선으로 연결 — 지금 레이아웃 스키마 일곱 개를 기준선 묶음으로 한 번 복사한다. 연결해야 4번이 열린다 · 형태 저장소

## 4. 기준선 캔버스
- 4.1 기준선 고르기 — 선 가까이 가면 강조되고 누르면 잡힌다
- 4.2 기준선 끌기 — 0.005 단위로 붙고 이웃 선을 넘지 못한다. 끄는 동안 캔버스 · 상자 · 5번 카드가 같이 움직이고, 손을 떼면 저장 · 형태 저장소(이 기기 + 열린 프로젝트가 있으면 서버). 키보드 · 숫자 입력은 없다
- 4.3 일곱 레이아웃 상자 — 첫닿자 · 홀자 · 받침 상자를 겹쳐 보여 준다. 범례 포함, 조작 없음

## 5. 일곱 조합 비교
- 5.1 ㄱ 가 고 과 각 곡 곽 — 옮긴 기준선으로 다시 계산한 글자. 보기만 하고 누를 수 없다. Noto 모델 상자를 안 쓰기 때문에 같은 글자가 다른 화면과 다르게 보인다
