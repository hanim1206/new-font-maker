# 대시보드

로그인하면 처음 보는 화면이자 지금 연 폰트의 한눈 화면. 셸 머리 `‹ 내 폰트`도 여기로 온다. 위는 폰트 카드, 아래는 왼쪽 레일 + 섹션 다섯(스타일 → 레이아웃 → 초성 → 중성 → 종성, 큰 것부터 작은 것). 플랜: `docs/plans/2026-09-26_섹션-홈과-도마.md`. 코드는 옛 랩 이름 `DashboardLabPage.tsx` 그대로.

## 1. 폰트 카드
- 1.1 알약 — 머리 왼쪽 회색 알약 `이름 ⌄` = 지금 폰트. 누르면 내 폰트 드로어(1.4), 다시 누르면 닫힌다. 머리 아래 선은 없다. 계정 폰트를 안 연 랩 화면이면 이름만
- 1.2 카드 — 지금 폰트 하나. 마지막 고침 · 예시 문장을 이 폰트로. 이름은 알약에 있어 카드엔 없다. 아래 오른쪽에 `…` · 다운로드
- 1.3 마이페이지 — 머리 오른쪽 아이콘. 아이디 · 요금제 · 폰트 수 `n / 3개`, 게이트가 켜졌을 때만 로그아웃
- 1.4 내 폰트 드로어 — 머리 바로 아래에서 내려오고, 닫을 땐 거꾸로 올라간다(바깥 · Esc · 알약). 만든 순서대로, 고르거나 고쳐도 자리가 안 바뀐다. 지금 폰트 줄은 회색 면 + ✓(고친 자소 수 · 고친 날), 나머지는 고친 날. 줄을 누르면 지금 폰트를 올리고 그 폰트로 대시보드를 다시 연다. 못 올리면 가지 않고 아래 알림
- 1.5 `…` — 카드의 다운로드 옆. 지금 폰트의 이름 바꾸기(카드 맨 위 줄이 입력칸, 서버에 바로) · 복제(아직 없음, 흐림) · 삭제(한 번 더 묻고 소프트 삭제 → 최근 폰트, 없으면 새 폰트로 다시 연다)
- 1.6 새 폰트 — 드로어 맨 아래. 프리셋 그대로 새 폰트를 만들어 연다(이름은 친구 아이디, 겹치면 뒤에 번호). 계정당 3개, 다 차면 흐리고 안내 한 줄
- 1.7 첫 화면 — 고른 폰트가 없으면(처음 로그인 · 지운 뒤) 최근 폰트를, 없으면 새 폰트를 연다. 옛 `/fonts`로 와도 여기
- 1.8 시안인 것 — 카드 다운로드 단추는 아직 동작하지 않는다

## 2. 섹션
- 2.1 레일 — 왼쪽 목차. 누르면 그 섹션으로 스크롤, 스크롤하면 따라온다. 맨 아래 `검수`
- 2.2 스타일 — 굵기 · 기울기 · 둥글기 · 부리 타일 넷. 아이콘은 값과 무관한 공통 예시, 값은 숫자
- 2.3 레이아웃 — 여섯 구조군 대표 글자 6장(첫닿자 상자 옅게)
- 2.4 초성 · 중성 · 종성 — 요약 줄: 제목 · 수 · 손댄 n · 앞 4장. 머리(화살표) 전체가 섹션 홈으로 가는 문. 카드는 그 자소 하나만 도마에 올리고 섹션 홈으로(편집기로 바로 가지 않는다)

## 3. 섹션 홈
- 3.1 주소 — `/dashboard/choseong` · `jungseong` · `jongseong`. 섹션 머리로 들어오고 `‹`는 대시보드로. 모르는 종류면 대시보드로 넘긴다
- 3.2 묶기 칩 — 초성은 `전체 · 줄기 · 홑·쌍 · 획 수`(줄기는 어휘사전, 획 수는 저장된 우리 획 수). 중 · 종성은 아직 `전체`만. 카드는 자리만 옮긴다. 고른 묶기는 주소 `?group=`에 남아 새로고침에도 그대로
- 3.3 도마 — 카드 탭 = 담기 · 빼기, 소제목 탭 = 그 묶음으로 교체. 맨 아래 도마 줄과 `편집 n`
- 3.4 편집 — `편집 n`은 도마를 들고 자소편집 획 편집으로(`?char=대표 글자&mode=stroke&part=`) 편집기로 가는 길은 이것 하나
- 3.5 돌아오기 — 편집기 머리 `‹`는 들어온 섹션 홈(묶기 그대로)으로 돌아온다
