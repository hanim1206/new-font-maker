## 작업 종료 기록 형식

각 조각이 끝날 때 아래 항목을 채운다.

- 열어볼 곳
- 직접 해볼 것 최대 3개
- 정상 결과
- 자동 검증 결과
- 변경 파일과 checkpoint commit
- 이번에 하지 않은 것
- 사용자 판정: `통과` 또는 `수정 필요`

사용자 판정 전에는 다음 조각을 시작하지 않는다. 같은 차단 원인에 대한 서로 다른 해결 시도 두 번이 연속 실패하면 더 진행하지 않고 증거와 선택지를 보고한다.
