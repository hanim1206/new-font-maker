# 오버라이드 카드 목록

- **이번에 비교하는 것**: 저장된 배치 Δ가 칩 하나 눌러야 "있음"만 보이는 지금과, 레이아웃 안에 쌓인 오버라이드를 카드 목록으로 한눈에 보는 것.
- **이번 승인으로 바뀌는 것**: 레이아웃 모드 아래에 `이 레이아웃의 오버라이드` 목록이 생긴다. 기본값 카드 + 저장 항목마다 카드 하나. 카드를 누르면 그 오버라이드가 닿는 글자가 표본 자리에 뜬다. ×로 지운다.
- **바뀌지 않는 것**: 저장 키·층·합산(`layoutDeltaStore`), 범위 칩, 캔버스 편집, 적용 흐름, 프리셋 모델, production 값.

출처: 주간 노트 W39 `레이아웃 수정 적용범위`(컬러박스 카드 + 글자 조합 보기) + 9/21 논의(노 ㄴ 작게·로 ㄹ 크게 = 같은 레이아웃에 오버라이드 둘). 원칙: 기본은 자동, 좁히기는 사용자. 프리셋 자동 보정과 사용자 오버라이드는 저장 따로.

## 지금 상태

**사실**
- 저장소는 이미 오버라이드 목록 구조다: `all`, `layers[ctx]`, `jamo[ctx][부품:자모]`. 노에서 ㄴ, 로에서 ㄹ을 `이 자모만`으로 적용하면 `jamo.bottom['CH:ㄴ']`·`['CH:ㄹ']` 둘이 따로 든다.
- 화면은 지금 칩의 층 하나만 본다(`useScopeDelta` → `저장된 Δ 지우기`). 뭐가 쌓였는지 볼 곳이 없다.
- 카드 8장(`propagationCandidates`)은 범위별 표본을 이미 뽑는다. 오버라이드 하나 = 범위 하나라 그대로 재사용된다.
- 프리셋 모델의 자동 보정(층 대표값 + 자모 효과 + 쌍 셀)은 `layoutDeltaStore` 밖이고 이 목록에 **안 온다**. 기본값 카드 한 장으로만 보인다. 프리셋 보정을 카드로 펼치는 건 `고정 Δ` 뒤의 다른 질문.

## 하려는 것

1. 전파 카드 아래 `이 레이아웃의 오버라이드` 절. 순서는 넓은 것부터: `기본값(모델)` → `전체` → `이 레이아웃` → 자모별(부품 순 CH·JU·JO, 자모 순). 기본값 카드는 늘 있고 못 지운다.
2. 카드 = 컬러박스(부품 색: 첫닿자 초록·홀자 파랑·받침 보라, 전체·이 레이아웃은 회색) + 이름(`ㄴ · 첫닿자`, `이 레이아웃`) + Δ 요약 줄(`윗변 −20u · 오른변 +12u`) + 닿는 글자 수. 글자는 안 그린다.
3. 카드를 누르면 표본 자리(카드 8장)가 그 오버라이드의 글자로 바뀌고, `다른 글자`로 넘긴다. 범위 칩과 고른 자모도 그 카드의 것으로 맞춰진다(같은 자리에 더 쌓기가 바로 됨).
4. 카드 × = 그 층 지우기(Undo 됨). 지금 `저장된 Δ 지우기` 버튼은 카드 ×로 흡수.
5. 다른 레이아웃의 오버라이드는 여기 안 보인다. 그 레이아웃 글자를 열면 보인다. (`전체`는 어느 레이아웃에서도 보인다.)

판단 변수 하나 = **목록이 있어야 하는가**. 카드 안에서 값을 직접 고치는 것, 프리셋 보정 카드, 고정 Δ 표시(`= 718`)는 이 플랜 밖이다. 고정 Δ가 오면 요약 줄에 `=` 항목이 추가될 뿐 카드 구조는 안 바뀐다.

사실
- 계산부 `src-next/layoutOverrides.ts`(`overrideCardsOf`·`deltaSummary`·`targetOfCard`), 화면 `src-next/LayoutOverrideList.tsx`. 전파 카드 절 맨 아래 `이 레이아웃의 오버라이드`. 저장소는 안 건드림.
- 카드 = 컬러박스(부품 색, 전체·이 레이아웃은 회색, 기본값은 빗금) + 이름 + Δ 요약(`첫닿자 윗변 -10u · …`, 자모 카드는 부품 이름 생략) + 닿는 글자 수(11,172자 전수에서 셈, 메모). 순서 기본값 → 전체 → 이 레이아웃 → 자모별(CH·JU·JO, 자모 순). 0만 남은 항목은 카드 안 됨.
- 카드 누르기: 전체·이 레이아웃은 칩만 바꿈. 자모 카드는 그 부품을 켜고(`onSelectPart` → 편집기 `selectPart`) 칩 `이 자모만`, 고른 자모 = 그 자모 하나 → 표본 8장이 그 글자로. 지금 칩·고른 자모에 맞는 카드는 켜져 보임(여러 자모를 골랐으면 여러 장).
- × = 그 층만 지우기, Undo 됨. 옛 `저장된 Δ 지우기` 버튼은 뺐다.
- 곁가지(사용자 요청): 카드 머리의 `적용` 버튼을 하단 고정 바로 옮김. 바는 한 칸 상태 기계 — 배치 Δ 있으면 `이 레이아웃에 적용` / `ㄱ·ㅋ에 적용` / `전체에 적용`(범위 이름은 카드가 `onScopeLabel`로 올림, 실행은 `ref.apply`), 없으면 `ㄱ 획 고치기`. 형태 Δ만 있으면 획 고치기 비활성 + `먼저 되돌리세요`. testid `review-propagation-apply`는 바로 이동. 이어서 `복원 · N개 변경`도 바 왼쪽으로 옮기고 캔버스 왼쪽 아래 복원 버튼은 뺌. 바 상태: Δ 없음 `획 고치기` / 배치 Δ `복원 | …에 적용` / 형태 Δ만 `복원 | 획 고치기(비활성)`. 다른 세션이 같은 시간에 카드 머리(제목·힌트)를 빼서 힌트 문구 e2e 한 줄 제거.
