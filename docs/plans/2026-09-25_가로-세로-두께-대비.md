# 가로 · 세로 두께 대비

- **이번에 비교하는 것**: 굵기를 한 값으로 두는 지금과, 가로줄기·세로줄기 두께를 막대 하나로 벌리는 것.
- **이번 승인으로 바뀌는 것**: 획 스타일 탭에 `가로·세로 대비` 막대(−100 ~ 100, 0이 같음, + 는 세로 굵게 · 가로 얇게). 토막 각도로 매끈하게 — ㅇ은 옆이 굵고 위아래가 얇아진다. 화면·fit·OTF 같은 함수. 0이면 전과 같다.
- **바뀌지 않는 것**: 상자·배치(중심선 지킴, 잉크가 조금 넘는 건 받아들임 — 굵기 결정 ①과 같음), 획 데이터, 굵기 막대, 둥글기, 납작 붓의 계산, 옛 단독 화면.

## 계약 (D0)

- 저장: brush 모드 `strokeStyle.contrast?: number` −1 ~ 1. 없거나 0이면 키 없음.
- 두께: 토막(중심선을 편 선분)마다 `반폭 × (1 − c · 0.5 · cos 2θ)`, θ는 가로에서 잰 각. 가로 = 1 − 0.5c, 세로 = 1 + 0.5c, 45°·곡선 중간은 1. c = 1이면 세로 : 가로 = 3 : 1.
- 함수: 일자 stroker(`flatStrokeGeometry`)가 토막별 반폭으로 옆면을 밀고 꺾임에서 두 오프셋 선의 교점을 잡는다. 둥글기 굴림 반지름은 그 자리 반폭을 따른다. 대비가 0이 아니면 둥글기처럼 채운 윤곽(`needsFilledRenderInk`)·끝은 butt/miter 기준.
- UI: 획 스타일 탭, 둥글기 막대 아래 `가로·세로 대비`. 굵기 탭이 아닌 이유 — 그 파일(`CalibrationSentenceEditor.tsx`)은 다른 세션이 고치는 중이라 피했다. 나중에 옮길 수 있다.

### 2026-09-25 구현 (D0~G2)
- **사실 — stroker**: `polylineToFlatInkGroups`에 `widthOf(direction)` 배율. 토막마다 반폭(`halves`), 꺾임은 `miterOf`(폭이 같으면 옛 식 그대로 → 대비 0은 점 하나까지 같음, 다르면 두 오프셋 선의 직선 교점). 둥글기 반지름은 `(hIn + hOut) / 2 / 기준 반폭`으로, 끝 굴림은 끝 토막 반폭으로 맞춘다. 조각 fallback도 토막별 반폭.
- **사실 — 대비 식**: `contrastWidthOf(c)` = 1 − 0.5c · cos 2θ. c = 1이면 세로 1.5 · 가로 0.5.
- **사실 — 저장·분기**: `strokeStyle.contrast`. `contrastOf` · `hasRoundness`(둥글기 또는 대비) 하나로 화면 · fit · OTF 분기. 부리는 `verticalWidthFactorOf`로 기둥 폭을 같이 읽는다(`SvgRenderer` · `fontGenerator`).
- **사실 — UI**: 획 스타일 탭, 둥글기 막대 아래 `가로·세로 대비`(−100 ~ 100, 출력 `세로 +40%` / `가로 +40%` / `같음`). 사용자 말대로 제품 화면의 `절단 끝` 규칙 버튼을 뺐다(붓촉형만). 옛 저장분이 다른 규칙이면 `붓촉형`으로 돌아올 버튼만 뜬다.
- **G0**: `한` +60 / −60 — 세로 굵고 가로 얇음(반대도), 상자 그대로.
- **G1**: 글(ㄹ · ㄱ 한 획 안의 가로·세로) 꺾임 교점 깔끔, 흠(ㅇ · ㅁ) 매끈, 설(ㅅ) 사선 중간, 둥글기 1 + 대비 +60 굴림이 폭 따라 다름, 굵기 700 + 부리 — 부리가 굵어진 기둥 폭에 맞음.
- **G2**: `tsc` · eslint. 단위(가로 0.5 · 세로 1.5 · 45° 1, ㄱ 안팎 교점 좌표, 대비 0 = 전과 같음), parity 대비 ±0.6 × 둥글기 0 · 1 다섯 글자(가장자리 0.13–0.29유닛, 상자 같음), 계약 해시 그대로. e2e 대비 줄(막대 → 저장 → 되돌리기) 통과.
- **사실 — 남의 실패**: `global-style-tone` e2e에서 HEAD `482db76`(다른 세션 도구 커밋) 뒤로 `jamo-layout-mode`가 열자마자 안 보이고, 패널을 연 채로는 `focus-canvas`의 SVG stroke 경로가 없어 마지막 줄이 깨진다. HEAD `54e795a`에서는 같은 줄이 통과했다. 격리 워크트리로 확인.
- **미결정**: 최소 잉크 간격 경고는 대비를 모른다. `CONTRAST_STRENGTH` 0.5(최대 3 : 1)가 맞는지 — G3.
