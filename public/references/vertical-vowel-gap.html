Noto 원본과 우리 Y 3안을 같은 조건으로 비교

네 칸 모두 Noto `가`의 X 빈 띠 149.9 units와 획 75를 사용합니다. 빨간 점선은 각 안의 잉크 상·하단입니다. Noto envelope는 표시용 권장안일 뿐 production Y·5선에는 반영하지 않았습니다.

01 · 조건부 전체 비교

무료폰트 원본 6종 + Noto-envelope 표시안

무료폰트는 원본 좌표이고, 우리 네 안에는 위에서 제안한 동일 Y 표시안만 적용했습니다. 이 구역의 X 숫자는 이전 가설이며 아직 고르지 않습니다.

02 · 판정 범위

이번에 결정할 것

`ㄱ+ㅏ` 무받침 prototype의 다음 X 검수에서 사용할 비교 화면 전용 Y 크기·위치.

  • 고정: UPM·baseline·획 75·X 빈 띠
  • 비교: Current / Body-fit / Noto envelope
  • 권장: Noto envelope 표시안

이번에 판단하지 않는 것

Y 표시안을 골라도 서체의 실제 세로 설계가 승인되는 것은 아닙니다.

  • A/B/C X 간격과 B 동결
  • 5선·ㅏ 가로팔·ㄱ 내부 획 위치
  • production starter·OTF·다른 자소
03 · 판단 기준

크기·위치와 내부 5선을 분리합니다.

공통 조건: UPM 1000, ascender 880, descender -120, baseline y=880, 획 75입니다. Current는 잉크 207.5…792.5, Body-fit은 75…925, Noto envelope는 52.7…957.1입니다. Y 좌표만 다시 계산하고 획과 X 간격은 바꾸지 않았습니다.

Noto envelope가 다음 X 비교에는 가장 통제된 안이지만, 이것은 외곽 상·하단만 맞춘 표시 보정입니다.

아직 맞지 않는 것
Noto `ㅏ` 가로팔 중심은 약 454.4이고 envelope 표시안의 팔은 504.9입니다. 외곽을 맞췄다고 내부 중심선·5선까지 맞은 것으로 보지 않습니다.
