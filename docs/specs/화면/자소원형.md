# 자소 원형 · 초성 ㄱ

초성 ㄱ 하나의 원형을 안쪽 기준선 네 개와 면 셀로 고치는 화면. 다른 자소로 바꿀 수 없다(ㄱ 고정).
**여기서 고친 값은 앱의 글자와 폰트 추출에 닿지 않는다.** 형태 저장소에 남고 이 화면 · 조합별 결과 화면의 미리보기에서만 보인다.
들어오는 길: 자소 편집 도구 줄(`자소편집 2.2`), 자소 현황, 조합별 결과.

## 1. 셸
- 1.1 문장 보정으로 · 탭 이동 · 상태 표시 · 되돌리기 — 이동은 `자소편집 1.1` `자소편집 1.4`와 같음. 상태 표시는 프로젝트 이름과 저장 상태(`저장 중…` `기기에 저장됨` `프로젝트 저장됨` `저장 확인 필요`). 되돌리기 · 다시 하기는 형태 저장소의 기록을 한 단계씩, 조합별 결과 화면과 기록을 같이 쓴다 · 되돌린 뒤 바로 저장

## 2. 머리
- 2.1 수정 범위 — `초성 ㄱ · 이 자소의 원형 · 단독 · 초성 조합 7개` 고정 표시(면 채우기일 땐 6개). `범위 변경`은 늘 꺼져 있다
- 2.2 형태 시스템 상태 · 저장 결과 — 상태는 연결 전 / 마스터 몇 개 연결됨 / 저장 데이터 확인 필요. 저장 결과는 `이 기기에 저장했습니다` / `프로젝트와 기기에 저장했습니다` / 실패 글. 형태 시스템이 없으면 여기서는 시작할 수 없고 편집이 전부 막힌다

## 3. 캔버스
- 3.1 결과 윤곽 — 초성 ㄱ 원형을 최종 윤곽으로 그린다. 끄는 중인 값도 바로 반영
- 3.2 보기 버튼 — `결과 윤곽`은 눌린 모양뿐이고 `원본 선` `기준선` `점유 면`은 늘 꺼져 있다
- 3.3 기준선 핸들 끌기 — 안쪽 왼 · 오른 · 위 · 아래 네 선. 0.005 단위로 붙고, 손을 떼면 단독 ㄱ과 초성 ㄱ 원형에 함께 저장 · 형태 저장소(이 기기 + 열린 프로젝트가 있으면 서버). 핸들은 키보드로 못 움직인다
- 3.4 면 셀 채우기 · 지우기 — `면 채우기` 도구일 때만. 처음 누른 칸이 비었으면 채우기, 차 있으면 지우기로 정해지고 끌고 지나간 칸이 손을 뗄 때 저장된다 · 형태 저장소

## 4. 정밀 조절 서랍
- 4.1 여닫기 — 접힘 → 중간 → 펼침. 면 채우기 도구일 땐 서랍이 없다
- 4.2 기준선 고르기 — 왼쪽 · 오른쪽 · 위 · 아래
- 4.3 값 슬라이더 — 지금 값(UPM)이 보이고, 끌거나 방향키로 옮긴 뒤 손을 떼면 3.3과 같은 곳에 저장
- 4.4 편집 불가 안내 — 고칠 수 없는 상태면 자물쇠 카드와 사유

## 5. 조합 비교
- 5.1 조합 카드 — ㄱ 가 고 과 각 곡 곽(면 채우기일 땐 ㄱ 빼고 여섯). 원형을 고친 결과가 카드에 바로 반영된다. 누르면 관찰 대상만 바뀐다
- 5.2 조합별 결과 확인 — 관찰 중인 글자로 `/workspace/jamo/result?char=…`에 간다

## 6. 도구 줄
- 6.1 선택 — 기준선 편집으로 돌아간다
- 6.2 면 채우기 — 면 편집으로 바꾼다. 면 격자를 못 만들면 꺼지는데 사유는 어디에도 안 나온다
- 6.3 중심선 · 레일 — 늘 꺼져 있다
