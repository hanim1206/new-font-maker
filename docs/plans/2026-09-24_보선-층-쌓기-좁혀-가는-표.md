# 보선 층 쌓기: 단계마다 좁혀 가는 표

- **이번에 비교하는 것**: 지금 페이지의 표(단계를 누르면 해당 축 머리·칸이 켜짐)와, 단계를 넘길 때마다 조건에 안 맞는 글자가 빠지며 마지막에 한 글자만 남는 애니메이션 표.
- **이번 승인으로 바뀌는 것**: 설명 페이지 `보선 층 쌓기`의 왼쪽 표 하나. 표는 고르는 도구가 아니라 "이 층이 몇 글자에 걸리는지" 보여 주는 무대가 된다.
- **바뀌지 않는 것**: 앱 코드와 모델 값, 페이지의 캔버스 · 단계 버튼 · 네 변 값 표, 앱 검수 탭.

## 지금 상태

**사실**
- 페이지: https://claude.ai/artifact/Axsgdzn6yncnUAgEpWwYwB (Version 59). 소스는 `docs/plans/assets/layer-stack.html`(단일 HTML, 질감 타일 포함). 고칠 때는 이 파일을 고쳐 같은 URL로 다시 올린다(`Artifact` 도구 `url` 인자). 아티팩트가 레포보다 앞서 있으면 `action: "read"`로 받아 파일부터 맞춘다.
- 데이터는 페이지에 들어 있다: 노토 모델 6개 레이아웃(`public/noto-preset/model.json`의 initial/final roleFaces, medial face·span), 홀자 두께, 자모 획(`src/data/baseJamos.json`), 질감 타일 2장(JPEG data URI).
- 단계: ⓪ 네모꼴(폰트 전체, 앱은 맨 끝에 선형 변환) · ① 뼈대(레이아웃 대표값) · ② 첫닿자 몫 · ③ 홀자 몫 · ④ 받침 몫 · ⑤ 쌍 보정 · ⑥ 사용자 옵션. ①–⑤는 더하기라 순서가 결과를 안 바꾼다. 순서가 결과를 바꾸는 건 ⑥의 `이 자리에 맞추기`(좁은 쪽이 이김)뿐.
- ①–⑤ 값은 전부 **레이아웃마다 따로** 있다(자모 몫도 레이아웃 안의 몫). ②·⑤는 첫닿자에 묶이고, ③·④는 첫닿자와 상관없이 같은 값.
- 지금 표 = 레이아웃 탭 · 받침 칩 · 행 첫닿자 × 열 그 레이아웃의 홀자. 단계마다 값을 정하는 축만 좁혀 켜고 나머지 축은 전부 켠다.

**미결정**
- 좁히는 기준. `봉`이면:
  - **A. 누적 교집합** — 여기까지 상자 자리가 같은 글자만 남긴다. 2,565 → 135 → 27 → 1. 이야기가 깔끔하지만 "③은 첫닿자와 상관없이 ㅗ 513자 전부"가 안 보인다.
  - **B. 교집합 + 흔적** — 남는 글자는 진하게, "이 층만 보면 같이 받는 글자"는 빠진 자리에 옅게 잠깐 뜬다.
  - AI 추천: A 기본, 단계를 길게 누르거나 올려 두면 B의 흔적.

## 하려는 것

1. 오른쪽에서 글자 입력 또는 🎲 → ⓪부터 자동 재생. 단계 버튼으로 앞뒤 이동, 뒤로 가면 빠진 글자가 돌아온다.
2. 단계마다 조건에 안 맞는 글자는 흐려지며 빠지고, 남은 글자는 빈자리를 메우며 모이고 조금씩 커진다. 숫자가 같이 준다. 조건 칩(`첫닿자 ㅂ만`, `+ 홀자 ㅗ`)을 붙인다.
3. 11,172자는 점(캔버스 2D)으로, 수백 자 이하부터 실제 글자(DOM)로 바꾼다. 처음엔 레이아웃 6덩이로 모아 ①에서 덩어리 하나만 남는 게 보이게.
4. 마지막 한 글자가 커지며 캔버스 쪽으로 넘어간다.
5. `prefers-reduced-motion`이면 애니메이션 없이 바로 바뀐다.

## 같이 넘기는 것 (이 플랜 밖, 결정 대기)

- **획 편집 자소 바로 옮기기**: ㄱ 획 편집에서 ㅏ로 가려면 레이아웃을 거쳐야 한다(09-21 결정, `CalibrationSentenceEditor.tsx`의 `lockedPart`). 제안: 옅게 보이는 다른 자소를 누르면 잠금이 그 자소로 옮겨 가고, `←`는 획 편집에 처음 들어온 뒤 전부를 취소. 결정 뒤집기라 사용자 `구현해` 대기.
- **보선이 레이아웃끼리 어우러지는지 보기**: 분류표 12·13. 첫 단계로 캔버스 옆 6개 레이아웃 카드에 같은 보선을 표시하는 안. 사용자가 P2 유지로 둠.
- **넓은 범위 옵션의 비율 Δ**: 레이아웃을 넘는 옵션을 절대 u 대신 상자 폭 비율로 더하는 안. 저장 형식이 바뀌므로 배포 전 여부 미정.
