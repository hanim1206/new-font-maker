# 프리셋 폰트 공방 제작 흐름

목표는 실험실을 많이 만드는 것이 아니다. 비전문 사용자도 바로 시작할 수 있는 완성도 높은 네모꼴 프리셋을 만들고, 이후 자기 개성을 안전하게 더할 수 있게 하는 것이다.

## 도구 역할

- 레퍼런스 랩은 무료폰트 윤곽을 관찰하고 프리셋 근거를 만드는 내부 계측기다.
- 제작 공방은 승인된 배치 골격과 조형 문법으로 실제 자소와 글자를 만드는 곳이다.
- 목공방 UI는 확정된 명령을 자·가이드·다이얼·절삭 도구 같은 직접 조작으로 표현하는 제품 인터페이스다.

세 도구를 한 화면이나 한 단계에서 동시에 설계하지 않는다.

## 길을 잃은 이유

- 레퍼런스 관측, 평균 집계, 후보 디자인, 제품 반영을 한 실험에 섞었다.
- 완성 폰트 윤곽에 들어 있지 않은 다섯 가로선의 의미까지 자동 복원하려 했다.
- 중립 고딕과 개성이 강한 스타일 폰트를 한 평균으로 섞으려 했다.
- 레이아웃, 선·면 조형, 문맥 보정, 목공방 UI를 동시에 진행해 결과가 나쁠 때 원인을 구분하기 어려웠다.
- 실제 글자 검수보다 데이터 구조와 구현 범위가 먼저 커졌다.

## 프리셋을 이루는 세 층

1. 배치 골격: 윗선·첫닿윗선·중심선·받침밑선·밑선과 X 분할, 자소 간격, 좌우 여백. 밑선은 typography baseline이다.
2. 조형 문법: 획 굵기, 각도군, 곡률, 모서리, 속공간, 선·면 결합 규칙.
3. 문맥 보정: 초성의 열림/닫힘, 세로·가로·섞임홀자, 받침 형태에 따른 예외.

다섯 선만으로 좋은 프리셋이 완성되지는 않지만, 모든 조형이 공유할 배치 골격이 된다.

## 진행 순서

### 1. 기준 골격

무료 고딕의 실제 윤곽을 같은 좌표계와 baseline에서 비교한다. 레퍼런스 랩에서는 미리 정의한 측정 영역을 클릭해 선 위치, 잉크 외곽, 자소 간격, 획 굵기를 확인한다. 자유 드래그는 측정 정의를 고치는 보조 기능으로 둔다.

중립 폰트의 중앙값과 분포는 보편적 범위를 보는 근거로 쓰고, Gowun Dodum·Black Han Sans 같은 개성 강한 폰트는 별도 스타일 목표로 본다. 전체 단순 평균을 정답으로 쓰지 않는다.

### 2. 선 기반 기준 프리셋

현재 작동하는 선 엔진으로 배치 골격과 공간 규칙을 먼저 검증한다. 이는 최종 표현을 제한하는 결정이 아니라 면 프리셋을 비교할 내부 기준자다. 한 번에 변수 하나만 바꾸고 실제 글자 후보를 확인한다.

첫 실험본은 여러 폰트의 중앙값을 기다리지 않고 Noto Sans KR 한 벌로 만든다. 우리 자모 형태는 유지하고, 검증된 Noto 공간값만 덮어쓴다. 미검증 후보는 임시값, 아직 추출하지 않은 필드는 기존값으로 표시해 섞인 근거를 숨기지 않는다. 목적은 Noto 복제가 아니라 `외부 관측 → 배치 골격 → 실제 문장·OTF → 사용자 보정` 제작 흐름을 먼저 통과시키는 것이다.

레거시 닿자 기준선은 이 실험본의 임시 관측값으로 사용할 수 있다. 같은 글자·같은 구조 역할이라면 후속 자동 추출값과 가까워야 하지만, 레거시 여섯 문맥은 선택 홀자와 실제 받침을 축약하므로 다른 조합까지 같은 값이라고 가정하지 않는다. 새 닿자 추출값이 생기면 동일 글자·동일 역할끼리 비교하고, 차이가 확인된 필드만 교체한다. 사용자 검수를 통과하기 전에는 출시 기본값으로 승격하지 않는다.

이용제의 닿자 분류는 첫 실험본의 수치를 만드는 규칙으로 바로 넣지 않는다. 같은 면적·시각 공간·홀자와의 상대 위치를 가진 닿자끼리 대표 글자를 묶어 보는 검수표로 사용한다. 여러 그룹에서 반복되는 보정이 확인될 때만 후속 문맥 규칙 후보로 올린다. 실험본은 사용한 레거시 스냅샷 버전을 고정하고, 레거시나 자동 추출값이 갱신돼도 기존 프리셋을 자동 변경하지 않는다. 새 값으로 별도 후보를 만든 뒤 차이와 실제 글자를 함께 확인한다.

### 3. 면 기반 기하학 프리셋

승인된 배치 골격은 고정한다. 면 캔버스의 채우기·사선·곡선을 Shape System과 FinalGlyphInk에 연결한다. ㄱ·ㅁ·ㅇ·ㅏ·ㅗ처럼 직선, 속공간, 곡선, 조합을 대표하는 소수 자소부터 수직으로 완성한다.

셀 점유 자체를 스타일로 보지 않는다. 공통 밴드 굵기, 각도군, 곡률군, 모서리, 속공간 규칙이 기하학적 일관성을 만든다.

### 4. 문맥 보정과 출력

대표 조합에서 초성·중성·받침 보정을 승인한 뒤 자소 역할 전체로 확장한다. 화면 SVG와 실제 preview OTF를 나란히 검수하고, 문장 검수를 통과한 후보만 프리셋 원본에 반영한다.

### 5. 목공방 UI

명령과 토큰이 안정된 뒤 외형을 입힌다. 다섯 선과 슬롯은 자와 펜스, 굵기·곡률·각도는 눈금 있는 다이얼, 채우기·절삭·사선·곡선은 물성 있는 도구로 대응한다. 장식용 노브는 두지 않고 모든 조작은 실제 값, 미리보기, 한 번의 Undo transaction에 연결한다.

## 사용자 확인 단위

각 화면 맨 위에 다음 세 문장을 고정한다.

- 이번에 비교하는 것
- 이번 승인으로 바뀌는 것
- 이번에 바뀌지 않는 것

실제 글자를 먼저 보여 주고 수치와 도표는 근거로 둔다. 한 단계에서 판단할 변수는 하나, 확인 질문은 세 개 이하로 제한한다. 사용자 승인 전에는 다음 단계와 production 값을 바꾸지 않는다.

## 다음 확인 단위

첫 세션은 `baseline을 기준으로 한 글자 외곽의 위·아래 관계`다. 대표 글자와 무료폰트 윤곽에 baseline, 잉크 윗끝, 잉크 밑끝만 겹쳐 보여 준다. 여기서는 후보를 고르지 않고 같은 구조를 제대로 측정하는지만 확인한다. 측정 정의가 승인되면 분포를 집계하고 우리 Shape의 후보를 만든다.
