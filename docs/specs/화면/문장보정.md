# 문장 보정

셸 없는 옛 첫 화면. 문장에서 글자를 골라 획을 고친다. 자소 편집과 같은 편집기를 셸 없이 쓴다. 앱을 열면(`/`) 이제 `자소편집`으로 넘어가고, 이 화면은 `/calibration`과 모르는 주소에서만 뜬다. 셸에서 오는 링크는 없앴다(제거 예정).
주소: `?char=간`으로 글자를 바로 연다. `mode=layout`은 여기서 안 먹는다.

자소 편집과 다른 점만 적는다. 나머지는 `자소편집`의 같은 이름 영역과 똑같다.

## 1. 머리
- 1.1 제목 — `문장에서 글자를 직접 다듬으세요`. 셸이 없어서 탭(자소 · 검수)도, 프로젝트 이름도 없다
- 1.2 도구 줄 — 자소 원형 화면 열기, OTF 추출, 형태 규칙, 글로벌 스타일 · `자소편집 2.2~2.5`와 같음
- 1.3 되돌리기 · 다시 하기 — 도구 줄 안에 있고, 되돌릴 수 있는 횟수가 숫자로 붙는다
- 1.4 `획 · 레이아웃` 전환이 없다 — 이 화면엔 레이아웃 모드(`자소편집 6`)가 없다

## 2. 문장 줄
- `자소편집 3`과 같음

## 3. 획 캔버스
- `자소편집 4`와 같음

## 4. 트랙패드
- 4.1 획 · 점 · 핸들 옮기기, 비율, 최소 잉크 간격, 획 도구 — `자소편집 5.1~5.4`와 같음
- 4.2 자소 통째로 옮기기 · 비율 — 자소 전체를 잡으면 여기서는 늘 트랙패드로 옮긴다(`자소편집 5.5`의 안내가 없다). 같은 구조의 글자에 함께 적용 · 레이아웃 스키마에 저장 · **글자가 모델 상자로 그려지는 동안은 저장돼도 글자에 안 닿는다** · 폐기 예정

## 5. 형태 규칙 패널 · 글로벌 스타일 패널
- `자소편집 7` `자소편집 8`과 같음
