# 화면 트리

화면마다 파일 하나. 기능은 `이름 영역.번호`로 부른다(예: `자소편집 6.14`). 지금 있는 것만 적고, 만들 것은 `docs/plans/`에 둔다.
개발 서버에서는 오른쪽 아래 책 모양 버튼이 지금 주소의 명세를 띄운다.

## 제품 화면

```
/fonts  내폰트 ──────── 로그인하면 처음. 목록 · 새로 만들기 (게이트 꺼지면 없음)
/  → /workspace/jamo 로 넘김 (앱을 열면 자소편집이 처음)
│
└─ 셸 = 폰트 덱 (머리 `‹ 내 폰트` · 이름 · 되돌리기, 하단 탭 셋: 폰트 · 자소 · 검수 / 햄버거 없음)
   ├─ /workspace/font          폰트          이름 · 마지막 고침 · OTF 추출 · 글로벌 스타일(문장 표본 + 탭 넷)
   ├─ /workspace/jamo          자소편집      획 · 레이아웃 두 모드. 실제로 글자를 고치는 곳
   └─ /workspace/review        검수격자      11,172자 표. 고치지 않고 자소편집으로 넘김

프로덕션에서 모르는 주소는 자소편집으로 넘긴다. `/workspace/…` 아래 모르는 주소만 안내 화면.
```

| 화면 | 주소 | 상태 | 한 줄 |
|---|---|---|---|
| [[내폰트]] | `/fonts` | 사용 중 | 로그인 뒤 메인. 폰트 목록 · 새로 만들기 · 이름 · 삭제 |
| [[폰트]] | `/workspace/font` | 사용 중 | 폰트 덱 첫 화면. 이름 · 추출 · 글로벌 스타일 |
| [[자소편집]] | `/workspace/jamo` | 사용 중 | 같은 편집기 + 셸 + 레이아웃 모드 |
| [[검수격자]] | `/workspace/review` | 사용 중 | 전체 글자를 표로 훑고 고칠 글자를 연다 |

## 넘어가는 길

- 로그인 게이트: Supabase 설정이 있으면 모든 주소 앞에서 세션을 본다. 없으면 초대 코드 입력 화면, 들어오면 내폰트. 편집 주소를 바로 열거나 새로고침하면 마지막 폰트로 바로 열고, 고른 폰트가 없으면 내폰트로. 셸 머리 `‹ 내 폰트` → 내폰트, 로그아웃은 내폰트 4.1
- 셸의 모든 화면 → 폰트 · 자소편집 · 검수격자(하단 탭). 화면 이동은 새로고침 없이 되어 되돌리기 기록이 남는다
- 자소편집 ⇄ 검수격자: 검수에서 글자를 열면 `자소편집` 레이아웃 모드(`?char=…&mode=layout`)
- 글로벌 스타일 `레거시 스냅 획` → 형태그리드랩
- 옛 주소: `/workspace/skeleton`(뼈대, 09-21 제거) · `/workspace/jamos` `/workspace/jamo/master` `/workspace/jamo/result`(자소현황 · 자소원형 · 조합별결과, 09-25 제거, 명세는 `docs/archive/`) → 자소편집, `/workspace/review/glyph` → 자소편집 레이아웃 모드
