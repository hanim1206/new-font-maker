# 변화량 모델 상호작용 v2 착수

[2026-09-15_변화량-모델-v1-설계](./2026-09-15_변화량-모델-v1-설계.md)의 후속. v1 주효과 모델과 corpus 랩 겹쳐보기가 끝난 뒤, 남은 큰 예외의 원인인 **첫닿자×홀자 상호작용**을 선택적으로 넣어보는 단계다. 새 세션이 이 문서만 읽고 이어갈 수 있게 정리한다.

## 왜

v1은 `대표값 + 첫닿자 + 홀자 + 받침` 주효과만 푼다. 큰 예외를 오버레이로 훑었더니 랜덤이 아니라 **ㄱ계 초성(특히 쌍기역 ㄲ) × 특정 홀자** 셀에 뭉친다. 단일 ㄲ 효과(층 전체 홀자 평균 중앙값 하나)가 홀자별 재배치를 못 담기 때문. 사용자가 꼭류(ㄲ+ㅗ)에서 눈으로 오차를 짚어냈고 데이터로 확인됐다.

## 확인된 신호 (실측)

첫닿밑선(`initial.roleFaces.bottom`), 가로받침 층(`bottom-final`), 각 셀 n=27:
- ㄲ+ㅗ 잔차 중앙 **−47u**, ㄲ+ㅛ **−47u** (ㄱ 형제는 −24·−31로 같은 방향·작음)
- ㄲ+ㅜ·ㅠ·ㅡ는 −1~+13로 작음 → ㅗ·ㅛ에서만 큼
- 27받침 전부에 걸쳐 일정 = 구조적. 쌍기역 넓은 폭이 ㅗ·ㅛ 밑에서 더 눌려 바닥이 위로 올라앉음.

같은 ㄱ계×ㅗ·ㅛ가 다른 타깃에서도 반복:
- 보선 가시길이 가로받침: ㄱㅗ·ㄱㅛ·ㄲㅗ·ㄲㅛ 셀 전체 +80~170u (크기로 보아 상호작용이 아니라 ㄱ 다리와 ㅗ 보 접합의 형태 전환 의심 — 윤곽 확인 필요)
- 첫닿왼선 혼합받침: ㄱㅢ·ㄲㅝ·ㅋㅘ·ㄱㅝ 셀 전체 +12~19u

무받침 가로(`bottom`)는 셀당 n=1이라 판정 불가. 받침 문맥에서만 보인다.

## 해볼 것

1. **ㄱ계×ㅗ·ㅛ 상호작용 스파이크**: `build_variation_model.py`에 특정 (첫닿자군, 홀자) 셀만 상호작용 항을 추가하는 선택적 경로를 넣고, 그 무리 예외가 잔차→0으로 흡수되는지 측정. 전 셀 상호작용은 v1에서 배제한 이유(주효과 흡수·편집 Δ 단위 붕괴) 그대로라 **셀 근거가 있는 것만** 투입한다.
2. **판정 규칙 v1.1 (뭉침 신호)**: 현재 규칙은 "상위 셀이 예외의 50% 이상"이라 셀 171~513개 층의 중간 뭉침을 놓친다(첫닿밑선 세로받침 상위 셀 잔차중앙 전부 10u 초과인데 분산으로 분류됨). "상위 셀 예외 점유율" 대신 "|셀 중앙값| > 임계인 셀 수"를 신호로 쓰는 안. 산출물에 두 지표 다 있어 규칙만 바꾸면 됨.
3. **보선 가시길이 ㄱㅗ류 윤곽 확인**: +80~170u는 상호작용이 아니라 형태 전환일 수 있음. 실물 윤곽 대조 먼저.

## 지켜야 할 원칙

- 실측은 안 덮는다. 상호작용을 넣어도 임계 초과 잔차는 예외로 실측 보존.
- 효과항 = 편집 단위. 상호작용을 넣으면 편집식 `실측 + Σ바꾼 효과항 Δ`에서 그 셀의 Δ 정의가 어떻게 되는지 먼저 정한다. 안 그러면 "ㄲ 밑선 내리기" 같은 편집이 꼬인다. → [[#편집 Δ (해소)]]
- 승인 57자·기존 후보 실측 불변. 산출물은 `analysis/` 아래 새 버전으로.
- median polish 유지(평균 회귀 금지).

## 편집 Δ (해소)

셀 보정에 별도 편집 Δ 정의는 필요 없다. 실측이 정확히 `대표값 + Σ효과 + 셀보정 + 잔차`라, 셀 보정은 이미 실측 안에 들어있다. 편집식이 `편집 후 = 실측 + 바꾼 주효과 Δ`이므로, 주효과를 바꾸면 그 자모군 전체가 평행 이동하고 셀 오프셋은 그대로 따라간다. "ㄲ 첫닿 −10"을 하면 ㄲㅗ도 −10만 더해지고, ㄲㅗ에 박힌 −47 구조 오프셋은 보존된다. 셀 보정 = 주효과 예측 대비 상대 오프셋이라 순차 구조가 꼬임을 이미 막는다.

두 불변 다 지켜짐: 실측 보존(편집은 실측에 대한 Δ), 편집 단위 = 주효과(셀 보정은 Δ에 안 들어감).

남는 결정: "ㄲㅗ만 더 내리기"(셀 단위 조정)는 열지 않는다. 셀은 편집 단위가 아니므로 그런 미세조정은 그 글자 실측 직접 편집(예외 경로)으로 간다. 셀 보정항을 편집 가능하게 만들면 셀도 편집 단위가 돼 "잔차처럼 딸려감" 원칙이 깨진다. 편집 단위를 늘리지 않는다.
