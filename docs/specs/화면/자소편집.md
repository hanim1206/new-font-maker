# 자소 편집

문장에서 글자 하나를 골라 그 글자의 획이나 배치를 고친다. 셸의 `자소` 탭.
주소: `?char=간`으로 글자를, `&mode=layout`으로 레이아웃 모드를 바로 연다. 글자가 없으면 `과`.

## 1. 셸
- 1.1 문장 보정으로 — 왼쪽 위 링크, `/`로 간다
- 1.2 상태 표시 — 프로젝트 이름과 `획 편집` / `레이아웃 수정`
- 1.3 되돌리기 · 다시 하기 — 이 화면에서 한 편집(획, 옛 배치, 획 스타일, 배치 Δ)을 한 단계씩 · 기록은 화면을 떠나면 사라진다
- 1.4 탭 이동 — 뼈대 · 자소 · 검수. 홈 · 출력 · 더보기는 아직 꺼져 있다

## 2. 도구 줄
- 2.1 `획 · 레이아웃` 전환 — 아래 편집 영역을 5번(획)과 6번(레이아웃) 사이에서 바꾼다. 글자가 모델 상자로 안 그려지면 `레이아웃`은 꺼진다
- 2.2 자소 원형 화면 열기 — `/workspace/jamo/master`
- 2.3 OTF 추출 — 지금 작업을 폰트 파일로 내려받는다. 진행 · 완료 · 실패가 버튼에 뜬다
- 2.4 형태 규칙 — 고른 자모의 획 순서 · 방향 · 연결과 끝점 부리를 패널로 본다(7번). 고른 게 없으면 꺼짐
- 2.5 글로벌 스타일 — 글자 네모꼴과 획 스타일 패널(8번)을 여닫는다

## 3. 문장 줄
- 3.1 글자 고르기 — 누른 글자가 편집 대상이 된다. 문장은 지금 획과 배치로 그려져서 고치는 대로 바뀐다
- 3.2 예시 문장 바꾸기 — 주사위, 준비된 문장 중 하나로
- 3.3 직접 입력 — 문장을 직접 친다. 고른 글자가 문장에서 사라지면 첫 한글로 옮겨 간다 · 문장은 저장되지 않는다
- 3.4 충돌 안전 표시 — 잉크 간격 때문에 자동으로 눌린 글자, 지금 움직임을 막고 있는 글자에 표시가 붙는다

## 4. 획 캔버스 (획 모드)
- 4.1 깔개 — 눈금, 글자몸 상자, 기준선, 부품 상자, Noto 고스트가 잉크 아래에 깔린다. 글자와 UPM 표시
- 4.2 자소 고르기 — 획을 누르면 먼저 그 자소 전체가 잡힌다(부품 상자가 진해짐)
- 4.3 획 고르기 — 잡힌 자소의 획을 다시 누르면 그 획이 잡히고 꼭짓점이 보인다
- 4.4 꼭짓점 · 곡선 핸들 고르기 — 점을 누르면 점이, 점의 핸들을 누르면 핸들이 잡힌다. 빈 곳을 누르면 풀린다
- 4.5 꼭짓점 여러 개 고르기 — 트랙패드에 한 손가락을 댄 채 점을 누르면 추가된다(같은 자모 안에서만)
- 4.6 `Noto 고스트` 켜고 끄기 — 켜면 Noto와의 차이(xor %)도 보인다 · 이 기기에 기억
- 4.7 `Noto 배치` 켜고 끄기 — 글자를 모델 상자로 놓을지 옛 스키마로 놓을지. 지금 어느 쪽인지 표시 · 이 기기에 기억 · **폐기 예정**

## 5. 트랙패드 (획 모드)
- 5.1 옮기기 — 한 손가락으로 고른 획 · 점 · 핸들을 옮긴다. 값(x · y)이 뜨고 눈금에 붙는다 · 자모의 기본 획에 저장(같은 자모를 쓰는 모든 글자에 닿음)
- 5.2 비율 바꾸기 — 두 손가락으로 고른 획의 가로 · 세로 비율을 바꾼다 · 자모의 기본 획에 저장
- 5.3 최소 잉크 간격 — 옮기다 문장 속 다른 글자에서 획이 너무 붙으면 거기서 멈추고 어느 글자 때문인지 알려 준다
- 5.4 획 도구 — 선 추가, 직선 ↔ 곡선, 가까운 획과 잇기, 끊기, 획 · 꼭짓점 삭제 · 자모의 기본 획에 저장
- 5.5 자리는 레이아웃에서 — 자소 전체를 잡으면 트랙패드 대신 안내가 뜨고, `레이아웃에서 고치기`를 누르면 그 부품이 켜진 채 6번으로 간다
- 5.6 (옛 경로) 자소 통째로 옮기기 · 비율 — `Noto 배치`를 껐거나 모델이 못 푸는 글자에서만. 같은 구조의 글자에 함께 적용 · 레이아웃 스키마에 저장 · **폐기 예정**

## 6. 레이아웃 편집 (레이아웃 모드)
- 6.1 부품 탭 — 첫닿자 · 홀자 · 받침 중 하나만 켠다. 켠 부품의 기준선과 상자만 제 색, 나머지는 회색
- 6.2 기준선 끌기 — 켠 부품의 기준선을 캔버스에서 끈다. 놓을 수 없는 자리(순서 · 간격 위반)면 경고가 뜨고 안 움직인다
- 6.3 붙기 — 끌다가 모델 값, 다른 기준선, 눈금 순으로 탁 붙는다. 붙은 자리가 캔버스 위에 뜬다
- 6.4 방향키 — 기준선을 잡고 방향키 1u, Shift와 함께 10u
- 6.5 옮긴 양 — 잡은 기준선은 주황 띠와 `+12u` 같은 숫자로, 나머지 옮긴 선은 작은 숫자로
- 6.6 잠긴 기준선 — 옮겨도 글자에 안 닿는 선은 점선이고 잡히지 않는다(`글자에 안 닿음`)
- 6.7 Noto 실측선 — 옅은 점선으로 참고만. 올리면 이름이 보인다
- 6.8 `Noto 고스트` 켜고 끄기 · 이 기기에 기억
- 6.9 복원 — 아직 적용 안 한 변경을 모두 되돌린다. 몇 개 바뀌었는지 표시
- 6.10 승인 표시 — 이 글자가 `승인 측정`인지 `실측만`인지
- 6.11 다른 글자 미리보기 — 기준선을 잡으면 같은 레이아웃 글자 여덟 자가 카드로 뜨고, 옮긴 만큼 얹힌 모습(검정)과 옮기기 전(주황 점선)이 보인다. 못 받는 글자엔 `Δ 안 닿음`
- 6.12 다른 글자 — 카드를 다음 여덟 자로 넘긴다
- 6.13 적용 범위 — `이 레이아웃`(기본) / `전체`
- 6.14 적용 — 옮긴 양(Δ)을 고른 범위에 저장한다. 문장 줄 글자가 바로 바뀐다 · 배치 Δ 저장소(이 기기)
- 6.15 저장된 Δ 지우기 — 고른 범위에 저장된 Δ가 있을 때만 보인다
- 6.16 자모 형태 Δ — 시작 · 끝 기준선(획 길이)을 옮기면 따로 표시되고 `이 자모로 올리기`로 같은 자모 글자에 미리 본다 · **저장되지 않는다**

## 7. 형태 규칙 패널
- 7.1 획 정보 — 고른 자모의 획 그림과 자동으로 계산된 순서 · 주방향 · 연결 · 접선
- 7.2 끝점 형태 적기 — 끝점마다 부리(원형 · 사각 · 각진, 크기 · 각도), 형태의 예절(글), 적용 범위를 적는다 · 이 기기에 메모로만 남고 **글자에는 반영되지 않는다**

## 8. 글로벌 스타일 패널
- 8.1 글자 네모꼴 — 가로 · 세로 크기. 범위는 `폰트 전체` / `현재 레이아웃`, 되돌리기 버튼 · 레이아웃 저장소
- 8.2 획 생성 규칙 — 붓촉형 · 절단 끝 · 레거시 스냅 획 중 하나. 문장과 캔버스에 미리 보이고 손을 떼면 적용 · 글로벌 스타일 저장소
- 8.3 붓촉 — 원형 · 납작형 · 네모형, 납작함과 각도
- 8.4 절단 끝 — 절단각과 모서리 곡률
