# 레이아웃 모드 세로 예산 — 범위 띠 합치기 + 상단 줄이기

- **이번에 비교하는 것**: 쌓인 오버라이드가 스크롤해야 보이는 지금과, 캔버스 바로 아래 첫 화면에서 보이는 것.
- **이번 승인으로 바뀌는 것**: ① 범위 칩과 오버라이드 목록이 가로 띠 하나가 된다. 자모 고르기는 시트로 뜬다. ② 도구 줄이 머리의 `…` 메뉴로 들어가고, 레이아웃 모드의 보정 문장이 한 줄이 된다.
- **바뀌지 않는 것**: 저장 키·층·합산(`layoutDeltaStore`), 적용 흐름과 하단 바(한 번 눌러 적용), 표본 카드 8장과 실시간 미리보기, 캔버스 편집, 획 편집 화면, 원칙, production 값.

출처: 9/21 논의. 사용자 — "상단이 너무 높아서 하단 오버라이드가 안 보인다". `적용` 누를 때 범위 팝업은 버림: 버는 높이가 50px뿐이고 원칙(기본은 자동, 좁히기만 사용자)과 부딪힌다.

## 지금 상태

**사실** (390×844, 멈, Playwright로 잼)
- 고정: 머리 66 + 도구 줄 57 + 보정 문장 104 = 위 227, `획 고치기` 65 + 내비 58 = 아래 123. 합 350(41%).
- 스크롤 영역 494 중 캔버스 346. 전파 절에 남는 148은 칩 줄 · 빈 Δ 줄 · `다른 글자` 줄이 쓰고 표본 카드는 머리만 보인다. 오버라이드 목록은 표본 8장 아래라 160px 넘게 접힌다.
- 범위 칩(`이 레이아웃 · 이 자모만 · 전체`)과 오버라이드 카드(`전체 · 이 레이아웃 · 자모별`)는 같은 축이다. 카드를 누르면 이미 칩이 그 카드로 맞춰진다(`selectOverride`). 같은 것을 위아래로 두 번 그리고 있다.
- 도구 줄 네 개(자소 원형 · OTF 추출 · 형태 규칙 · 글로벌 스타일)는 `CalibrationSentenceEditor`의 `actions`. 셸 머리의 `…`(`MobileWorkspaceShell`)는 지금 비활성 자리표시다.
- 보정 문장은 `flex: 0 0 104px` 두 줄 고정, 오른쪽에 버튼 둘이 세로로 놓인다.

## 하려는 것

**A. 범위 띠** (`ReviewPropagationCards` · `LayoutOverrideList`)
1. 캔버스 바로 아래 가로 스크롤 띠 하나. 앞의 셋은 지금 칩 그대로 `이 레이아웃 · 이 자모만 · 전체`, 그 뒤에 자모 칩(저장된 것 + 지금 고른 것)이 부품 · 자모 순으로 붙는다.
2. 저장된 Δ가 있는 칩은 부품 색으로 차고 Δ 요약 한 줄과 ×가 붙는다(`ㄴ · 5자 / 윗변 +20u 외 1`). 없는 칩은 테두리만.
3. 칩 누르기 = 적용 범위 고르기 = 표본 8장이 그 글자로. 지금 카드 누르기와 같은 동작이고 하단 바 글씨(`ㄴ에 적용`)도 그대로 따른다. × = 그 층만 지우기(Undo 됨).
4. `이 자모만`을 누르면 자모 고르기 시트가 뜬다(초성 19 · 홀자 21 · 받침 27, 여러 개, 마지막 하나는 못 끔). 인라인 자모 줄은 없앤다.
5. 아래 `이 레이아웃의 오버라이드` 절은 없앤다. `다른 글자`는 Δ 줄 오른쪽 끝으로 옮겨 한 줄을 줄인다.

**B. 상단 줄이기** (`WorkspaceChrome` · `CalibrationSentenceEditor`)
1. 도구 줄을 없애고 네 도구를 머리 `…` 메뉴에 넣는다(−57). 획 편집 화면도 같이 바뀐다. 추출 진행 상태는 `…` 단추에 점으로.
2. 레이아웃 모드에서만 보정 문장을 한 줄 가로 스크롤로(104 → 56, −48). 고른 글자는 자동으로 보이는 자리에 온다. 오른쪽 버튼 둘은 가로로.

기대: 위 고정 227 → 122, 전파 절 첫 화면 148 → 약 300. 띠 + Δ 줄 + 표본 첫 줄이 온전히 보인다.

## 미결정

1. 칩 안 내용 — 이름 + 글자 수 + Δ 요약 첫 항목(추천) vs 이름 + Δ 요약만.
2. `기본값(모델)` 카드 — 뺀다(추천, 눌러도 아무 일 없음) vs 띠 맨 앞에 남긴다.
3. 도구 줄 — `…` 메뉴로 넣는다(추천) vs 레이아웃 모드에서만 숨기고 획 편집에는 남긴다.
