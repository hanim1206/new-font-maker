# 대시보드

지금 연 폰트의 한눈 화면. 셸 머리 `‹ 내 폰트`가 여기로 오고, 내폰트에서 폰트를 고르면 여기부터. 위는 폰트 카드, 아래는 왼쪽 레일 + 섹션 다섯(스타일 → 레이아웃 → 초성 → 중성 → 종성, 큰 것부터 작은 것). 플랜: `docs/plans/2026-09-26_섹션-홈과-도마.md`. 코드는 옛 랩 이름 `DashboardLabPage.tsx` 그대로.

## 1. 폰트 카드
- 1.1 카드 — 이름 · 마지막 고침 · 손댄 자소 수 · 예시 문장을 이 폰트로. 지금 폰트 하나
- 1.2 새 폰트 — 카드 옆 단추. 내폰트(`/fonts`)로 간다(목록 · 새로 만들기는 거기서). 못 올린 변경은 먼저 올린다
- 1.3 마이페이지 — 머리 오른쪽 아이콘. 아이디 · 요금제 · 폰트 수, 게이트가 켜졌을 때만 로그아웃
- 1.4 시안인 것 — 이름 바꾸기 · 다운로드 · `…` 메뉴는 아직 동작하지 않는다

## 2. 섹션
- 2.1 레일 — 왼쪽 목차. 누르면 그 섹션으로 스크롤, 스크롤하면 따라온다. 맨 아래 `검수`
- 2.2 스타일 — 굵기 · 기울기 · 둥글기 · 부리 타일 넷. 아이콘은 값과 무관한 공통 예시, 값은 숫자
- 2.3 레이아웃 — 여섯 구조군 대표 글자 6장(첫닿자 상자 옅게)
- 2.4 초성 · 중성 · 종성 — 요약 줄: 제목 · 수 · 손댄 n · 앞 4장. 머리(화살표) 전체가 섹션 홈으로 가는 문

## 3. 섹션 홈
- 3.1 층 — 대시보드 위로 오른쪽에서 밀려온다. `‹`로 돌아오면 묶기 상태가 남는다
- 3.2 묶기 칩 — 초성은 `전체 · 줄기 · 홑·쌍 · 획 수`(줄기는 어휘사전, 획 수는 저장된 우리 획 수). 중 · 종성은 아직 `전체`만. 카드는 자리만 옮긴다
- 3.3 도마 — 카드 탭 = 담기 · 빼기, 소제목 탭 = 그 묶음으로 교체. 맨 아래 도마 줄과 `편집 n`
- 3.4 편집 — `편집 n`은 도마를 들고 자소편집 획 편집으로(`?char=대표 글자&mode=stroke&part=`). 대시보드의 자소 카드는 홈을 건너뛰고 그 자소 하나만 올려 같은 곳으로
